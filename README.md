# MusicGameDemo

基于 **Phaser 4 + Vite + TypeScript** 的 2D 音乐弹幕游戏原型。当前原型验证“自由走位 + 固定节拍攻击 + 轻重连段 + 节拍弹幕”的战斗循环。

- 在线试玩：[cj-viewer.github.io/MusicGameDemo](https://cj-viewer.github.io/MusicGameDemo/)
- 开发分支：`dev-1.0`
- 生产 Pages：发布源为 `gh-pages` 分支；推送 `main` 后由 GitHub Actions 自动构建并更新该分支，`dev-1.0` 可通过 Actions 手动部署到同一在线链接。

## 快速开始

```powershell
git clone --branch dev-1.0 https://github.com/cj-viewer/MusicGameDemo.git
Set-Location MusicGameDemo
npm ci
npm run dev
```

默认访问 <http://localhost:5173>；点击画面开始游戏并解锁浏览器音频。端口被占用时可指定其他端口，例如：

```powershell
npm run dev -- --host 127.0.0.1 --port 3000
```

| 指令 | 用途 |
|---|---|
| `npm ci` | 按锁定文件安装依赖 |
| `npm run dev` | 启动带热更新的开发服务器 |
| `npm run build` | TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 本地预览生产构建 |

## 操作

| 输入 | 行为 |
|---|---|
| `W A S D` | 带惯性的八向移动 |
| 自动瞄准 | 默认锁定综合优先级最高的敌人；移动方向前方总角度 `45°` 的扇区内，敌人的有效距离减半，因此实际距离为普通目标 `2 倍` 时仍同等优先 |
| `"` 键 / `Enter` | 轻攻击 / 重攻击（均需踩节拍） |
| 左 `Shift` / 右 `Shift` | 沿当前移动方向闪避 |
| `Esc` | 打开 / 关闭音量设置面板；打开时游戏完全暂停，可调敌人死亡音效并开关右下 FPV 观察窗；P 面板打开时按 Esc 会直接切换到音量面板 |
| 左摇杆 | 移动；右摇杆不再控制瞄准 |
| `LB` / `RB` | 闪避 / 自动按当前节拍提交轻或重攻击 |
| `R` / `F` | 重新开始 / 调试时直接充满 ComboMeter |
| `C` | 调试时直接触发从左向右的全屏发光条清弹效果 |
| `P` | 打开调参面板；可调整玩家/敌人战斗参数、切换两种重击新模式，并一键导出当前战斗参数 TXT |
| `Space` | 在开场标题页或任一段开场视频期间跳过全部片头并进入教学；教学期间直接进入正式关 |

## 当前原型快照

- `P` 面板可开关玩家远程无限射程；按回传配置默认开启。关闭后有限模式最远飞行 `164px`，可按 `20px` 调为 `40–2000px`。无限模式仍在命中或飞出战斗区时销毁；错误输入在有限模式下只飞行设定距离的 `50%`。
- 敌人致死命中即时播放高频破裂、中频下坠与低频落地三层合成死亡音，不再额外排队普通受伤音；独立“敌人死亡音效”滑杆位于 `Esc` 音量面板，默认和上限均为 `100%`，并继续乘“受伤与敌亡”分类音量。
- `P` 面板“模式 / 导出”页中，荧光棒“贯屏激光”和警棍“击退月牙波”按回传配置默认开启。激光充能延迟默认 `0ms`（`0–1500ms`、步进 `50ms`），粗细默认 `56px`（`12–160px`、步进 `4px`）。月牙正确重击最远距离默认 `424px`（`120–1600px`、步进 `40px`），Poor 为当前值 `50%`，末段减速后急停。警棍轻击角度默认 `180°`（`30–180°`、步进 `10°`），距离范围默认 `111px`（`40–400px`、步进 `10px`）；Poor 仍只把覆盖角缩至 `50%`。两种重击继续读取当前拍基础伤害、判定与 ComboMeter 倍率。
- 同页的“导出当前战斗参数 TXT”会下载 UTF-8 文本，使用稳定的 `key=value` 键名记录玩家、两把武器、敌人、掉落、射程、死亡音量、粉丝螺旋概率及两种新模式开关；不包含 BGM 槽和纯显示设置，可在事后回传该文件以把记录值改成代码默认值。

- 内部开发画布统一为 `1920 x 1080`，Phaser 全局使用 Nearest Neighbor / `pixelArt` / 整数像素渲染；低于 1080p 的物理屏幕显示分辨率提示，不启动游戏。旧 `1280 x 720` UI 按 `1.5x` 迁移；角色、特效与武器不采用原生 `1x` 放大，而按等效比例保持此前屏幕视觉大小。
- 进入页面后先显示“节奏星球 / DJ Drop the Beat”开场标题页；点击“开始”后依次带原声播放 `intro.mp4` 与 `intro-rocket.mp4`，第二段结束后直接进入教学。标题页或任一段视频播放期间均可按空格跳过全部片头。两段视频均为 `1920 x 1080` H.264 + AAC，并将 `moov` 前置以支持边下边播。
- `src/game/assetManifest.ts` 统一管理加载分层：片头播放期间预热进入教学前所需的 `140` 个 core Loader 项，其中包含 `137` 张图片、两条节拍音效与教学 BGM；37 张环境运行资源与 1 张教学连段透明 UI 均计入这 137 张图片。core 文件合计 `12,977,685` 字节（约 `12.38MiB`）；两段片头视频由 `IntroScene` 单独加载，不计入 core。其余三首 BGM 在教学开始后后台下载，无物件 `pink-stage-clean-background.png` 与 10 张演唱会候选图不会被运行时请求。
- 教学关使用项目方 `111.png` 定版内容覆盖后的 `pond-stage-background.png`（`1920 x 1080`）作为俯视池塘底图；完成教学并选择进入正式关时，只切换环境层到粉紫音乐广场。正式关由 `pink-stage-runtime-base.png` 与 35 张 `1920 x 1080` 坐标系透明环境 PNG 原位重组；物件 RGB 全部直接取自项目方提供的 sRGB 原图，透明范围包含原始投影，安检口内的左右设备、中央淡色场景与前排栏杆归入入口大门层，底部左右灌木和低墙覆盖到画布边缘。35 个物件以各自底边为锚点跟随当前轻 / 重拍同步回弹：轻拍放大到 `100.3% x 101%`、单程 `80ms`，重拍放大到 `100.6% x 102.2%`、单程 `110ms`，随后 yoyo 回到原比例；运行底图与另行保留的无物件 `pink-stage-clean-background.png` 均不参与动画。两套环境都不带碰撞，命中、Fever 与连段的瞬时反馈、教学 UI、角色、敌人和战斗特效继续绘制在其上方。
- `132 BPM`、`4/4`；攻击判定窗口为拍点前后各 `0.2s`。校准后绝对误差 `≤100ms` 评价为 `PERFECT`，`100–200ms` 为 `GOOD`，超出窗口或轻重输入错误为 `POOR`；Perfect / Good 均按正确攻击结算。教学关与正式关都不再绘制未来三拍的整场扩散框，移除只影响视觉提示，不改变判定窗口、节拍类型或攻击结算。四首 BGM 均以 `132 / 各自源 BPM` 的倍率播放，Conductor 和 BGM 同速减慢；各曲目的源文件首拍偏移会按倍率换算，启动及各自循环拍数边界都会重新与节拍时钟对齐。
- 默认主音量为 `150%`，范围 `0–300%`；BGM、节拍喊声、攻击与错误、受伤与敌亡、Combo、Fever、拾取六类音效默认均为 `100%`，各自范围 `0–200%`。最终响度为主音量乘对应分类音量。BGM 内部基础混音为 `0.084375`：在 BGM 滑杆由旧 `150%` 归一显示为 `100%` 后，默认有效响度仍再提高为上一版的 `1.5x`。`Esc` 面板打开时会暂停节拍时钟、BGM、物理、动画、补间和输入推进，并可开关右下角 `240 x 153px` 的只读 FPV 观察窗。轻 / 重拍叫喊基础音量为 `0.42 / 0.28`，分别提前 `70ms / 74ms` 播放，重叫喊在素材时间 `330–360ms` 淡出。
- `P` 调参面板分为“速度 / 频率”“玩家伤害”“敌人 / 掉落”“模式 / 导出”四页。玩家伤害页可分别设置荧光棒轻 / 重基础伤害 `10 / 18` 和警棍轻 / 重基础伤害 `12 / 26`，范围均为 `0–100`、步进 `1`，并保留两把武器各自的 Perfect / Good / Poor 倍率。导出的 TXT 同步包含四个基础伤害及其它全部战斗数值。
- “速度 / 频率”页将玩家动作速度拆为荧光棒轻 / 重、警棍轻 / 重四项，默认均为 `100%`，可按 `10%` 调为 `50–200%`；分别缩放对应攻击的角色特效、武器挥动和动作锁。警棍弧弹飞行速度继续单独设置。TXT 保留旧统一速度键作兼容，并新增四个分项键。
- 两段片头全部结束或按空格跳过后直接显示教学场景，不再出现第二层全屏标题字幕或“点击开始”。教学关在场地左下区域绘制精简操作卡：左栏以 WASD / 左右 Shift 对齐显示移动和冲刺，右栏以双引号键、Enter、Esc 对齐显示轻攻击、重攻击和设置；不重复说明锁定规则或四拍顺序。操作卡位于场地底图之上、角色与战斗特效之下，进入正式游戏后隐藏。完成连续三个小节后，`Quote` 轻攻击直接进入正式关，`Enter` 重攻击重新开始教学；鼠标不提交战斗输入，手柄 `RB / LB` 分别对应进入 / 重练。教学练习期间也可按 `Space` 跳过，直接进入正式关倒计时。
- 战斗区仍为 `1638 x 921px`，相对 1080p 内部画布左、右、下各保留约 `123px` 的场外留白。教学关与正式关均不再创建旧版约 140 根深紫粉边缘律动条，也不再显示常驻紫色战斗区外框，因此三侧不再出现随拍跳高、变亮或重拍转橙的程序色块，战斗区边缘也不再常驻描边。不可见物理边界、Fever 临时边框、出生点、弹丸清理与 HUD 布局不变。
- 玩家、保安和粉丝仍按脚底 Y 做 TopDown 遮挡：越靠屏幕下方越晚绘制并遮住上方对象；玩家手持武器和敌人血条继续跟随所属角色深度。
- HP 血条移至左下并与 ComboMeter 处于同一水平基线；Combo 环另向右移动其自身宽度的一半（`22px`），仍保持更明显的同拍律动：轻拍前纵向压至 `0.84x`、拍点弹至 `1.26x`；重拍前压至 `0.62x`、拍点弹至 `1.50x`。只改变厚度和最多 `5%` 的明度 / 饱和度，血量长度与数字保持稳定。
- 当前武器名放在 ComboMeter 圆环右侧并使用 `22px` 粗体，只显示“荧光棒”或“警棍”；荧光棒为青色，警棍为紫色。右上角不再常驻显示设置快捷键提示，设置仍只由 `Esc` 打开。
- 1080p 内部画布中的程序化场内对象使用 `1.2x` 世界倍率（旧 `0.8x × 1.5`），换算到屏幕后保持旧版视觉尺寸。正式红发玩家与 Light 特效基准使用约 `0.7067x`，Hard 特效在此基础上乘 `1.18`；玩家内部可见高度约 `76.3px`，显示到旧 720p 尺寸的窗口时仍约为 `50.9px`，固定碰撞体内部尺寸约 `29.7 x 76.3px`。HUD、场地与节奏提示按 `1.5x` 迁移；三侧场外留白继续由当前战斗区坐标保留。圆形表盘标题常驻显示 `ComboMeter`。
- 教学与正式游戏均不显示常驻战斗区外框、未来三拍的整场扩散框或底部汇聚式节奏条。教学练习期间左上使用项目方提供的 `578 x 278` RGBA 连段面板，运行时显示为 `366 x 176px`，中心位于 `(284, 211)`、左上角为 `(101, 123)`；标题、框线和“轻轻轻重”图形均直接来自同一张透明图，当前拍与命中反馈只裁剪对应格并以 ADD 短暂高亮。旧深色程序化背板、程序文字、三小节进度、延迟数值和 `SPACE` 提示不再可见，但三小节判定、延迟校准与 `Space` 跳过逻辑保持不变。进入正式关后仍改为 `320 x 64px` 的紧凑四拍图标条，仅保留四个当前武器 pattern 图标并继续逐拍高亮，武器切换时同步重建。正确输入、Fever 和连续四拍仍可触发各自短暂反馈；连续完成四拍后，场地四边仍会爆发 84 个向内 / 向外分层的 ADD 光屑，并叠加双层瞬时边框冲击波、宽光带、四角星爆与轻微镜头震动，但结束后不会留下常驻或循环扩散框。Fever Time 中每次正确输入额外恢复 `10 HP`；踩拍镜头相对基础 zoom 的轻 / 重增幅分别为 `0.00375 / 0.01875`。
- 玩家手持武器使用正式 `light_stick_player.png / baton_player01.png`，比例约 `0.5653x`。旋转原点统一放在素材握把末端：荧光棒 `(101/128, 98/128)`、警棍 `(123/128, 121/128)`；该点固定在角色腰部中线、内部下移 `22.5px`。朝向另一侧时不使用 Phaser `flipX`，而是以负 `scaleX` 围绕非中心 Origin 做几何镜像，并同步反转挥击角，因此所有武器严格关于角色中线对称。玩家层级由前到后为“武器 > 角色 > 攻击特效”，自动索敌不显示白色攻击方向短线。轻 / 重攻击使用不同幅度的非线性挥击并在 `200ms` 内结束；荧光棒弹幕速度为 `360 px/s`。玩家直射完全沿用“点/线特效自发光”任务的短光束比例：亮芯长度为判定段 `1.35x`、厚度为原弹体 `0.52x`，连续胶囊外晕为判定段 `1.95x`、原弹体 `3.2x`；中心仍位于从实时武器发光端前方内部 `28.8px` 开始的原判定段上。普通亮芯按 `66%` 向白抬亮，正确踩拍使用 `96%` Alpha 的纯白亮芯，外晕保持武器原色与 ADD 合成；判定长度、三点命中盒、弹速和寿命不变。荧光棒踩拍不再从角色侧边叠加双环或白色扇形。
- 敌方弹幕使用点状亮芯，颜色迁移为保安青色 `#52efff`、粉丝橙红色 `#ff543d`，并使用连续径向 Alpha 衰减的 ADD 光晕；默认基础速度为 `144 px/s`，默认关闭节拍突进并全程匀速运动。`P` 调参面板仍可手动开启突进，开启后每拍前 `0.2s` 按归一化 `easeInExpo` 曲线重分配同样总路程。
- 保安默认 `1 次/拍` 发射单个点弹；粉丝默认 `0.25 次/拍`，即每四拍攻击一次。粉丝每次攻击默认有 `10%` 概率生成三弧共 `30` 个点弹；未触发时回退为量化方向单发。概率、两类频率与弹幕伤害均在 P 面板调整。
- 前五波敌人总数为 `2 / 4 / 6 / 10 / 16`，保持逐波递增且每波保安与粉丝各半。首次清空第五波后继续每隔 `2s` 重复生成第五波的 `16` 只敌人，无限循环，顶部波次继续累计。
- 教学关默认播放 `bgm0.mp3`；正式关默认改为 `bgm2.mp3`，仍可在 P 面板切换其它 BGM。
- 玩家使用正式红发角色序列帧：待机 / 跑步各 8 帧、闪避 12 帧。轻 / 重攻击 PNG 继续使用原尺寸并作为角色身后的单一特效 Sprite，与角色同中心、同翻转并在播放期间跟随；Light / Hard 分别以亮黄 `#fff36b` / 紫粉 `#f28cff` 填色，Alpha 为 `0.72 / 0.92`，使用 ADD、Glow 与 Threshold→Blur→ADD Bloom，不再生成放大副本。角色与敌人受击时分别闪白 `140 / 120ms`。冲刺位移仍为 `140ms`，Dash 动画与动作锁为 `360ms`，位移结束后继续收势 `220ms`；拖影只在实际位移期间按 `10ms` 固定时间轴补齐，起始 Alpha 为 `1.0`。玩家战败时不再播放死亡动画或全场溶解：玩家与所有存活敌人立即停止位移并原地循环 Idle（无独立 Idle 的保安保持静止帧），场上敌我弹幕和命中盒立即销毁，场景保留并显示重开提示。
- 玩家、保安、粉丝及预留中型保安的本体也按“轻轻轻重”跟拍。每一拍都以脚底为视觉锚点，仅在 Y 轴向上弹：轻拍到基础高度的 `105%`，重拍到 `110%`，随后在各自 `170ms / 220ms` 内回归基础比例；不会低于原本高度。X 轴和左右镜像完全不动。律动只改变显示 Sprite 的果冻表现，不缩放物理碰撞体、武器、攻击特效、FPV 或 Dash 位移。
- 保安和粉丝每拍只重选一次带随机偏差的移动方向，拍间持续匀速；保安 / 粉丝速度分别为 `44 / 66 px/s`，未启用的中型保安速度为 `72 px/s`。所有敌人本体随当前移动 / 攻击方向左右镜像，攻击特效与本体使用同一朝向，FPV 投影也复制该镜像状态。保安攻击时叠加 Light 特效；`FanEnemy` 使用正式橙色粉丝外观，循环 8 帧 Run，攻击时叠加橙色 Hard 特效并挥动专属荧光棒。其 `256 x 256px` 本体按玩家同款约 `0.7067x` 显示，`128 x 128px` 武器按玩家武器同款约 `0.5653x` 显示。粉丝加入物理组后会重新写入初始匀速；攻击特效由场景时钟按 `500ms` 手动切换，禁止再调用会锁住主线程的 Phaser 特效动画 `.play()`。角色、武器、特效由前到后分层，不再播放旧 Roll / 近战素材。
- Combo 环、左下武器名、顶部 Wave 文字与右下 FPV 框随每个轻重拍纵向律动；重拍振幅高于轻拍。
- 左右 `Shift` 冲刺距离为 `160px`、耗时 `140ms`，不再消耗或显示体力。拍点前后 `0.12s` 内为正确闪避并扣 `10` 点 ComboMeter（半级），窗口外扣 `20` 点（一级）；ComboMeter 已为 `0` 时，两次成功启动的闪避至少间隔 `500ms`。Fever 激活期间改为分别缩短 `1.6 / 3.2` 拍。每次闪避进行到约 `93ms`（总时长的三分之二）都会释放 Fever 重拍同款 `190px` 全圆音波，清除敌弹并按同款伤害规则结算，不再返还 ComboMeter。
- 正确攻击的弹幕数由 ComboMeter 等级决定：荧光棒基础 `1` 发、每升 `1` 级增加 `1` 发、最多 `5` 发；警棍基础 `1` 段、每升 `2` 个等级增加 `1` 段、最多 `3` 段。错误输入两把武器均只保留中线 `1` 条。Fever 满格时，一根贯穿画面高度的橙金发光条用 `620ms` 从左向右扫屏，逐列清除敌弹并保留玩家弹；`C` 可直接调试同一效果。单发 / 单段伤害为当前武器轻 / 重基础伤害 × Perfect / Good / Poor 倍率 × ComboMeter 倍率。
- 保安仍对应警棍掉落，粉丝仍对应荧光棒掉落；两者默认掉落概率均为 `100%`，可在 P 中独立调为 `0–100%`。只有玩家未持有且场上不存在同种掉落时才进行本次概率判定，继续避免重复掉落。
- 主场景基础镜头为 `1.0x`；角色离开场地中央 `12%` 死区后，镜头会按其靠近上下左右或四角的程度向同方向前探，1080p 内部坐标的水平 / 垂直最大约 `45 / 30px`，以约 `220ms` 指数阻尼缓入缓出；HUD、设置面板、调参面板与右下 FPV 保持屏幕锚定。

精确玩法数值与验证范围见 [简化玩法策划案](docs/简化玩法策划案（原型版）.md)。

## 文档入口与维护规则

文档目录的职责和更新顺序见 [docs/README.md](docs/README.md)。各文件不是重复备份：

| 文档 | 用途 |
|---|---|
| [简化玩法策划案](docs/简化玩法策划案（原型版）.md) | 当前可运行原型的玩家规则与验收范围 |
| [实机落地与调整记录](docs/实机落地与调整记录.md) | 代码事实、精确参数、历史变更和验收清单 |
| [完整策划案](<docs/2D音乐弹幕游戏策划案 (持续更新).md>) | 长期产品目标；不等于已实现内容 |
| [更新记录](docs/更新记录/README.md) | 每次可交付改动的短记录与影响范围 |
| [资源与素材规范](docs/资源与素材规范.md) | 资源目录、命名、加载和验收规则 |
| [美术资产索引](docs/美术资产索引.md) | 美术目录分类、资源数量与运行时加载索引 |
| [AGENTS.md](AGENTS.md) | Agent 进入项目时必须先读的规范、变更合同与验证要求 |

**任何影响玩法、参数、素材、输入、音效、表现、工程入口或部署的改动，必须在同一提交中：**

1. 在 `docs/更新记录/` 新增或更新对应日期的短记录；
2. 更新 `docs/实机落地与调整记录.md` 的“当前实机规则”和验收项；
3. 若玩家可感知规则变化，再同步更新简化玩法策划案；
4. 若改变了长期产品目标，再同步完整策划案。

只改代码、不更新文档，视为改动未完成。
