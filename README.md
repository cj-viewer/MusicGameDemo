# MusicGameDemo

基于 **Phaser 4 + Vite + TypeScript** 的 2D 音乐弹幕游戏原型。当前原型验证“自由走位 + 固定节拍攻击 + 轻重连段 + 节拍弹幕”的战斗循环。

- 在线试玩：[cj-viewer.github.io/MusicGameDemo](https://cj-viewer.github.io/MusicGameDemo/)
- 开发分支：`dev-1.0`
- 生产 Pages：发布源为 `gh-pages` 分支；推送 `main` 后由 GitHub Actions 自动构建并更新该分支，`dev-1.0` 可通过 Actions 手动部署到同一在线链接。

## 快速开始

```powershell
git clone --branch dev-1.0 https://github.com/cj-viewer/MusicGameDemo.git
Set-Location MusicGameDemo
npm ci
npm run dev
```

默认访问 <http://localhost:5173>；点击画面开始游戏并解锁浏览器音频。端口被占用时可指定其他端口，例如：

```powershell
npm run dev -- --host 127.0.0.1 --port 3000
```

| 指令 | 用途 |
|---|---|
| `npm ci` | 按锁定文件安装依赖 |
| `npm run dev` | 启动带热更新的开发服务器 |
| `npm run build` | TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 本地预览生产构建 |

## 操作

| 输入 | 行为 |
|---|---|
| `W A S D` | 带惯性的八向移动 |
| 自动瞄准 | 默认锁定综合优先级最高的敌人；移动方向前方总角度 `45°` 的扇区内，敌人的有效距离减半，因此实际距离为普通目标 `2 倍` 时仍同等优先 |
| `"` 键 / `Enter` | 轻攻击 / 重攻击（均需踩节拍） |
| 鼠标左键 / 右键 | 轻攻击 / 重攻击（保留键盘之外的备用输入） |
| 左 `Shift` / 右 `Shift` | 沿当前移动方向闪避 |
| `Esc` | 打开 / 关闭设置面板；打开时游戏完全暂停，可分别调主音量、BGM、音效及右下 FPV 观察窗 |
| 左摇杆 | 移动；右摇杆不再控制瞄准 |
| `LB` / `RB` | 闪避 / 自动按当前节拍提交轻或重攻击 |
| `R` / `F` | 重新开始 / 调试时直接充满 ComboMeter |
| `P` | 打开调参面板；可调整玩家/敌方弹速、BGM 槽并开关敌方弹幕节拍突进 |
| `Space` | 在开场标题页或开场视频期间跳过片头，直接进入教学 |

## 当前原型快照

- 内部开发画布统一为 `1920 x 1080`，Phaser 全局使用 Nearest Neighbor / `pixelArt` / 整数像素渲染；低于 1080p 的物理屏幕显示分辨率提示，不启动游戏。旧 `1280 x 720` UI 按 `1.5x` 迁移；角色、特效与武器不采用原生 `1x` 放大，而按等效比例保持此前屏幕视觉大小。
- 进入页面后先显示“节奏星球 / DJ Drop the Beat”开场标题页；点击“开始”后带原声播放 `intro.mp4`。标题页和视频播放期间均可按空格跳过，视频结束或跳过后直接进入教学。
- `132 BPM`、`4/4`；攻击判定窗口为拍点前后各 `0.1s`。四首 BGM 均以 `132 / 各自源 BPM` 的倍率播放，Conductor 和 BGM 同速减慢；各曲目的源文件首拍偏移会按倍率换算，启动及各自循环拍数边界都会重新与节拍时钟对齐。
- 默认主音量为 `150%`，范围 `0–300%`；BGM 通道默认 `150%`，音效通道默认 `100%`，范围均为 `0–200%`。三者只能通过 `Esc` 设置面板调整，最终响度为主音量乘对应通道音量。音效通道包含轻重鼓点/叫喊、攻击、命中、受伤、拾取、Combo 与 Fever 等反馈。面板打开时会暂停节拍时钟、BGM、物理、动画、补间和输入推进。面板同时可开关右下角 `240 x 153px` 的只读 FPV 观察窗；它锚定屏幕右下，右/下边缘仅留 `20px`，并沿玩家当前自动锁定方向投影主场景中的敌人和弹幕。BGM 内部基础混音保持 `0.0375`；轻拍叫喊基础音量为 `0.42`，重拍保持 `0.28`。素材分别提前 `70ms / 74ms` 播放，重叫喊在素材时间 `330–360ms` 淡出。
- 游戏加载后直接显示教学场景，不再出现全屏标题字幕或“点击开始”。教学关在场地左下区域绘制精简操作卡：左栏以 WASD / 左右 Shift 对齐显示移动和冲刺，右栏以双引号键、Enter、Esc 对齐显示轻攻击、重攻击和设置；不重复说明锁定规则或四拍顺序。操作卡位于场地底图之上、角色与战斗特效之下，进入正式游戏后隐藏。完成连续三个小节后，轻攻击（`Quote` / 鼠标左键）直接进入正式关，重攻击（`Enter` / 鼠标右键）重新开始教学；手柄 `RB / LB` 分别对应进入 / 重练。
- 战斗区为 `1638 x 921px`，相对 1080p 内部画布左、右、下各预留约 `123px` 的人群律动带。约 140 根完全不透明的深紫粉竖条沿三侧按交错轨道铺开；旧版位置、尺寸和随机错落统一按 `1.5x` 迁移，因此在屏幕上的视觉密度与大小保持不变。律动条没有碰撞盒，可在跳动时侵入战斗区；轻重拍的明度提升和饱和度降低均不超过 `5%`。每个拍间只读取下一拍：轻拍前始终保持粉紫色；重拍前也保持粉紫色，仅在正确判定窗口开启前最后 `0.2s` 内过渡为橙色。当前判定窗为拍点前后各 `0.1s`，因此转色区间为拍点前 `0.3s → 0.1s`，窗口开启时完成转橙，并保持到重拍落点。
- 律动条与角色 Sprite / Image 统一按脚底 Y 做 TopDown 遮挡：越靠屏幕下方越晚绘制并遮住上方对象；玩家手持武器、瞄准线和敌人血条跟随所属角色深度。
- HP 血条移至左下并与 ComboMeter 处于同一水平基线；Combo 环另向右移动其自身宽度的一半（`22px`），仍保持更明显的同拍律动：轻拍前纵向压至 `0.84x`、拍点弹至 `1.26x`；重拍前压至 `0.62x`、拍点弹至 `1.50x`。只改变厚度和最多 `5%` 的明度 / 饱和度，血量长度与数字保持稳定。
- 当前武器名放在 ComboMeter 圆环右侧并使用 `22px` 粗体，只显示“荧光棒”或“警棍”；荧光棒为青色，警棍为紫色。右上角不再常驻显示设置快捷键提示，设置仍只由 `Esc` 打开。
- 1080p 内部画布中的程序化场内对象使用 `1.2x` 世界倍率（旧 `0.8x × 1.5`），换算到屏幕后保持旧版视觉尺寸。正式红发玩家与 Light 特效基准使用约 `0.7067x`，Hard 特效在此基础上乘 `1.18`；玩家内部可见高度约 `76.3px`，显示到旧 720p 尺寸的窗口时仍约为 `50.9px`，固定碰撞体内部尺寸约 `29.7 x 76.3px`。HUD、场地、节奏条与边缘律动带按 `1.5x` 迁移。圆形表盘标题常驻显示 `ComboMeter`。
- 教学与正式游戏统一使用场地判定框：底部汇聚式节奏条均不显示，顶部四拍连段只在教学练习期间显示，进入正式关后连同背板、图标与文字彻底销毁，武器切换也不会重建；教学仍保留延迟校准。场地内同时预告未来 `1 / 2 / 3` 拍的三个缩放框：每个方框从场地 `0.7x` 出发，在 `3` 拍内按 `easeInExpo` 缓慢扩大，到达边界即为拍点并立即隐藏，绝不显示到场地框外。轻拍粉紫框与重拍橙色框的初始透明度均为 `0`，两者统一使用 `Expo.In` 淡入；橙色框将透明度进度压缩到原时长的 `90%`，因此曲线类型一致但会稍早达到峰值。正确输入会额外让本拍场地框加粗、轻微外扩并淡出。Fever Time 中每次正确输入额外恢复 `10 HP`，不超过最大生命；踩拍镜头相对基础 zoom 的轻 / 重增幅分别为 `0.00375 / 0.01875`（最大 `1.00375x / 1.01875x`）。
- 玩家手持武器使用正式 `light_stick_player.png / baton_player01.png`，比例约 `0.5653x`。旋转原点统一放在素材握把末端：荧光棒 `(101/128, 98/128)`、警棍 `(123/128, 121/128)`；该点固定在角色腰部中线、内部下移 `22.5px`。朝向另一侧时不使用 Phaser `flipX`，而是以负 `scaleX` 围绕非中心 Origin 做几何镜像，并同步反转挥击角，因此所有武器严格关于角色中线对称。玩家层级由前到后为“武器 > 角色 > 攻击特效”，自动索敌不显示白色攻击方向短线。轻 / 重攻击使用不同幅度的非线性挥击并在 `200ms` 内结束；荧光棒弹幕速度为 `360 px/s`。
- 敌方弹幕默认基础速度为 `144 px/s`，默认关闭节拍突进并全程匀速运动；`P` 调参面板仍可手动开启突进，开启后每拍前 `0.2s` 按归一化 `easeInExpo` 曲线重分配同样总路程。
- 所有敌人统一在每个小节最后一拍（第 4 拍）攻击：先瞄向玩家，再吸附到最近的八方向扇区中线；实际发射角只会是 `0° / 45° / 90° / 135° / 180° / -135° / -90° / -45°`。玩家仍使用原来的连续惯性移动。
- 前五波敌人总数为 `2 / 4 / 8 / 16 / 32`，每波保安与粉丝各半。首次清空第五波后，场景底层显示低饱和紫色纯色背板与 `VICTORY`，角色、敌人、弹幕、场地框和 HUD 均从其上方经过；背板和文字在之后的循环波次中随轻重拍持续呼吸。战斗继续，每隔 `2s` 重复生成第五波的 `32` 只敌人，无限循环。顶部波次继续累计为 `Wave 6、Wave 7……`，用于记录挑战轮次。
- 玩家使用正式红发角色序列帧：待机 / 跑步各 8 帧、闪避 12 帧、两套死亡各 8 帧。轻 / 重攻击 PNG 作为角色身后的独立特效层，与角色 `256 x 256` 画布同中心、同翻转并在播放期间跟随；轻特效源 PNG 的非透明像素全部为 `Alpha=255`，因此运行时统一降至 `0.45` 不透明度，重特效保留素材渐变并放大至角色基准的 `1.18x`。攻击特效另叠加 ADD 自发光副本，重击的亮度与扩散幅度高于轻击；实际轻 / 重按键始终映射对应特效。角色与敌人受击时分别闪白 `140 / 120ms`。冲刺位移仍为 `140ms`；12 帧 Dash 动画以 `360ms` 慢速播放，位移结束后继续收势 `220ms`，再切换为 Run / Idle。拖影只在实际位移的 `140ms` 内每 `10ms` 连续采样一次，起始不透明度为上限 `1.0`（两倍原 `0.55` 的 `1.10` 会被 Phaser 截断）；战败随机播放一套 `800ms` 死亡动画，同时除玩家外的场景层在 `820ms` 内以块状溶解退为纯黑。内部视觉高度约 `76.3px`，屏幕占比维持上一版。
- 保安和粉丝每拍只重选一次带随机偏差的移动方向，拍间持续匀速；保安 / 粉丝速度分别为 `44 / 66 px/s`，未启用的中型保安速度为 `72 px/s`。所有敌人本体随当前移动 / 攻击方向左右镜像，攻击特效与本体使用同一朝向，FPV 投影也复制该镜像状态。保安第 4 拍叠加 Light 攻击特效；`FanEnemy` 使用正式橙色粉丝外观，循环 8 帧 Run，第 4 拍叠加橙色 Hard 攻击特效并挥动专属荧光棒。其 `256 x 256px` 本体按玩家同款约 `0.7067x` 显示，`128 x 128px` 武器按玩家武器同款约 `0.5653x` 显示。粉丝加入物理组后会重新写入初始匀速；攻击特效由场景时钟按 `500ms` 手动切换，禁止再调用会锁住主线程的 Phaser 特效动画 `.play()`。角色、武器、特效由前到后分层，不再播放旧 Roll / 近战素材。
- Combo 环、左下武器名、顶部 Wave 文字与右下 FPV 框随每个轻重拍纵向律动；重拍振幅高于轻拍。
- 左右 `Shift` 冲刺距离为 `160px`、耗时 `140ms`，不再消耗或显示体力。拍点前后 `0.12s` 内为正确闪避并扣 `10` 点 ComboMeter（半级），窗口外扣 `20` 点（一级）；ComboMeter 已为 `0` 时，两次成功启动的闪避至少间隔 `500ms`。Fever 激活期间改为分别缩短 `1.6 / 3.2` 拍。每次闪避进行到约 `93ms`（总时长的三分之二）都会释放 Fever 重拍同款 `190px` 全圆音波，清除敌弹并按同款伤害规则结算，不再返还 ComboMeter。
- 玩家正确攻击的弹幕数由 ComboMeter 等级决定：等级 `0–5` 对应 `1–6` 发 / 段。荧光棒先生成中央弹丸，此后每升一级按左、右交替增加一发；错误输入固定中央 1 发。警棍保持原有弧线扫击形式，等级 `0 / 1 / ≥2` 分别启用中、内、外共 `1 / 2 / 3` 层，且不再叠加纯色扇形方向图形。两把武器均围绕腰部握把向下挥动，并在 `200ms` 内回位。
- 主场景基础镜头为 `1.0x`；角色离开场地中央 `12%` 死区后，镜头会按其靠近上下左右或四角的程度向同方向前探，1080p 内部坐标的水平 / 垂直最大约 `45 / 30px`，以约 `220ms` 指数阻尼缓入缓出；HUD、设置面板、调参面板与右下 FPV 保持屏幕锚定。

精确玩法数值与验证范围见 [简化玩法策划案](docs/简化玩法策划案（原型版）.md)。

1. 在 `docs/更新记录/` 新增或更新对应日期的短记录；
2. 更新 `docs/实机落地与调整记录.md` 的“当前实机规则”和验收项；

4. 若改变了长期产品目标，再同步完整策划案。

只改代码、不更新文档，视为改动未完成。

## 项目结构

```text
src/                       游戏代码（场景、敌人、玩家、节拍、HUD、武器）
public/assets/             运行时资源
docs/                      项目文档、更新记录和策划附件
.github/workflows/         GitHub Pages 部署工作流
.claude/skills/            Claude 侧 Phaser 技能
.agents/skills/            共享 agent 技能副本
```

`dist/`、`node_modules/` 和本地自动化产物不应提交。资源放置与命名要求见 [资源与素材规范](docs/资源与素材规范.md)。
