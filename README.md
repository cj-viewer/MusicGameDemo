# MusicGameDemo

基于 **Phaser 4 + Vite + TypeScript** 的 2D 音乐弹幕游戏原型。当前原型验证“自由走位 + 统一鼓点 + 任意拍起手的轻重连招 + 节拍弹幕”的战斗循环。

- 在线试玩：[cj-viewer.github.io/MusicGameDemo](https://cj-viewer.github.io/MusicGameDemo/)
- 开发分支：`dev-1.0`
- 生产 Pages：发布源为 `gh-pages` 分支；推送 `main` 后由 GitHub Actions 自动构建并更新该分支，`dev-1.0` 可通过 Actions 手动部署到同一在线链接。

## 快速开始

```powershell
git clone --branch dev-1.0 https://github.com/cj-viewer/MusicGameDemo.git
Set-Location MusicGameDemo
npm ci
npm run dev
```

默认访问 <http://localhost:5173>；点击画面开始游戏并解锁浏览器音频。端口被占用时可指定其他端口，例如：

```powershell
npm run dev -- --host 127.0.0.1 --port 3000
```

| 指令 | 用途 |
|---|---|
| `npm ci` | 按锁定文件安装依赖 |
| `npm run dev` | 启动带热更新的开发服务器 |
| `npm run build` | TypeScript 检查并构建到 `dist/` |
| `npm run preview` | 本地预览生产构建 |

## 双人联机

标题页可选择“单人模式”继续原有剧情 / 波次流程，或选择“多人联机”进入房间大厅。联机需要同时运行网页服务器与 WebSocket 服务器：

    npm run multiplayer:server
    # 另开终端
    npm run dev

房主创建 5 位房间码并固定使用警棍；第二位玩家输入房间码加入并固定使用荧光棒。双方均为真人、各有独立 100 HP 血条，不生成 AI。移动支持方向键 / WASD，Z/J 轻击、X/K 重击；攻击需落在 132 BPM 拍点前后 190ms 内。房间服务器负责命中、伤害和胜负判定。部署到 HTTPS 页面时，需用 VITE_MULTIPLAYER_WS_URL=wss://你的服务器地址 指向单独部署的 WebSocket 服务；GitHub Pages 本身只托管静态网页。
## 操作

| 输入 | 行为 |
|---|---|
| `W A S D` | 带惯性的八向移动；突然反向时立即清零原速度并向新方向起步 |
| 自动 / 手动瞄准 | 默认自动锁定综合优先级最高的敌人；P Menu“模式 / 导出”可开启手动瞄准，开启后角色脚下显示跟随鼠标方向旋转的三角箭头 |
| 鼠标左键 / `"` 键 | 轻攻击（需踩节拍）；警棍轻击为准星方向近战扇形，扇形内敌人都会受击 |
| 鼠标右键 / `Enter` | 重攻击；只有命中当前 Pattern 的重击拍才生效，错拍 / 错步骤只显示节拍错误且不产生攻击 |
| 鼠标滚轮 | 正式关在已永久获得的荧光棒 / 警棍间循环切换；教学不响应 |
| 左 `Shift` / 右 `Shift` | 沿当前移动方向闪避 |
| `Esc` | 打开 / 关闭浅色磨砂白线音量面板；打开时游戏完全暂停，可调主音量、BGM、节拍与轻重喊声，并开关右下 FPV 观察窗；P 面板打开时按 Esc 会直接切换到音量面板 |
| 左摇杆 | 移动；右摇杆不再控制瞄准 |
| `LB` / `RB` | 闪避 / 自动提交当前连招所需输入（空闲时始终为轻攻击起手） |
| `R` / `F` | Replay（跳过教学、从第一关入场开始）/ 调试时直接充满 ComboMeter |
| `P` | 打开六页调参面板；可调整玩家 / 敌人 / Boss 战斗参数、ComboMeter 奖励、切换两种重击模式，并可持久化保存或导出当前配置 |
| `Space` | 在开场标题页 / 开场视频期间跳过片头；教学期间跳至教学结束动画；动画期间跳过并进入第一关 |

## 当前原型快照

- 内部画布统一为 `2560 x 1440`（2K），Phaser 使用 Nearest Neighbor、`pixelArt` 与整数像素渲染；低于 2K 的屏幕继续由 FIT 等比缩放运行，只在控制台提示。旧 `1280 x 720` UI 按 `2x` 映射，程序化场内对象的世界倍率为 `1.6x`。
- 当前唯一运行时标题图为 `backgrounds/intro/intro-title-background.png`，以 Cover 加安全出血铺满 2K 画布并带轻微分层视差。点击开始后播放 `intro.mp4`，播放完进入教学；教学结束后播放 `tutorial-complete.mp4`，自然播完或按 `Space` 跳过后进入第一关入场。两段视频均可用 `Space` 跳过。
- `src/game/assetManifest.ts` 的 core 共 `203` 个 Loader 项：`200` 张图片、两条节拍音效与教学 BGM，合计 `14,320,123` 字节（约 `13.66 MiB`）。仓库现有图片资源文件总数为 `259`（背景 `16`、角色 `192`、环境 `35`、UI `8`、武器 `8`；角色数含预览 GIF）；已停用的教学进度 / 静态底栏、片头视频、延后加载 BGM 和历史候选不计入 core。
- 教学关使用 `bg1.psd` 的无 UI 环境合成作为池塘底图。进入后先隐藏所有 UI 并锁定玩家操作，主角用 `2.8s` 从左侧自动走到画面中间偏左；停下后在角色头顶显示跟随玩家的白底黑字圆润像素气泡，鼠标左键或 `Quote` 依次推进六句入场台词，长句按气泡宽度自动换行。新增内容会说明按节奏击打、闪避的短暂无敌，以及三个小节加一次闪避的练习目标；教学 / 第一关不受控行走、教学 / 第一关对白和波次教学气泡存在期间，节拍器静音，恢复玩家控制后再恢复当前节拍音量。
- 教学开始时轻攻击、重攻击、Esc 设置与 L / R Shift 闪现四张操作卡同时出现并常驻。教学直接复用正式第一关的实时 ComboMeter；累计完成 3 个完整四拍 Pattern 并成功启动 1 次闪避后，玩家操作锁定并依次显示七句能量说明，其中包括“能量会给你的攻击带来加成。”和拾取武器提示，最后一句推进后直接进入教学结束动画。
- 教学池塘中的展示对象为粉色教学角色：无手持武器，使用 Idle / Run / Roll 三套动作，以正式粉丝速度的 `68%` 追随玩家，每 `16` 拍先死亡退场再翻滚生成；攻击按粉丝 `0.20 次/拍` 的节奏从嘴部发射粉色单发基础泡泡，玩家受击闪光与冲击反馈和第一关一致，但固定造成 `0` 伤害；进入第一关倒计时恢复满血。角色交替显示 Light / Hard 透明特效，加入玩家攻击判定与自动瞄准候选，但其死亡不计入正式波次或掉落。
- 教学关隐藏正式 HP、Wave、状态文字、FPV 和旧 PSD 静态状态条，直接显示上移后的正式第一关 ComboMeter / 武器状态组。正式关恢复完整实时 HUD 与 FPV。教学结束视频后，主角固定朝右，从左侧自动走到屏幕中央，以同款气泡说完两句对白后开始真实 `5s` 倒计时；倒计时攻击不增加 ComboMeter，开波时恢复收益。
- 两把武器各有一套四段轻重连招：任意踩中鼓点的轻攻击起手，后续必须在紧接着的下一拍完成对应步骤，漏拍、错拍或类型错误都会失败。正式顶部节奏条默认隐藏，起手后显示为 `7aae97b` 的无底板四图标样式，整体为 `116%`；底部 ComboMeter / 武器组同步放大到 `144%`，上移后最终约为 `(925,1250,530,144)`。正式 ComboMeter 使用橙色进度弧；Fever 触发帧立即清成空环与 `0%`，不再显示缓慢下降的剩余时间。玩家 HP 为 `144 x 50` 世界单位的头顶小血条。
- 教学仍使用闪现能量门槛：踩拍消耗 `5` 点，错拍消耗 `20` 点。正式关改为独立 `700ms` 冷却且不再消耗 ComboMeter；踩拍闪现保留清弹音波，错拍闪现只提供位移与无敌，不触发音波。
- 战斗活动区为 `x=96, y=96, 2368 x 1248px`，不可见物理边界仍生效，但教学和正式关均不创建常驻紫色边框、边缘律动色块或底部汇聚节奏条。正确输入仍显示屏幕锚定的短时判定框，起始 Alpha 为 `0.5`；连招已起手时，第 2–4 步恢复旧版同层级的三框小节预告，按原 `0.7x → 1x`、`2.4` 拍指数缩放曲线推进，并按待输入类型着色。正确重拍保留边框粒子，并随机把少量粒子强化为更大、更亮的烟花主束。
- `4/4`，教学关和第一关节奏 BPM 均默认 `132`，可分别在 P Menu 手动输入。教学背景仍保持每拍相同短鼓点；正式关每小节首拍换成更低、更重的鼓点，同时让玩家、普通敌人、17 个白名单场景物件、HUD 与 FPV 共同执行重拍脉冲。攻击判定窗口为拍点前后各 `0.2s`：校准后绝对误差 `≤100ms` 为 `PERFECT`，`100–200ms` 为 `GOOD`，其余、连招步骤轻重类型错误，或下一步拍点后 `200ms` 仍未输入均为连招失败。教学默认 `bgm0.mp3` 实测为 `153.057 BPM / 0.0s` 首拍 / `436` 循环拍，正式关默认 `bgm1.mp3` 为 `145 BPM / 0.0s` 首拍 / `498` 循环拍（军鼓频段八段相位检验，见 scripts/measure_audio_timing.py）；每关 BGM 按该关目标 BPM 与源 BPM 的比例变速；BGM 基础混音为 `0.125`。
- `Esc` 设置只保留当前实际发声的三路：主音量、BGM、节拍与轻重喊声，默认均为 `100%`、范围 `0–200%`；三条滑杆等距排列，FPV 开关上移到其下方。打开设置或 P 面板时，节拍、BGM、物理、动画、补间与玩法输入全部暂停。
- `P` 面板包含“速度 / 频率、玩家伤害、量表 / Fever、敌人 / 掉落、Boss、模式 / 导出”六页。玩家移动速度默认 `320 px/s`；荧光棒弹速默认 `1040 px/s`，玩家弹速调参上限为 `1600 px/s`，均可在“速度 / 频率”页调节并随配置保存 / 导出。当前浏览器保存的整份 P 参数已固化为代码默认值，包括保安 / Boss 单弹 `2.0x`、粉丝单弹 `1.5x`、粉丝三弧 `30%` 及 Boss 三类弹速 `280 / 240 / 300 px/s`。“模式 / 导出”页可切换自动 / 手动瞄准。“量表 / Fever”页除 Perfect `4` 点、Good `3` 点和完整 Pattern `10` 点奖励外，可分别设置教学关 / 第一关节奏 BPM：默认均为 `132`，范围 `40–240`，`±` 步进 `0.1`，点击蓝色数值可直接键盘输入小数；关闭 P Menu 后，Conductor、判定节拍和当前 BGM 播放速度按新值重新对齐。同页还包含默认 `1.0 点/秒` 的 ComboMeter 自然衰减，以及范围 `-500–500ms`、步进 `5ms` 的正式关节拍对齐偏移。
- 荧光棒前三拍正确轻击逐拍积累协同火力，第四拍重击按蓄势提高伤害；三拍完整时，贯屏激光追加两束窄角支援光。Wave 2 清空并等待 `2s` 后，第三波暂不生成，警棍固定掉在场地中央并复用玩家气泡依次说明拾取、新节奏型与滚轮切换；关闭最后一句后才启动 Wave 3。拾取后警棍加入永久库存并自动装备。警棍左键恢复近战伤害，不再清弹或弹反：攻击瞬间让准星方向扇形内的所有敌人受击。扇形改为更深的紫色实心范围，并复用重击的低强度外光、紫色主边与近白亮芯；默认角度随等级由约 `90°` 增至 `180°`，满级距离为 `300px`。教学仍只使用荧光棒。
- 正式关普通正确重击只保留短时判定框；完整四拍 Pattern 的最后一步才触发共同爆发：低频收尾音、场景 / HUD / FPV 重拍脉冲与 84 枚边缘光屑同时发生。玩家与敌人的共同重拍由稳定的小节首拍统一驱动，避免输入窗口内重复补间造成位置漂移。教学的连招反馈不变。
- Wave 3 使用“敌方问、玩家答”的四拍结构：每小节第 1、2 拍各限制两名敌人发射一组可读直射，留出第 3、4 拍重击收尾。Wave 4 起发射预警可在拍内切分出现，但危险抵近时刻仍锁在主拍。普通近战保持局部反馈，完整 Pattern 和 Wave Clear 才提升反馈层级。
- 所有敌方子弹不再按拍数或固定飞行距离自动销毁；普通点弹、Boss 三连弹、半月波和音符弹阵都会持续飞行，直到命中、被清弹效果清除或场景重置。离开教学进入结束动画前会清空全部教学弹幕。前五波普通敌人总数为 `2 / 6 / 12 / 18 / 24`，第五波后进入警卫长 Boss 战。清空 Boss 与随从后不显示 `VICTORY`，玩家原地通过同款气泡说“终于可以通过第一道安检口了。”；推进并关闭对白后原地等待 `2s`，再自动跑向画面顶部中央并淡出，完成后才冻结物理、动画、节拍和音频。按 `R` 会直接回到第一关入场，不重复教学。
- 正式保安与粉丝的 Idle / Run 已替换为场景统一配色，玩家轻击、两类 NPC 轻 / 重攻击特效已替换为修复透明通道的序列。正式保安接入 Idle / Run 各 8 帧及独立警棍，整体相较此前显示比例放大 `1.25x`；警棍再放大 `1.25x`，维持素材原色、无 Tint / Bloom，攻击时完成 `200ms` 挥击。玩家移动中使用警棍攻击不会锁住跑步动画。玩家线弹与保安 / 粉丝点弹现在分别把近白核心、明亮过渡、饱和实色外壳和极窄柔光烘入单张运行时 CanvasTexture，并且每颗弹只显示一个 `NORMAL` Image，不再叠加独立 ADD 光层；警棍、重击、Fever / 冲刺音波和清屏条也使用实色主体配克制外沿光。命中反馈改为保留纹理的暖粉短闪，致死帧不再出现放大纯白剪影。玩家红色线弹的可见主体在该材质基础上再缩短 `20%`，由判定段 `1.35x` 收为 `1.08x`，尾端锚点、外部纹理包围、厚度、判定、动画、速度、寿命、伤害和命中盒均不变。
- 敌人被击败时，在死亡位置触发一次性爆炸：双层冲击环、放射状长条溅射、主爆炸粒子和高速火花；保安为青色系、粉丝为橙红色系，短暂扩散后自动销毁，不依赖新素材或常驻动画。
- 玩家、正式粉丝、正式保安和教学角色均使用 `256 x 256px` 同画布阴影，运行时 Alpha 为 `0.45`；阴影不参与角色拍点缩放，层级仅高于场景并低于攻击特效、武器和角色。角色、武器和特效继续按脚底 Y 与所属角色深度排序；掉落武器的外环加粗、扩大并提高 Glow，武器贴图自身也增加独立发光，拍点时亮度更明显。正式关底图与非白名单环境物件保持静止，仅 `5、9、17、18、19、22、25–34、36` 这 17 个红框确认物件随轻 / 重拍回弹并生成顶部粒子花。主镜头基础 zoom 为 `1.065x`，死区为活动区 `3%`，最大前探约 `45 / 30px`，以约 `220ms` 阻尼缓入缓出；攻击、命中、Combo、Fever 和错误反馈不再触发整屏 shake 或 zoom punch。
- 教学与正式关 ComboMeter 满格时都会进入 Fever，Meter 当帧清零；Fever 只持续到橙金发光条用 `760ms` 完成从左向右清弹，结束瞬间为玩家恢复 `20 HP`。除此之外战斗中没有其他回血；第一关倒计时开始时的满血是关卡初始状态重置。正确攻击的单发 / 单段伤害为当前武器轻重基础伤害 × 判定倍率 × ComboMeter 倍率。

精确玩法数值与验证范围见 [简化玩法策划案](docs/简化玩法策划案（原型版）.md)。

## 项目结构

