## 维护规则

- 角色动作目录名称直接使用 `idle`、`run`、`dash`、`attack_light`、`attack_hard`、`death01`、`death02`；预览 GIF 与 PNG 帧一起放在所属动作的 `preview/`，但预览文件不登记为运行时贴图。
- 玩家维持现有 `player/animation/` 层级，避免无关重命名 61 张正式帧。新 NPC 不再新增 `animation/` 中间层，直接遵循 `npc/<角色>/<动作>/`。
- 任何资源迁移必须在同一提交同步更新本索引、`资源与素材规范.md`、全部加载路径与本地构建验证；移动后必须确认旧路径没有运行时引用。
- 当前 16 张背景与 35 张环境物件中，core 实际请求教学底图 1 张、粉紫运行底图 1 张和物件 35 张，共 37 张；6 张教学 UI 独立请求，不计入环境口径。完整 core 为 113 张图片 + 3 条音频，共 116 个 Loader 项（2026-08-21 循环动画抽帧与量化后，经浏览器 Loader 实测 totalToLoad=116、totalFailed=0）。当前开场标题图由 `IntroScene` 单独请求且不计入 core；教学进度 / 静态底栏、干净底图、旧 `arena.png`、上游 `main-menu.png` 和 10 张演唱会候选图只随构建归档，不进入当前加载清单，`bg1.psd` 是外部制作源，也不进入运行时加载清单。
