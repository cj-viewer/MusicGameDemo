# 2026-08-21 行走静音、径向弹反、分敌弹尺寸与 Replay 修复

## 需求

- 玩家处于剧情不受控行走时关闭节拍器声音。
- 警棍轻击保持武器形状，改为把周围伤害弹回，并按子弹相对玩家的实时角度决定方向。
- P Menu 分别调整不同敌人的单弹尺寸。
- Replay 修复入场走路动画，并跳过教学直接从第一关开始。

## 实现

- 教学 / 第一关脚本行走与全部对白状态共用节拍静音门；BGM 保持播放，恢复控制后恢复节拍音量。
- 警棍轻击改为连续圆弧弹反波。普通点弹保留原形并从敌方物理组迁移至玩家组，复杂 Boss 弹转成紫色反射弹；两者方向均取触发帧的玩家到子弹角度。
- P Menu 增加保安、粉丝、Boss 三项独立单弹尺寸，实时同步可见图像、主 Body 和三点采样盒，并进入本机保存 / TXT。旧统一尺寸值用于迁移旧存档。
- `R` 使用带数据的 Scene restart 直达第一关；场景创建时恢复全局 AnimationManager、Arcade World 和 TweenManager，脚本行走开始时主动重启 Run。

## 影响

- 改变脚本行走音频、警棍轻击、敌弹尺寸调参和 Replay 起点。
- 不改变 BGM、敌弹原始伤害 / 速度、警棍贴图、Wave 数量或首次进入的教学流程。

## 验证

- `npm run build`：通过 TypeScript 检查与 Vite production build。
- 待实机覆盖 Replay 入场 Run、两段脚本行走静音、普通 / Boss 弹反及三类尺寸即时调参。

## 遗留

- 第 4 项节奏专注方向仅在交付中提供设计建议，本轮不写入玩法代码。
