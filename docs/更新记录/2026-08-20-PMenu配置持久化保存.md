# 2026-08-20：P Menu 配置持久化保存

- 需求：为 P Menu 增加持久化保存当前配置的按钮。
- 实现：“模式 / 导出”页新增“保存当前配置”，将 P Menu 全部当前值和教学 / 正式 BGM 槽写入版本化浏览器本机存储；刷新或下次打开同一站点时自动恢复。按钮提供成功 / 失败反馈，原 TXT 导出按钮继续保留。
- 影响：不保存 FPV 或 Esc 音量设置；不新增运行时素材，不发送网络请求，不改变 TXT 导出格式。
- 验证：`npm run build` 通过；本地浏览器完成“参数 `0.75 → 0.80`、保存、刷新恢复 `0.80`、恢复并保存 `0.75`”闭环，控制台无 error / warning。
- 遗留：当前没有“清除本机保存”按钮；如需恢复代码默认值，可手动调回后再次保存。
