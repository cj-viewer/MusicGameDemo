# 2026-08-20：波次敌人分批生成与调参

## 需求

- 每波敌人改为分批生成，每批随机 `1–4` 名。
- 后续批次随机间隔 `2–5s`；整波名单生成完毕后停止刷新。
- 全部敌人死亡后等待 `2s` 进入下一波，下一波继续分批生成。
- 批次数量范围和间隔范围加入 P Menu。

## 实现

- 每波先生成保留原种类、数量和编队坐标的待生成队列，首批立即执行，后续批次由 Scene Clock 逐次安排。
- 波次完成条件同时检查待生成队列、批次计时器和场上存活敌人，避免玩家提前清空某一批时错误跳波。
- P Menu“敌人 / 掉落”页新增每批最少 / 最多敌人数、最短 / 最长批次间隔；默认分别为 `1 / 4 / 2 / 5`。
- 四项参数进入浏览器本机保存和 TXT `[waveSpawn]` 导出段。

## 影响

- 普通波、Boss 波及通关后的循环波次全部改为分批登场；每波总数量、敌人种类和原编队落点不变。
- 打开设置或 P Menu 时 Scene Clock 暂停，因此尚未到时的下一批不会在暂停期间生成。

## 验证

- `npm run build` 通过。
- `http://127.0.0.1:5174/` 返回 HTTP 200。
- 内置浏览器确认四项 P Menu 默认值为 `1 / 4 / 2.0s / 5.0s`，控制台 `0 error / 0 warning`。
- 临时把每批范围改成 `1–1` 后进入 Wave 1：首批只出现保安，等待区间结束后粉丝作为第二批出现；该临时参数未保存。

## 遗留

- 未新增单独的批次倒计时 UI；玩家仍通过敌人实际登场观察刷新节奏。
