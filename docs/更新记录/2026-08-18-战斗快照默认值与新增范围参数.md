# 2026-08-18：战斗快照默认值与新增范围参数

## 需求

- 读取回传的战斗参数 TXT，并把记录值设为游戏默认值。
- P 菜单新增警棍轻击距离范围和荧光棒右键激光粗细。
- 修复 Esc 音量菜单仍无法显示的问题。

## 实现

- 快照中的玩家、武器倍率、敌人和掉落参数全部回填；无限射程及两种新重击默认开启，激光延迟为 `0ms`，月牙距离为 `424px`，轻击角度为 `180°`。
- 新增激光粗细 `56px`（`12–160px`、步进 `4px`）与警棍轻击距离 `111px`（`40–400px`、步进 `10px`），两项同步导出到 TXT。
- Escape 改由 Window 捕获阶段统一处理，并把音量容器提升到 `depth 2000`；场景重启会移除监听，不会重复绑定。

## 影响

- 激光粗细直接参与视觉和命中宽度，Poor 为当前设定的 `55%`。
- 警棍轻击距离只改变轻击弧段半径，不影响旧重击或新月牙。
- P 面板打开时按 Esc 仍会直接切换到音量面板。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- Chrome 实机派发 Escape 后，音量面板真实显示九条滑杆与 FPV 开关，容器为 `visible / active = true / true`、`depth = 2000`，玩法处于暂停。
- P“模式 / 导出”页实际显示激光粗细 `56px` 与轻击距离 `111px`，布局无重叠；运行时默认值与回传快照逐项一致，TXT 包含两个新增键，控制台无 Runtime exception。

## 遗留

- 无。
