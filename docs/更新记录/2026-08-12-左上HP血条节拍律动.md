# 2026-08-12：左上 HP 血条节拍律动

## 需求

- 为左上角血条增加与边缘律动类似的节拍反馈。

## 实现

- 每拍前 `0.42拍` 开始纵向压缩：轻拍压到 `0.9x`，重拍压到 `0.72x`。
- 拍点轻拍弹到 `1.15x`、重拍弹到 `1.32x`，分别在 `170ms / 220ms` 内回落。
- 轻拍颜色变化为明度 `+3%`、饱和度 `-3%`；重拍为 `+5% / -5%`。
- 只改变填充条和背板的纵向尺寸，横向 HP 比例与数字不变。

## 影响

- HP 条能辅助提示当前拍型，但不会让玩家误读剩余生命。
- 正常绿色与低血量红色都会在各自基础色上进行同样的小范围变化。
- 不修改生命值、受伤、无敌时间或其他 HUD。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地实机确认血条拍前压缩、拍点弹起，轻重拍幅度不同且横向长度 / 数字稳定。
- 浏览器控制台无 error / warn。

## 遗留

- 当前只让血条形状律动，HP 数字保持完全静止；如需更强受伤反馈，应单独设计而不是放大常驻数字。
