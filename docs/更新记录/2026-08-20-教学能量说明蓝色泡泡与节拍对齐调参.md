# 2026-08-20：教学能量说明、蓝色泡泡与节拍对齐调参

## 需求

- 稍微放慢 Fever 清屏；教学角色改吐蓝色攻击泡泡。
- 缩小并加粗像素对话框；教学 UI 同时出现，并在 3 次正确节拍输入和 1 次成功闪避后补充五句 ComboMeter 说明。
- 将默认每秒 1% 的 ComboMeter 流逝和正式关音乐 / 节拍对齐偏移放进 P Menu。

## 实现

- 清屏扫动由 `620ms` 调为 `760ms`。
- 教学角色复用粉丝基础单发泡泡的速度、尺寸、伤害和频率，独立使用蓝色复合材质并禁用三弧散射。
- 对话框缩为 `330 × 104` 世界尺寸，正文和继续提示均加粗并保留自动换行。
- 四张教学操作卡同时淡入并常驻；3 个不同拍点的正确输入加 1 次实际成功闪避后，锁定操作并按顺序显示用户指定的五句能量说明，随后进入结束动画。
- ComboMeter 普通状态默认衰减 `1.0 点/秒`；P Menu 可在 `0–20 点/秒` 内以 `0.1` 调整。
- P Menu 新增正式关节拍对齐偏移，默认 `0ms`，范围 `-500–500ms`、步进 `5ms`，正值让音乐相对判定拍更早；两项参数都支持本机保存和 TXT 导出。

## 影响

- 修改教学流程、教学敌弹表现、对话 UI、ComboMeter 运行规则、Fever 清屏速度和正式关 BGM 对齐。
- 不新增或替换运行时素材；正式粉丝弹幕种类、伤害和三弧概率不变。

## 验证

- `npm run build` 通过。
- 按快速迭代要求未进行浏览器试玩。

## 遗留

- 正式关节拍偏移的最佳数值需要结合目标播放设备和歌曲主观试听后再保存。
