# 2026-08-21：正式关换 bgm1 与关闭 B/C/V 调试键

## 需求

- 正式关卡音乐由 bgm2 换为 bgm1；换曲后复检教学关与正式关的音乐-鼓点对齐，不对则调整。
- 关闭 B / C / V 三个调试按键。

## 实现

- `bgmTracks.ts` 的 `DEFAULT_LEVEL_BGM_SLOT 1→0`（bgm-1），`TuningEditor.levelBgmSlot` 默认同步 `1→0`。
- 移除 `MainScene` 中 `KeyC`（全屏清弹）、`keydown-V`（一键通关）、`keydown-B`（一键跳 Boss）三个调试入口及 `C` 键捕获；随之删除唯一由 B 键调用的 `debugJumpToBoss()`。`triggerFeverScreenClear` / `finishVictory` 仍由 Fever 满格扫屏与 Boss 波正常通关路径调用。`F`（充能）与 `H`（判定框）调试键按要求保留。
- README 同步：删除 C 键行与 Fever 行的调试提及，修正 BGM 默认曲目与实测参数表述。

## 对齐复检（scripts/measure_audio_timing.py）

- **bgm1（新正式关曲目）**：`145.0 / 0.0` 八段相位平整（±10ms 内无趋势漂移），全局宽扫描最优 `145.0132` 的八段呈 +20ms 斜坡，斜率折算真值 ≈ `145.00`，表值成立；`loopBeats 498 = round(206.069×145/60)` 精确。
- **bgm0（教学关）**：宽扫描曾出现相位 `0.188` 的竞争解，经分频段仲裁否决——军鼓 150–400Hz（1.19x）与高频 2k–8kHz（1.28x）都支持 `0.0` 相位族，`0.188` 只是中频反拍音色族。军鼓频段决定性测量为 `153.0438 / 0.3815`（八段 0.381–0.385 纹丝不动），与表值 `153.057 / 0.0` 的偏差为起点 10.5ms、曲末 4ms，全程低于感知阈，**表值维持不变**。
- 结论：两关对齐均通过，无需调整数值。

## 影响

- 正式关默认曲目变为 bgm1（145 BPM 源、播放速率 `132/145 ≈ 0.9103`）。
- **P Menu 配置持久化会盖过新默认**：本地存过配置的测试者需在 P Menu 把正式关曲目改回 bgm1（或清掉 localStorage 的调参配置）才会听到新默认。
- 玩家可用输入不再包含任何跳关 / 清弹 / 通关捷径；`F` / `H` 仍为开发用途保留。

## 验证

- 对 `KeyV / KeyB / KeyC` 派发真实 `keydown` 事件：状态、波次均不变，`victoryAchieved=false`，无异常。
- 控制台无 error；`npm run build` 通过。
