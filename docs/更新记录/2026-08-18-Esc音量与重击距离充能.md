# 2026-08-18：Esc 音量与重击距离充能

## 需求

- 恢复无法正常找到的 Esc 音量菜单，并把敌人死亡音效独立音量放入其中。
- 为警棍新重击加入可调最远距离与接近终点时的明显减速急停。
- 为警棍轻击加入范围角度参数。
- 为荧光棒新重击加入可调充能延迟。

## 实现

- FPV 控件从误放的 P 容器移回 Esc 音量容器；P 打开时按 Esc 可直接切换到音量面板。
- Esc 新增“敌人死亡音效”第九滑杆，默认 `100%`、范围 `0–200%`；P 左侧删除重复入口。
- P“模式 / 导出”新增激光充能延迟 `300ms`（`0–1500ms`、步进 `50ms`）、月牙最远距离 `624px`（`120–1600px`、步进 `40px`）及警棍轻击角度 `90°`（`30–180°`、步进 `10°`）。三个值同步写入战斗参数 TXT。
- 激光先显示充能环，再由可暂停 / 可取消的 Scene Timer 发射。月牙在最后 `15%` 行程以二次 ease-out 减速到零，终点停留 `90ms` 后用 `110ms` 放大淡出。Poor 月牙距离为设定值 `50%`；Poor 轻击角度仍为设定值 `50%`。

## 影响

- 两种新重击开关仍默认关闭；关闭时原重击不变。
- 轻击角度只影响警棍实际轻击，不影响旧重击或新月牙。
- 游戏结束会同时取消未完成的激光充能 Timer 与相关特效。

## 验证

- `npm run build` 通过。
- Chrome 实测 P → Esc 切换、敌亡滑杆、FPV 归属、`300ms` 激光延迟、`400px` 月牙终点与末段减速、`30° / 150°` 轻击起始角，以及 TXT 新键；控制台无 error / warn。

## 遗留

- 新增参数均已进入 P 和 TXT，可在后续试玩后直接通过快照回填默认值。
