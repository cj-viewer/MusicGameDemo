# 2026-08-14：镜头跟随、FOV 与下一拍单框预告

## 需求

- 缩小镜头死区，让角色移动时的镜头跟随更明显。
- 轻拍 FOV 缩放降为现有的 `0.5` 倍，重拍提升为现有的 `1.25` 倍。
- 节拍缩放方框仅在自己成为下一拍时出现，减少画面叠加。

## 实现

- 主镜头归一化死区由 `0.24` 调整为 `0.12`；最大前探和阻尼保持 `30 / 20px`、`220ms`。
- 轻拍相对基础 zoom 的增幅由 `0.0075` 调整为 `0.00375`，重拍由 `0.015` 调整为 `0.01875`。
- 节拍框预告数量由未来三拍改为下一拍一个，方框在一拍内从 `0.7x` 扩大至场地边界。
- 外侧律动条只在下一拍为重拍时，按照该橙框的透明度曲线转橙；轻拍恢复原色。

## 影响

- 角色较小幅度离开场地中心便能带动镜头，更容易感受到跟随方向。
- 轻拍镜头更稳定，重拍冲击更明显。
- 场内不会再同时叠加三个不同节拍的缩放框。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 浏览器实机确认仅显示下一拍方框与轻重拍视觉强度差异；源码参数读回死区 `0.12`、zoom 增幅 `0.00375 / 0.01875`。
- 浏览器控制台无 error / warning。

## 遗留

- 需要继续主观确认 `0.12` 死区在长时间键盘移动下是否舒适。
