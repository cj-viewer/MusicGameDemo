# 2026-08-16：修复 Esc 设置并加入攻击准确度评价

## 需求

- 修复 Esc 无法进入设置的问题，并确保设置暂停后仍能用 Esc 关闭。
- 为玩家攻击增加音游式 `PERFECT / GOOD / POOR` 准确度评价，并设计有张力的文字和进退场表现。

## 实现

- Esc 改由主键盘监听优先识别 `event.code === 'Escape'`，显式捕获 `KeyCodes.ESC`，处理位置早于所有暂停和面板可见性拦截；移除重复的独立 `keydown-ESC` 入口。
- 攻击窗口改为拍点前后各 `200ms`。校准后绝对误差 `≤100ms` 为 PERFECT，`>100ms 且 ≤200ms` 为 GOOD，窗口外或轻重类型错误为 POOR。Perfect / Good 均按正确攻击结算，Poor 沿用错误攻击、断连和弱化弹幕。
- 按后续反馈，评价改为在玩家实际攻击锚点附近生成的小型 JRPG 浮字。主字使用 `Arial Narrow` 回退字体栈、粗斜体、深色描边和轻微纵向渐变；副标显示 `ON BEAT` 或 `EARLY / LATE + 三位毫秒数`。
- 浮字从轻微压缩状态快速弹起，停留后继续上浮消隐。Perfect 使用金色，Good 使用蓝色，Poor 使用灰色；每个实例独立退场销毁，连续攻击只会短暂自然重叠。

## 影响

- 影响键盘设置入口、攻击窗口、正确攻击结算范围、Combo 连续性和攻击反馈 HUD。
- 不改变 BGM、Conductor、场地框提前量、闪避窗口、伤害公式、武器 pattern、自动瞄准或敌人行为。
- 教学延迟校准继续限制在 `±120ms`；评价读取校准后的偏差，不建立第二套计时。

## 验证

- `npm run build`：TypeScript 类型检查与 Vite 生产构建通过。
- Chrome DevTools 键盘事件验证：首次 Escape 后 `panel=true / paused=true`，再次按下后恢复为 `false / false`。
- 判定边界验证：`±100ms=PERFECT`、`±200ms=GOOD`、`±201ms=POOR`。
- 浮字运行时验证：三档对象均生成在攻击锚点附近，字号为 `24 / 22 / 20px`，副标分别正确显示 EARLY / LATE / OFF BEAT，约 `850ms` 后均已销毁。

## 遗留

- 没有新增运行时素材或字体文件；显示效果使用系统字体回退栈，避免增加资源加载失败点。
