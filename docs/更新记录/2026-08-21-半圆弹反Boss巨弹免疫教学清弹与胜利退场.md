# 2026-08-21：半圆弹反、Boss 巨弹免疫、教学清弹与胜利退场

## 需求

- 把警棍弹反改为有方向的浅紫半圆，并让轻 / 重攻击在 Fever 时温和扩大。
- 禁止弹反 Boss 巨型弹珠和巨型紫色月牙。
- 教学结束时清理全部教学弹幕。
- 胜利后不显示 `VICTORY`，原地显示对白，关闭后停留 `2s`，再让玩家自动走向画面顶部中央后淡出。

## 实现

- 左键弹反使用面向准星的浅紫填充扇面与紫色双弧，正确 / 错拍总角约 `150° / 105°`；距离和角度在 Fever 时增加 `12%`。
- 右键扫击 / 月牙同样获得 `12%` Fever 角度与距离增幅，但保留更窄、更深、更远的表现。
- Boss 三连巨型弹与七采样紫色月牙增加不可弹反标记；音符弹和普通点弹不受影响。
- 教学结束公共入口统一清弹。胜利结尾隐藏 `VICTORY`；冻结延后到原地对白、对白关闭后的 `2s` 停留、不可控上行和 `650ms` 整体淡出之后。
