# 2026-08-17：背景任务素材与分层环境完整迁移

## 需求

把“背景图验证：抠图/动态物体”任务中的背景素材、可重复生成资料和最终运行时表现完整迁移到当前本地，同时保留当前已经完成的敌我攻击自发光与全部战斗逻辑。

## 实现

- 教学关接入 `1920 x 1080` 绿色池塘底图；完成教学进入正式关时切换为粉紫音乐广场。
- 正式关使用 `pink-stage-runtime-base.png` 与 35 张 RGBA 环境物件按生成坐标原位重组；物件以底边为锚点同步轻 / 重拍回弹，底图不动且全部环境层无物理体。
- 迁移参考 JPG、补画源、灰度蒙版、离线重组预览、生成脚本与生成坐标清单，保留完整可追溯链。
- 一并迁移背景任务早期生成的 10 张演唱会候选图；它们仅归档在 `concert-variants/`，当前不 preload、不参与关卡切换。
- 合入上游加载优化后，`assetManifest.ts` 统一预载池塘、粉紫运行底图与 35 个物件共 37 张环境运行资源；`MainScene.ts` 只保留环境创建、教学 / 正式切换与整数拍回弹接线，没有覆盖当前自发光、发射点、命中判定、伤害、弹速、寿命或敌人逻辑。
