# 2026-08-14：敌弹节拍突进开关与速度曲线

## 需求

- 恢复敌方弹幕跟随节奏突进，并在 `P` 调参面板中提供可选开关。
- 敌方弹幕默认速度降为上一版的 `0.8x`。
- 每拍前 `0.2s` 先减速、后向前突进；这一窗口的总位移必须等于原本匀速 `0.2s` 的路程。

## 实现

- 敌弹默认基础速度从 `180 px/s` 改为 `144 px/s`。
- `TuningEditor` 新增“弹幕节拍突进”开关，默认“已开启”；开关会即时作用于现存和后续敌弹。
- 拍前窗口固定为 `0.2s`，累计位移使用归一化 `easeInExpo`：开头慢、临近拍点快。
- 每帧按实际覆盖的曲线区间积分，并对跨窗口边界、跨拍点的帧分段计算；因此一个完整窗口总位移恒为 `baseSpeed × 0.2s`，默认 `28.8px`。
- 关闭开关时弹幕全程以 P 面板当前敌弹速度匀速运动；重新开启时立即恢复节拍突进。

## 影响

- 敌弹瞬时速度和拖尾节奏重新具有明显拍点感，但总路程不因曲线而变化。
- 敌弹尺寸、伤害、8 拍寿命、发射方向、判定盒和每小节一次的攻击频率不变。

## 验证

- `npm.cmd run build` 通过。
- 本地浏览器确认 P 面板默认显示 `敌人弹速 144 px/s` 和“弹幕节拍突进：已开启”，点击可在 `false / true` 间即时切换。
- 以 120 段检查归一化积分，结果 `28.800000000000008px`，与目标 `28.8px` 一致；曲线四分位累计路程为 `0.159 / 0.9 / 5.091 / 28.8px`，符合先慢后快。
- 控制台 `0 error / 0 warning`，页面返回 `HTTP 200`。
