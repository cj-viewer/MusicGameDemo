# 2026-08-17：移除双关卡边缘律动色块

## 需求

删除教学关与正式关左侧、右侧和底部会随节拍跳动、变亮或转橙的紫粉色块。

## 实现

- `MainScene` 不再创建约 140 个三侧 `rhythmBlocks`。
- 删除这些色块专用的拍前压缩、逐帧重拍转色、拍点跳高 Tween、状态字段与颜色插值代码。
- 两关共用同一个主场景，因此同一处删除同时覆盖教学与正式流程。

## 影响

- 战斗区继续保持 `x=141–1779`、`y=18–939`，左、右、下约 `123px` 场外留白和所有物理边界不变。
- 场地框、三拍预告、Fever 边框、角色跟拍、正式关 35 个物件回弹，以及连续四拍触发的 84 个 ADD 边缘光屑均保留。
- 无资源增删；core 仍为 137 张图片 + 3 个音频、共 140 个 Loader 项与约 `12.38MiB`，图片 / GIF 仍为 `209` 个。

## 验证

- `npm.cmd run build` 与独立 TypeScript 检查均通过。
- 在 `http://127.0.0.1:5180/` 的教学关和正式关各观察至少一个完整四拍周期：左、右、底部均无旧紫粉色块、跳高、亮度跳变或重拍转橙；场地提示、角色跟拍、正式关物件回弹和双关卡切换保持正常。
- 浏览器控制台 `0 error / 0 warning`。

## 遗留

如后续需要扩大实际战斗区或重新设计三侧装饰，应另行确认；本次只删除旧色块视觉层。
