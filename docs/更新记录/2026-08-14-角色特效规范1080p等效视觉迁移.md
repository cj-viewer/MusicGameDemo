# 2026-08-14：角色特效规范与 1080p 等效视觉迁移

## 需求

- 按飞书 [Si想家-角色特效规范](https://lilithgames.feishu.cn/wiki/N1fTwofxXiMNs2k8H8VcTX9jnnd?from=from_copylink) 构建角色、武器和轻重攻击表现。
- 轻攻击使用 Attack Light 粒子特效，重攻击使用 Attack Hard 放射爆发特效。
- 不把角色改成原生 `1x` 后放大；维持本轮修改前的屏幕视觉大小。
- 先在本地修改，不提交、不推送。

## 实现

- 内部画布迁移为 `1920 x 1080`，旧 720p UI、场地和边缘律动带统一按 `1.5x` 映射；启用 Nearest Neighbor、`pixelArt` 和整数像素渲染。低于 1080p 物理分辨率时只显示提示。
- 玩家与攻击特效使用约 `0.7067x`，1080p 内部可见高度约 `76.3px`；FIT 到旧 720p 窗口时仍约 `50.9px`。程序化场内对象使用 `1.2x`，武器使用约 `0.5653x`，保持旧屏幕占比。
- Attack Light / Hard 独立 Sprite 与角色同中心、同缩放、同翻转并在播放期间跟随，不再侧移、额外放大或淡出。表现类型改为跟随实际轻 / 重输入；错误输入不会按目标 pattern 串播另一套特效，自动演示仍按 pattern。
- 荧光棒和警棍使用 `128 x 128px` 正式贴图及各自握点原点。玩家层级由前到后为“武器 > 角色 > 特效”；轻 / 重挥击使用不同的非线性幅度并在 `200ms` 内回位。
- 战败增加全屏淡黑，保留 Death1 / Death2 随机死亡动画。

## 影响

- 画布、HUD、场地、主镜头、FPV、角色、正式武器、攻击特效和低分辨率入口受影响。
- BPM、输入窗口、伤害、波次、音量和在线部署不变。
- 本次没有修改或新增素材文件。

## 验证

- 54 张玩家动画 / 特效 PNG 全部为 `256 x 256px`；8 张玩家武器候选 PNG 全部为 `128 x 128px`。
- `npm.cmd run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地开发页内部 Canvas 为 `1920 x 1080`，缩放后的玩家屏幕视觉大小与上一版接近；轻、重攻击独立特效在角色身后播放。

## 遗留

- 当前仓库仍没有 Pick 序列帧，不使用其他动作冒充。
- 粉丝现有动画是旧版可变画布素材，尚无符合 256 方形模板的替换源文件。
- 当前更改仅在本地工作树，未创建提交、未推送远端。
