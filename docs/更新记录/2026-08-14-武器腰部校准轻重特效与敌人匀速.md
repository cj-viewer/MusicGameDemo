# 2026-08-14：武器腰部校准、轻重特效与敌人匀速

## 需求

- 修正玩家手持武器位置。
- 减轻 Light 攻击特效，确认引擎是否丢失透明渐变；适当放大 Hard 攻击特效。
- 敌人改为匀速移动，并略微降低移速。
- 继续只在本地修改。

## 实现

- 武器保留正式素材握点，握点相对角色中心按朝向侧移内部 `7.5px`、下移 `22.5px`，FIT 到旧 720p 窗口时等效 `5 / 15px`。
- Light 攻击独立 Sprite 使用 `0.45` Alpha；Hard 保留素材 Alpha 并使用角色基准 `1.18x`。
- SmallGuard / FanEnemy 拍间速度改为恒定 `44 / 66 px/s`，仅在整数拍重选方向；MidGuard 移动速度改为 `72 px/s` 匀速。
- 粉丝普通移动持续播放 Run，后半拍不再切换 Roll；受击和攻击动画不变。

## Alpha 核对

- Light 第 `1 / 3 / 5` 帧所有非透明像素均为 `Alpha=255`，每帧只有 1 个非零 Alpha 档位。
- Hard 第 3 帧有 `246` 个非零 Alpha 档位，范围为 `1–255`，中位数约 `25`。
- 结论：Phaser 能读取透明渐变；Light 的硬重感来自源 PNG 本身没有半透明像素。
