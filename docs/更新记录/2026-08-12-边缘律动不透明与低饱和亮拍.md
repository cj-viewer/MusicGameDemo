# 2026-08-12：边缘律动不透明与低饱和亮拍

## 需求

- 缓解边缘律动条过花、过亮和晃眼的问题。
- 所有律动条改为不透明；变亮时只提高明度并降低饱和度。

## 实现

- 律动条创建、蓄力、拍点和回落阶段统一保持 `alpha=1`，删除所有透明度动画。
- 基础色改为四种深紫粉：`#4c1d6f / #63356f / #70234e / #75405c`。
- 轻拍在基础色上提升约 `7%` 明度、降低 `20%` 饱和度；重拍提升约 `18%` 明度、降低 `42%` 饱和度。
- 蓄力阶段在基础色与目标色间插值，拍点后恢复基础色；轻重拍的压缩和跳高参数保持不变。

## 影响

- 重叠律动条不再产生透明叠色，静态画面更稳、更暗。
- 拍点仍有轻重差异，但颜色反馈从透明度闪烁改为克制的明度 / 饱和度变化。
- 不修改律动条数量、尺寸、位置、场地、角色、节拍或战斗规则。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地实机确认所有律动条始终不透明，静止时为深紫粉，轻重拍只改变明度、饱和度和形变。
- 浏览器控制台无 error / warn。

## 遗留

- 190 根律动条仍会在重拍同时大幅跳起；如果后续仍感觉动态刺激过强，可只降低重拍 `scaleY`，无需重新引入透明度变化。
