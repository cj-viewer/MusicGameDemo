# 2026-08-14：正式关隐藏顶部连段与教学完成输入

## 需求

- 教学结束并进入正式关后，顶部四拍连段面板必须彻底消失。
- 教学完成确认页使用现有轻重攻击输入：轻攻击进入下一关，重攻击重新教学。

## 实现

- `MainScene.buildPatternPanel(false)` 改为销毁整个顶部容器、清空图标和进度文字引用后直接返回；正式关不再创建紧凑版背板。
- 正式关切换武器时仍调用同一清理入口，因此不会重新生成顶部连段图标。
- 教学完成状态下，物理 `Quote` 键与鼠标左键映射为轻攻击并调用 `finishTutorial()`；`Enter` 与鼠标右键映射为重攻击并调用 `retryTutorial()`。
- 手柄确认保持单键兼容：`RB` 进入正式关，`LB` 重新教学。
- 完成页按钮文案同步改为“轻攻击：进入游戏 / 重攻击：重新教学”，鼠标点击按钮会停止事件冒泡，避免被全屏轻重输入重复处理。

## 影响

- 顶部四拍连段只服务教学练习；正式关只保留场地扩散判定框作为节拍视觉提示。
- 正常战斗中的轻重攻击、自动瞄准、武器切换、波次和判定规则不变。

## 验证

- `npm.cmd run build` 已通过。
- 无窗口本地浏览器确认教学练习仍显示顶部四拍连段。
- `Quote / Enter` 与鼠标左 / 右键分别验证为进入正式关 / 重开教学；轻攻击进入后 `patternPanel=false`、`patternIcons=0`，再次切换武器后仍保持清空。
- 重攻击重新进入教学后 `patternPanel=true`、`patternIcons=4`；浏览器控制台 `0 error / 0 warning`，页面返回 `HTTP 200`。

## 遗留

- 无。
