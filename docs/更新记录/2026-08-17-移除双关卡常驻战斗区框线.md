# 2026-08-17：移除双关卡常驻战斗区框线

## 需求

移除教学关和正式关围住整个战斗区的细紫色矩形框，并避免未来三拍扩散提示在到达边界时再次形成几乎相同的整场框。战斗范围和攻击判定不变。

## 实现

- 从 `MainScene` 删除常驻 `arenaBorder`、基础描边颜色和创建逻辑。
- 删除整数拍与连续四拍反馈中对该常驻对象加粗、换色和恢复描边的写入。
- 删除 `arenaBeatCues` 三个整场缩放框及其逐帧曲线、颜色、透明度和拍点清理链，避免教学关和正式关循环出现粉紫 / 橙色大框。
- 两关共用同一个 `MainScene`，因此同一处删除同时覆盖教学关和正式关。

## 影响

- 拍间不再显示围住整个 `ARENA` 的常驻紫色外框，也不再绘制未来三拍的整场扩散框。
- `ARENA` 的 `x=141–1779`、`y=18–939` 坐标与 Arcade Physics 世界边界保持不变，角色限制、敌人出生、弹丸清理、HUD 和 FPV 不受影响。
- 正确输入短效、Fever 临时边框，以及连续四拍的 84 个 ADD 光屑、双层瞬时边框波、宽光带和四角星爆继续保留；它们结束后不会恢复常驻或循环扩散框。
- 无资源增删；core 仍为 137 张图片 + 3 个音频、共 140 个 Loader 项与约 `12.38MiB`，图片 / GIF 仍为 `209` 个。

## 验证

- `npm.cmd run build` 与独立 TypeScript 检查通过，`git diff --check` 无错误。
- `http://127.0.0.1:5180/` 返回 HTTP `200`；浏览器在教学关与正式关各观察超过一个完整四拍周期，确认没有常驻紫色外框或循环扩散框，池塘 / 粉紫环境切换正常。
- 浏览器控制台为 `0 error / 0 warning`；源码读回确认 `physics.world.setBounds(ARENA...)` 仍使用原坐标。

## 遗留

如果后续希望正确输入、Fever 或连续四拍的瞬时边框反馈也全部取消，需要另行确认；本轮保留这些短效。
