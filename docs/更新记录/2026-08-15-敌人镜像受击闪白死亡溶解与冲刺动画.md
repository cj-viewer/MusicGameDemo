# 2026-08-15：敌人镜像、攻击特效、受击闪白、死亡溶解与冲刺动画

## 需求

- 所有敌人改变朝向时同步左右镜像本体；轻重攻击特效也按相同朝向镜像。
- 保安补充 Light 攻击特效，粉丝保留 Hard 攻击特效。
- 玩家和敌人受击时用纯白填充闪烁。
- 玩家死亡时播放正式死亡动画，其他图层以溶解方式退到纯黑背景。
- 冲刺使用 Dash 动画至位移结束后 `0.1s`，拖影采样间隔改为 `0.03s`。

## 实现

- `Enemy` 统一提供朝向镜像方法；保安、粉丝和保留代码中的中型保安均从当前移动 / 攻击角更新 `flipX`。攻击特效与本体共享朝向，FPV 观察窗复制主场景敌人的镜像状态。
- 新增保安 Light 攻击特效帧表和 `500ms` 场景时钟播放器；粉丝 Light / Hard 资源路径从连字符目录修正为素材实际使用的下划线目录。独立特效不调用 Phaser Animation `.play()`。
- Phaser 4 受击闪白改为 `setTint(0xffffff) + TintModes.FILL`，玩家保持 `140ms`、敌人保持 `120ms`，结束后恢复 `TintModes.MULTIPLY`。
- 死亡动画总时长固定为 `800ms`。玩家提升至死亡表现层；其余场景由打乱顺序的 `28px` 块状遮罩在 `820ms` 内溶解，FPV 同步淡出，最终只保留死亡角色和黑色背景。
- 冲刺移动仍为 `140ms`，Dash 动画与动作锁持续 `240ms`；拖影每 `30ms` 采样，并继续复制当前 Dash 帧。

## 验证

- `npm.cmd run build` 通过 TypeScript 检查与 Vite 生产构建。
- 浏览器实机确认敌人位于玩家左右两侧时，本体与对应 Light / Hard 特效同步反向；FPV 读取相同 `flipX`。
- 浏览器实机确认玩家和敌人受击期间进入纯白 Fill 模式，计时结束后恢复正常，控制台无 error / warning。
- 浏览器实机确认冲刺 `60ms` 时处于 Dash 且已有两道残影，`170ms` 时位移结束但仍保持 Dash，`270ms` 时回到 Run 且残影销毁。
- 浏览器实机确认致死后播放死亡动画，FPV 与其他图层溶解退为纯黑，死亡角色和失败提示保留在最上层。
