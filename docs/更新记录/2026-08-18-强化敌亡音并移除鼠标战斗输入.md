# 2026-08-18：强化敌亡音并移除鼠标战斗输入

## 需求

- 让敌人死亡音效在战斗中更容易辨认。
- 删除鼠标战斗控制，只保留键盘轻重攻击。

## 实现

- 敌亡音由单层下行三角波改为三层合成：短促高频破裂提示、中频锯齿下坠和低频三角波落地；独立敌亡音倍率继续限制在 `0–100%`。
- 删除 MainScene 的全局鼠标按下战斗监听与右键菜单屏蔽；鼠标左 / 右键不再提交轻 / 重攻击，也不能操作教学完成选择。
- 教学操作卡删除“左键 / 右键”字样，改为只显示 `Quote / Enter`。Esc 音量面板和 P 调参面板的鼠标按钮、滑杆交互继续保留。
- 手柄映射不在本次“删除鼠标”范围内，保持 `LB / RB` 规则不变。

## 影响

- 浏览器右键菜单恢复正常；游戏战斗与教学选择可完整使用键盘完成。
- 标题页的开始按钮和设置类 UI 仍属于界面交互，不会提交战斗输入；标题页仍可直接按 `Space` 跳过片头进入教学。

## 验证

- `npm run build` 通过。
- 浏览器确认鼠标左 / 右键不再调用战斗输入，`Quote / Enter` 仍正常提交轻 / 重攻击；右键菜单未被阻止，Esc / P 面板仍分别保留 `19 / 18` 个可交互控件。
- 浏览器控制台无 Runtime exception，敌亡音三层均正常建立并播放。

## 遗留

- 无。
