# 2026-08-18：统一鼓点与任意拍起手连招

## 需求

- 背景不再区分轻 / 重鼓点；移除场景内普通攻击、命中和错误攻击音效。
- 两把武器改为独立四段连招，不再绑定全局小节内拍位。
- 顶部节奏条只在正式关连招判定中显示；错误时红闪、震动并隐藏。

## 实现

- `Conductor` 每拍调度同一枚旧荧光棒轻攻击音色（330→220Hz、90ms 方波）的短鼓点；其增益由 `0.12` 提至 `0.36`。原 `beat-light` / `beat-heavy` 素材保留为玩家连招正确输入时的轻 / 重“嘿”，播放起点分别裁至 `105 / 110ms`，保留峰值前短起声并继续裁短重声尾音。
- `ComboSystem` 以独立的 `comboActive / comboStep / expectedBeat` 追踪当前武器连招：踩中鼓点的轻攻击起手，荧光棒按 `L-L-L-H`、警棍按 `L-L-H-H` 继续；每一步必须在紧接下一拍后的 `200ms` 内完成，漏拍、错拍或错键都会退出。错拍和错键仍按 Poor 攻击结算，漏拍不生成攻击。
- 正式关顶部四段节奏条默认隐藏。正确起手时显示，恢复提交 `7aae97b` 的无底板四图标样式并由 `58%` 放大至 `116%`；后续正确步骤短闪，完成时隐藏，连招错误或漏拍时先红闪和横向震动再隐藏。底部 ComboMeter / 武器组同步由 `72%` 放大至 `144%`，中心不变。教学完成目标同步为连续三套完整连招。
- 已起手连招的第 2 / 3 / 4 步恢复原 `arenaBeatCues` 三框小节判定预告：原层级、`0.7x → 1x`、`2.4` 拍指数缩放和提前输入窗的半程位置均保留，并按下一步轻 / 重类型着色；非连招时不显示。
- 移除 `MainScene`、`Player`、`Enemy` 中的常规攻击、错误攻击、玩家受击、存活敌人受击、Combo、Fever、拾取和敌亡音效调用。运行时仅保留 BGM、背景鼓点和连招正确输入的轻 / 重“嘿”。

## 影响

- 节奏判定仍为 `132 BPM`、拍点前后 `0.2s`，`≤100ms` 为 Perfect、`100–200ms` 为 Good。
- ComboMeter、武器伤害、命中盒、弹幕与视觉表现不因本次改动改变；只有连招的起手与推进时机、漏拍处理、场地方框提示、顶部节奏条样式/可见性和常规战斗音频发生变化。

## 验证

- `npm run build` 通过。
- `git diff --check` 通过。
- 本地浏览器需验证：每拍背景鼓点一致；正确连招输入仅播放对应“嘿”；普通攻击、错误攻击、玩家 / 存活敌人受击无场景音效；正式条带按起手、完成、失败 / 漏拍三种状态正确显隐；连招起手后不输入下一拍，须在该拍后 `200ms` 红闪、抖动并隐藏，且第 2 / 3 / 4 拍均出现同款场地方框。

## 遗留

- Esc 面板保留既有攻击 / 受伤分类滑杆以兼容当前设置布局；由于对应的常规场景调用已移除，它们不再驱动普通攻击或存活受击声音。
- BGM 内部基础混音先由 `0.25` 降为 `0.0625`，随后翻倍至 `0.125`；Esc 的 BGM 滑杆显示值与范围不变。
