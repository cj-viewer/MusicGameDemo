# 2026-08-21 警棍弹反与波次二武器切换

## 目标

把警棍变成围绕敌方重拍弹幕进行反击的节奏武器，并用固定波次奖励替代随机掉落，让玩家只需围绕“看拍点、接弹、反击”这一条主循环做决策。

## 实现

- 清空 Wave 2 后固定永久获得并自动装备警棍；教学关不提前引入警棍。
- 正式战斗与波间可用鼠标滚轮在已拥有的荧光棒 / 警棍间循环切换，换武器会安全停止长按并中止旧连招。
- 警棍左键从直接扫击改为全圆扩张弹反；Perfect / Good / Poor 分别提供大、中、小弹反范围。
- 被触及的敌弹完整迁移到玩家弹幕与碰撞组，并按“玩家实时位置 → 子弹实时位置”径向飞出，而非倒转旧轨迹。
- 反击弹统一使用紫白定向胶囊、紫色转换冲击与“弹反 ×N”反馈；普通点弹与 Boss 特殊弹共用同一转换路径。
- 警棍四拍规则与代码统一为“弹反、弹反、重击按下、重击松开”，同时修复长按按下 / 漏松反馈的步骤下标。
- 普通保安不再随机掉落警棍，武器获取从随机注意点收束为 Wave 2 后的确定节奏节点。

## 验证

- `npm run build`：连续两次通过；`git diff --check` 通过。
- `http://127.0.0.1:5173/`：HTTP 200。
- 内置浏览器从标题、教学跳过、第一关入场实际推进到 Wave 2 清空，确认自动装备警棍与获取提示，全程控制台 `0 error / 0 warning`。
- 角色随后在 Wave 3 开始后死亡，因此滚轮切换与普通 / Boss 敌弹弹反仍列为人工验收项，不将构建通过代替玩法验收。
