# 2026-08-18：敌人死亡爆炸特效

## 需求

- 敌人被击败时，在死亡位置添加一次性爆炸特效。

## 实现

- `src/game/enemies.ts`：`Enemy.die()` 调用 `scene.spawnEnemyDeathExplosion()`。
- `src/scenes/MainScene.ts`：新增 `spawnEnemyDeathExplosion()`，使用 `__WHITE` 粒子发射器与冲击环：
  - 主爆炸粒子 54 颗，速度 `180–560 px/s`、寿命 `400–820ms`；
  - 高速火花 30 颗，速度 `320–760 px/s`、寿命 `220–430ms`；
  - 18 条放射状长条溅射，飞行距离 `90–190px`、长度 `28–58px`；
  - ADD 混合；
  - 保安 `0x52efff`，粉丝 `0xff7832`，并向金白过渡；
  - 双层冲击环，快波 `240ms`、主色慢波 `420ms`；
  - 发射器 `900ms` 后销毁。

## 影响

- 敌人死亡表现新增视觉反馈。
- 不新增运行时素材，不影响血量、掉落、波次、攻击、判定或音效。

## 验证

- `npm run build` 通过。

## 遗留

- 实机爆炸密度和颜色亮度仍可继续人工目视调优。
