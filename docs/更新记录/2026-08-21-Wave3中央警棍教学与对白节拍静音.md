# 2026-08-21 Wave 3 中央警棍教学与对白节拍静音

## 需求

- 第三波开始前在场地中央掉落警棍，暂停敌人生成，并用现有对白 UI 依次提示拾取、新节奏型和鼠标滚轮切换。
- 玩家关闭最后一句对白后才生成第三波。
- 教学与第一关的所有对白存在期间关闭节拍器声音。

## 实现

- Wave 2 清空后的原 `2s` 波间等待保留；等待结束后进入独立 `waveWeaponDialogue`，生成中央警棍但不创建 Wave 3 敌人队列。
- 复用玩家头顶圆润像素气泡显示三句指定台词。对白期间锁定战斗输入和拾取；关闭第三句后启动 Wave 3，玩家随后可走近拾取警棍。
- 正式关恢复本局永久武器库存：初始拥有荧光棒，拾取警棍后入库并自动装备；滚轮仅在正式战斗 / 波间循环已拥有武器。普通保安不再随机提前掉落警棍。
- 教学入场、教学能量、第一关入场和 Wave 3 武器对白统一临时把 `Conductor` 节拍 / 喊声通道设为 `0`，关闭气泡后恢复用户当前节拍音量；鼓点通过共享增益门即时静音，连提前约 `220ms` 排程的下一拍也不会漏进对白，BGM 保持不变。

## 影响

- 改变 Wave 2 到 Wave 3 的衔接、警棍获取时机、正式关滚轮输入和对白期间音频表现。
- 不改变敌人数、Wave 3 对答弹幕、武器伤害、节拍判定窗口或 BGM。

## 验证

- `npm run build`：通过 TypeScript 检查与 Vite production build。
- 待浏览器完整覆盖 Wave 2 清空、三句对白、节拍静音 / 恢复、中央拾取、滚轮切换与 Wave 3 延后生成。

## 遗留

- 无代码层遗留；完整长流程仍需实机听感验收。
