# 2026-08-21：警棍左键恢复成长型扇形近战

## 需求

- 警棍左键恢复近战攻击。
- 攻击应覆盖完整扇形，而不是只命中弧线。
- ComboMeter 增长时扩大角度，并小幅增加距离。

## 实现

- 左键攻击瞬间结算准星方向扇形，范围内所有敌人各受击一次；不再清除或弹反任何敌弹。
- P Menu 的轻击角度 / 距离作为满级上限。ComboMeter `0–5` 级时角度从 `50%` 线性成长至 `100%`，距离从 `88%` 成长至 `100%`；Fever 使用满级范围。
- 错拍轻击使用当前等级结果的 `70%` 角度和 `50%` 距离；视觉改为短时浅紫填充扇形。

## 影响

- `src/scenes/MainScene.ts`
- 根 README、简化玩法策划案与实机落地记录。

## 验证

- `npm run build` 已通过 TypeScript 与 Vite production build；差异格式和本地服务检查见本轮交付。

## 遗留

- P Menu 当前显示角度 / 距离代表满 ComboMeter 上限；后续如需更直观，可再给面板补充“当前实效范围”只读值。
