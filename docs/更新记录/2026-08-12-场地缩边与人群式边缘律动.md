# 2026-08-12：场地缩边与人群式边缘律动

## 需求

- 缩小战斗场地，在左、右、下三侧各留出约一个角色高度的边缘律动区。
- 律动条在轻拍前小幅压缩、拍点跳动；重拍前大幅压缩、拍点大跳。
- 所有边缘律动条保持竖直，沿屏幕边缘像草丛 / 人群一样随机放置并允许重叠。

## 实现

- 画布保持 `1280 x 720px`，战斗区改为 `x=94, y=12, 1092 x 614px`，左、右、下各内缩 `82px`。
- 左、右各生成 42 根、下侧生成 76 根随机紫粉竖条，共 160 根；随机宽高、位置、颜色、透明度及层次，允许互相覆盖。
- 每拍前 `0.42拍` 开始压缩：轻拍目标 `0.82x`，重拍目标 `0.52x`；拍点分别跳到约 `1.3x / 1.85x`，并加入少量个体延迟与跳高差异。
- 下侧静态高度限制为 `18–46px`，确保重拍放大后仍基本位于预留边缘带内。

## 影响

- 玩家、敌人、碰撞、出生点、Fever 边框与玩家弹丸越界范围随战斗区一起缩小。
- 顶部不放置律动条，继续保留 HP、波次和音量入口的清晰空间。
- 不修改 BPM、攻击窗口、武器节拍或敌人数量。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地浏览器确认战斗区和三侧边缘带分离，竖条随机重叠，轻重拍存在不同压缩和跳动幅度。
- 浏览器控制台无 error / warn。

## 遗留

- 随机布局会在每次刷新或重开时重新生成；后续如需完全一致的舞台构图，可改为固定随机种子。
