# 2026-08-17：第一关粉紫音乐广场分层重组

## 需求

在 GitHub 最新 `dev-1.0` 上，把无物件底图作为第一关基底，并把已拆出的 35 个透明物件放回参考图原位置，用实机画面检查拆分是否成功。

## 实现

- 从 `upstream/dev-1.0` 最新提交 `4802757` 建立独立预览分支 `codex/pink-stage-preview`，不覆盖原有两个脏工作区。
- 新增 `src/game/PinkStageEnvironment.ts`，集中维护底图、物件纹理键与 `1918 x 1081 → 1920 x 1080` 坐标映射。
- 第一关预加载并创建 1 张干净底图和 35 张透明物件 PNG；物件使用原黄框左上角和画布尺寸定位。
- 环境层使用静态 `Image`、深度 `-20 / -19`，不添加 Arcade Physics Body。

## 影响

- 教学开始后即可看到重组后的粉紫音乐广场；正式战斗继续复用同一环境。
- 不改变节拍、输入、角色、敌人、弹幕、掉落、HUD、FPV 或碰撞规则。
- 新增 36 张运行时图片，公开发布前仍需由项目方完成权属复核。

## 验证

- `npm.cmd ci`：成功；依赖审计报告 1 个既有 high severity vulnerability，本次未自动升级依赖。
- `npm.cmd run build`：通过 TypeScript 检查与 Vite 生产构建。
- 浏览器实机：36 张 `pink-stage` 图片全部进入页面资源清单；第一关重组画面可见，控制台无 error / warn。

## 遗留

- 当前是视觉试装。若正式采用，可根据试玩反馈微调个别物件坐标、环境遮挡深度或碰撞范围。
