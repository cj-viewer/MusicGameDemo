# 2026-08-14：玩家武器握把旋转轴与中线镜像

## 需求

- 将武器旋转锚点移动到截图红点，即握把末端。
- 朝向另一侧时，整把武器必须关于角色中线对称。
- 当前及后续所有玩家武器统一遵守。

## 实现

- 荧光棒透明内容边界为 `x=28–101, y=26–98`，旋转原点改为 `(101/128, 98/128)`。
- 警棍透明内容边界为 `x=2–123, y=0–121`，旋转原点改为 `(123/128, 121/128)`。
- 两把武器的世界旋转轴统一固定在角色腰部中线：`x=player.x`、`y=player.y+22.5px`。
- 删除按朝向分别添加的水平位置偏移；左右切换只执行贴图水平翻转，轻 / 重挥击角同步反号。

## 影响

- 玩家荧光棒、警棍的静止持有位置和 `200ms` 轻重挥击轨迹受影响。
- 攻击方向、弹幕出生点、伤害、判定、武器尺寸与层级不变。

## 验证

- `npm.cmd run build` 通过 TypeScript 检查与 Vite 生产构建。
- 两把武器均复用同一“握把末端 Origin + 腰部中线世界轴 + 水平翻转”路径。
- 本次未创建提交、未推送远端。
