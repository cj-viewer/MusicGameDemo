# 2026-08-16：角色跟拍律动

## 需求

让玩家与所有敌人像场边律动条一样跟随“轻轻轻重”节拍运动，但幅度保持克制、可辨识。

## 实现

- `MainScene` 在每个整数拍将当前轻 / 重拍类型传给玩家和全部存活敌人。
- 玩家、保安、粉丝和预留中型保安的本体 Sprite 在轻拍瞬间变为基础显示倍率的 `1.035x`，于 `170ms` 内以 `Back.easeOut` 回弹；重拍对应 `1.075x / 220ms`。
- 律动只改显示对象的缩放；Arcade 物理体、武器、攻击特效、FPV 投影、移速和 Dash 位移均不参与缩放。

## 影响

- 角色会在“轻轻轻重”中提供统一、轻微的节奏反馈，重拍比轻拍更明显。
- 攻击、受击、闪避和敌人移动的玩法判定保持不变。

## 验证

- `npm run build` 通过。
- 本地运行时确认教学中的玩家与正式关中的玩家、保安、粉丝均有轻 / 重拍脉冲，且碰撞、朝向、攻击、Dash 和 FPV 不跳变。

## 遗留

- 如果实机观感仍偏强或偏弱，只需调整角色脉冲的两个倍率，不需要修改律动条参数。
