# 2026-08-21 双武器四拍乐句与波次对答

## 目标

把玩家的火力、弹反、蓄力、敌方发射和高潮反馈组织进同一个四拍句子，减少同时追踪多套计时器的负担；教学关保持不变。

## 玩家可见变化

- 荧光棒第 1–3 拍连续积累火力，第 4 拍重击统一放大；完整蓄势的贯屏攻击追加两束窄角支援光。
- 警棍第 1、2 拍用跟随准星的紫色扇形弧面捕获敌弹，第 3 拍蓄力，第 4 拍把累计成果集中为一道扩大月牙。
- Wave 3 改成第 1、2 拍敌方提问、第 3、4 拍玩家回应的对答节奏；后续波次允许切分预警，但来弹抵近仍对齐整数主拍。
- 单弹反仅显示局部紫色冲击，多弹反显示计数；完整 Pattern 与波次清空才使用全场大反馈。
- 鼠标滚轮仍由玩家主动选择武器风格，不存在要求见到特定敌人就强制切换的硬克制。

## 工程实现

- `MainScene` 新增双武器乐句状态、警棍捕获池和蓄力弧；移除逐弹阵营迁移的反击胶囊路径，并停止执行警棍长按连射。
- 敌人攻击调度为 Wave 3 限制主拍攻击者；Wave 4 起使用局部弧线预警，并为节奏锁定弹写入固定速度，避免逐帧调参覆盖其到达时机。
- 开新波次、错漏拍和换武器会清理对应乐句状态，避免跨句保留收益。
