# 2026-08-13：双 16:9 等大俯视 / FPV 视口

## 需求

- 将右下角 FPV 小窗扩大到与现有俯视主视口相同尺寸。
- 两个视角都保持 `16:9`，不能因放大而拉伸。

## 实现

- 组合逻辑画布改为横向 `2560 x 720`，左、右分别承载 `1280 x 720` 的俯视主视口和 FPV 视口。
- 主场景相机固定在左半区；FPV 独立 Scene 相机固定在右半区，针孔投影焦距随 `1280px` 宽度重新计算，地平线、地面线、边框、标签、方位角、准星与拍相环同步适配。
- 新增 `src/game/viewLayout.ts` 作为双视口尺寸的唯一事实源。
- FPV 继续只读：右侧点击不触发标题或攻击，鼠标移入右侧不改变主场景最后有效瞄准角；右摇杆继续正常控制瞄准。

## 影响

- 浏览器继续使用 `Phaser.Scale.FIT`，因此两个子视口均等比显示。组合画布为 `32:9`，在普通 `16:9` 屏幕上会出现上下黑边，这是同时展示两个完整 `16:9` 画面的正常留白。
- 左侧战斗区、物理世界、HUD、节拍、弹幕、美术替换背景和现有玩法参数不变。
- Esc 设置中的 FPV 开关继续控制整个右侧视口。

## 验证

- `npm.cmd run build`：通过 TypeScript 检查和 Vite 生产构建。
- Codex 内置浏览器：教学阶段左右视口等大且均为 `16:9`；FPV 大画面的边框、地平线、准星、方位角和拍相环正常显示。
- `R` 回到标题后点击右侧，游戏未开始；控制台无 error / warn。

## 遗留

- 当前组合画布固定为横向双联；如需针对竖屏设备改成上下排列，应另行定义响应式布局规则。
