# 2026-08-14：恢复三拍提前框与重拍先快后慢淡入

## 需求

- 节拍缩放框提前出现并降低移动速率，恢复原来的三拍预告。
- 橙色框和粉色框使用相同的初始不透明度。
- 橙色框的不透明度按先快后慢的速率变化。

## 实现

- 同时预告未来 `1 / 2 / 3` 拍，每个方框用三拍从 `0.7x` 扩大到场地边界。
- 轻重框初始透明度统一为 `0`。
- 粉色框保持 `Expo.In` 淡入；橙色框改为 `Cubic.Out` 淡入，前段快速显现、后段逐渐放缓。
- 外侧律动条继续使用橙框的实时透明度作为转橙进度。

## 影响

- 每个节拍框有更长的移动时间，更早进入视野。
- 轻重框不再依靠不同初始透明度区分，重拍由独立的先快后慢淡入曲线强化辨识。
- 会重新出现最多三个预告框同时显示的状态。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 浏览器实机确认三个方框提前出现、移动变慢，橙框前段显现更快。
- 浏览器控制台无 error / warning。

## 遗留

- 需要继续观察三框同屏时的视觉密度。
