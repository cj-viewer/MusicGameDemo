# 2026-08-12：三倍主音量与 Alt 滑块

## 需求

- 将游戏默认音量提高到原来的 3 倍。
- 增加可调音量滑块，按 `Alt` 时呼出鼠标并进行调整。

## 实现

- 默认主音量设为 `300%`，滑块范围为 `0–300%`。
- 右上角增加 `ALT 音量` 提示；`Alt` 打开或关闭面板，`Esc` 关闭面板。
- 打开面板时释放指针锁定，面板内鼠标操作不触发攻击。
- BGM、节拍叫喊继续保留现有基础混音值；程序合成音效改接 Phaser 音频总线，使全部声音统一受主音量控制。

## 影响

- 初次进入时整体输出响度为旧默认的 3 倍，可能更容易触及设备或浏览器输出限幅。
- 只改变统一输出增益与交互入口，不修改 BPM、素材、轻重拍比例、判定窗口或武器规则。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地浏览器实机确认 `Alt` 打开面板时显示 `300%`，点击滑轨中点后显示 `150%`，`Esc` 可关闭。
- 浏览器控制台无 error / warn。

## 遗留

- 当前音量只在本次运行内生效，刷新页面后恢复默认 `300%`；如需记忆玩家设置，可后续接入本地存储。
