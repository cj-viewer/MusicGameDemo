# 2026-08-20：警棍长按连射、按松判定与四拍 UI

## 需求

- 警棍重击支持长按，保持期间持续发射当前弧形光波，发射频率可在 P Menu 调节。
- 四拍改为轻击、重击按下、重击松开、轻击，并分别判定按下与松开时机。
- 四拍 UI 提供按下、持续按住和松开反馈。

## 实现

- `ComboSystem` 为警棍第三拍增加重击松开阶段；第二拍按下和第三拍松开各自进入原 Perfect / Good / Miss 时间窗。
- MainScene 维护警棍物理按住状态，以可暂停的 Scene Clock 计时器按频率持续发波，鼠标右键、Enter 与手柄按键均支持按下 / 松开。
- 正式四拍条中间两格加入按下 / 松开标记和长按进度条，分别显示按下评价、持续状态和松开评价。
- P Menu“速度 / 频率”页新增警棍长按发波频率，默认 `4.0 次/秒`、范围 `0.5–20.0`、步进 `0.5`，同步保存与 TXT 导出。

## 影响

- 荧光棒 Pattern 与攻击方式不变。
- 警棍连续发波沿用按下评价，但不重复增加 ComboMeter；松开事件不额外生成攻击。
- 未新增运行时素材。

## 验证

- `npm run build` 通过。
- 按快速迭代要求未进入关卡试玩。

## 遗留

- 无。
