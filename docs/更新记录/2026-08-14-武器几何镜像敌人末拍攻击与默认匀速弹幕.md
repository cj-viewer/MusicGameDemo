# 2026-08-14：武器几何镜像、敌人末拍攻击与默认匀速弹幕

## 需求

- 修正玩家武器左右没有真正关于角色中线对称的问题。
- 所有敌人在每个小节最后一拍攻击。
- 敌方弹幕默认匀速运动。

## 根因与实现

- Phaser `flipX` 翻转的是纹理 UV；对非中心 Origin，素材中的握把端点会换到 Origin 的另一侧，所以可见武器不是围绕握把世界轴做几何镜像。
- 武器改为始终 `flipX=false`，另一朝向使用负 `scaleX`，从而围绕握把 Origin 镜像几何；轻 / 重挥击角同步反号。荧光棒和警棍共用该规则。
- SmallGuard、FanEnemy、MidGuard 的攻击条件统一改为 `beatInMeasure === 3`，即每小节第 4 拍。
- `enemyBulletBeatSurgeEnabled` 默认值改为 `false`，新生弹幕的 `bursting` 初值同步读取该开关；敌弹默认从出生首帧起按 `144 px/s` 匀速。P 面板仍可手动开启旧节拍突进。

## 影响

- 玩家两把正式武器的左右持有布局和挥击轨迹。
- 所有现有敌人的攻击拍位，以及敌弹首次进入游戏和重开后的默认运动方式。
- 攻击角、弹幕伤害、弹速数值、命中盒、敌人移动速度与 P 面板手动开关能力不变。

## 验证

- `npm.cmd run build` 通过 TypeScript 检查与 Vite 生产构建。
- 三类敌人的 `onBeat()` 均在 `beatInMeasure !== 3` 时返回。
- 武器更新路径读回为 `setFlipX(false)` 与左右 `±PLAYER_WEAPON_SCALE`。
