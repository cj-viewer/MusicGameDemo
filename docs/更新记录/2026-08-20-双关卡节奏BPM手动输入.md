# 2026-08-20：双关卡节奏 BPM 手动输入

## 需求

为教学关和第一关分别提供可手动输入的节奏 BPM，降低歌曲与判定节拍的对齐难度。

## 实现

- P Menu“量表 / Fever”页新增教学关与第一关 BPM，默认均为 `132`，范围 `40–240`。
- `− / +` 每次微调 `0.1 BPM`；点击蓝色数值可直接用键盘输入整数或小数。
- 每关 BPM 同时控制 Conductor 判定节拍和 BGM 播放速度；关闭 P Menu 后立即按当前拍号相位重新对齐。
- 两个数值进入浏览器本机保存，并写入 TXT 的 `[bgm]` 段；旧配置自动使用默认值。

## 影响

教学关和第一关现在可以独立校准。正式关原有 `-500–500ms` 首拍偏移继续保留，可与 BPM 组合使用。

## 验证

`npm run build` 通过。按快速迭代要求未进行关卡试玩。

## 遗留

无。
