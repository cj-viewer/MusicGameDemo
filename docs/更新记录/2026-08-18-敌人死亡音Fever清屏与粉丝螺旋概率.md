# 2026-08-18：敌人死亡音、Fever 清屏与粉丝螺旋概率

## 需求

- 敌人死亡时播放死亡音，并在 `P` 面板调整其音量。
- Fever Time 满格时不再触发玩家三方向攻击，改为带表现的全敌弹清屏，不销毁玩家弹幕。
- 粉丝三向螺旋弹幕不再每次必定触发，默认概率 `10%`，并加入 `P` 面板。

## 实现

- `Sfx.enemyDie()` 新增独立音量倍率参数；致死命中立即播放，不再排队普通 `enemyHurt`。`P` 面板默认 `100%`，范围 `0–200%`、步进 `10%`。
- Fever 激活时清理 `bullets` 敌弹组，不遍历 `playerBullets`。视觉包含全屏 ADD 闪光、双层扩散环与最多 96 个敌弹消散火花，全部对象在 `420ms` 内销毁。
- 玩家 Fever 攻击删除 `±120°` 两个追加方向，只保留当前瞄准方向；既有正确输入 Fever 音波、回血和持续时间规则不变。
- 粉丝每次攻击以 `fanSpiralAttackChance` 独立掷骰。命中概率时保持 `3 弧 × 10 点`；未命中时回退为量化基准方向单发。`P` 面板默认 `10%`，范围 `0–100%`、步进 `5%`。

## 影响

本轮不新增运行时素材；死亡音继续使用 WebAudio 合成并经过现有主音量与“受伤与敌亡”分类。保安攻击、粉丝攻击频率、单弹伤害 / 速度 / 寿命、玩家弹数与 Fever 正确输入音波不变。

## 验证

- `npm run build` 通过 TypeScript 检查与 Vite 生产构建。
- 本地浏览器验收 `P` 面板默认值与上下限；验证致死音、Fever 清敌弹不清玩家弹、粉丝螺旋 `0% / 100%` 边界，并检查控制台。
