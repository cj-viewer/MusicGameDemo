# 2026-08-20：教学结束动画与第一关衔接

## 需求

- 教学关结束后播放用户提供的新动画。
- 动画可按 `Space` 跳过，播放完或跳过后进入第一关。

## 实现

- 源视频转为 `public/assets/video/tutorial-complete.mp4`，使用 H.264 + AAC、`1920 x 1080 / 60fps`、CRF `23` 与 `+faststart`，体积由约 `9.53MB` 降到 `1,536,158` 字节。
- 视频在教学进行期间与正式关 BGM 一同后台加载，不阻塞进入教学。
- 教学完成确认或教学中按 `Space` 后进入全屏过场状态；停止教学 BGM，隐藏教学 UI / HUD / FPV，只保留右下“空格跳过”提示。
- 视频完成、播放错误或按 `Space` 后，统一初始化第一关场景、HUD、BGM 与倒计。

## 影响

- 原教学进度、连招判定和重练分支不变。
- 原本“教学结束立即进入第一关”改为“教学结束 → 过场动画 → 第一关”。

## 验证

- `ffprobe` 核对通过：时长 `4.017007s`、H.264 + AAC、`1920 x 1080 / 60fps`。
- `npm run build` 通过。
- 按快速迭代要求未完整试玩流程。

## 遗留

- 未做主观观感调整；视频声音与第一关 BGM 衔接可在后续试玩时微调。
