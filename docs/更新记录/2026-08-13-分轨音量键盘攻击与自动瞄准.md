# 2026-08-13 / 分轨音量、键盘攻击与自动瞄准

- 设置面板新增 BGM 与音效两个独立滑杆：BGM / 音效默认 `100%`、范围 `0–200%`，主音量仍为默认 `150%`、范围 `0–300%`。
- 音效滑杆统一控制轻重节拍采样以及攻击、命中、错误、受伤、拾取、Combo、Fever 等程序合成反馈；所有声音仍受主音量控制。
- 取消鼠标移动瞄准；双引号所在的物理 `Quote` 键为轻攻击，`Enter` 为重攻击，左、右 `Shift` 都可立即沿当前移动方向闪避；`;` 不承担战斗输入。
- 自动瞄准选择加权距离最低的存活敌人：最后移动方向前方总角度 `45°` 内目标的有效距离减半，其余目标使用实际距离；没有敌人时保持最后移动方向。
- 玩家朝向、手持武器、攻击方向和右下 FPV 观察方向统一使用自动锁定结果；右摇杆不再控制瞄准。
- 验证：`npm.cmd run build` 已通过；待本地浏览器确认设置滑杆、键位与自动锁敌的实机手感。
