# 2026-08-10：角色动画校准与玩家静态图恢复

## 需求

- 玩家恢复原来的静态角色图，不使用粉丝序列帧。
- 新粉丝动画与旧粉丝静态图的实际可见角色占比保持一致；同一动作内帧高统一，不同动作只做小幅自然差异，避免切换突变。
- 粉丝受击继续使用翻滚。

## 实现

- 读取 Git 基线中的旧 `fan.png` 作为视觉基准：旧图画布 `288 × 402px`，可见内容 `279 × 386px`；旧显示尺寸 `48 × 76px` 下，可见角色约为 `46.5 × 73px`。
- 新帧逐一按透明内容裁切并最近邻缩放：跑步 `445px`、翻滚 `415px`、近战 `500px` 内容高度；宽度保持等比变化。
- 引擎以跑步约 `73px` 可见高度为缩放基准，翻滚约 `68px`、近战约 `82px`。三种状态与旧粉丝占比接近，翻滚和近战只保留适度的姿态差异。
- `Player` 恢复加载 `images/characters/player.png`，保留原来的 `54 × 82px` 静态显示、闪避拖尾、受击闪白与武器挥动逻辑。
- `FanEnemy` 继续使用 Sprite：慢行跑步、拍前突进/受击翻滚、攻击近战，并通过 `setFlipX` 处理左向。

## 验证

- 已校验跑步 4 帧均为 `445px` 高、翻滚 6 帧均为 `415px` 高、近战 6 帧均为 `500px` 高。
- `npm.cmd run build` 已通过 TypeScript 检查与 Vite 生产构建。
- 已在 Codex 内置浏览器启动本地试玩：中心角色恢复为原粉色静态玩家，粉丝小怪仍使用新序列帧，控制台无运行时 error。

## 遗留

- 后续替换粉丝或玩家素材时，必须重新按《资源与素材规范》测量旧视觉基准和每一帧透明内容，不能复用本次数值。
