# 2026-08-17：教学连段 UI 与池塘背景替换

## 需求

- 将教学关旧深色程序化连段面板替换为项目方提供的透明成品 UI，保持原图标题、框线、字形和四格设计。
- 使用项目方桌面 `111.png` 定版第一关背景，并覆盖现有教学池塘运行路径。
- 不改变教学判定、校准、`Space` 跳过、完成选择或正式关紧凑连段 UI。

## 实现

- 新增 `public/assets/images/ui/tutorial/tutorial-pattern-panel.png`。源图为 `578 x 278` RGBA；运行时显示为 `366 x 176px`，中心 `(284, 211)`、左上角 `(101, 123)`。
- 教学当前拍与正确命中反馈从同一张 UI 图裁剪对应四拍格，并以 ADD 在 `150 / 220ms` 内淡出；不再叠加旧深色矩形、程序标题、轻重标签、三小节进度、延迟数值或 `SPACE` 提示。
- 以 `111.png` 的 `1920 x 1080` 内容覆盖 `public/assets/images/backgrounds/pond-stage/pond-stage-background.png`；保留原运行时路径、纹理键、depth 与无碰撞规则，不提交重复背景副本。
- 教学 UI 进入 `assetManifest.ts` 的 core 清单。精确展开后当前为 137 张图片、两条节拍音效与教学 BGM，共 140 个 Loader 项、`12,977,685` 字节（约 `12.38MiB`）；环境运行资源仍为 37 张，UI 独立为 1 张。

## 影响

- 教学关连段提示改为左上成品美术面板，背景切换为项目方 `111.png` 定版池塘图。
- 连续三小节判定、延迟采样与校准、`Space` 跳过、轻攻击进入 / 重攻击重练均保持原逻辑；只是进度、延迟和跳过说明不再额外显示。
- 正式关 `320 x 64px` compact pattern、左下操作卡、正式关背景与物件回弹均不变。
- 当前图片 / GIF 总数为 `209`：角色 151、武器 8、背景 14、环境物件 35、UI 1。
