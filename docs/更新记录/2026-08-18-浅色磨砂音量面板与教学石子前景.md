# 2026-08-18：浅色磨砂音量面板与教学石子前景

## 需求

- Esc 音量面板不能再靠深色遮罩提高可读性，要保留明亮、半透明的真实磨砂质感。
- 修正面板中文字的字形与显示清晰度。
- 第一关底部石子必须绘制在 Photoshop 静态状态条上方，第二关不得残留。

## 实现

- 打开 Esc 时先暂停场景，抓取面板后方 `900 x 975px` 的当前帧，并在 Canvas 上应用 `blur(14px) saturate(82%) brightness(106%)`；其上只叠 `#f2f0e8 / 0.18` 浅色雾面与白色 Alpha `0.10 → 0.035` 的轻渐变，不再使用全屏暗罩、深色隐私底或深灰实色板。
- 面板中文改用 Microsoft YaHei UI / Microsoft YaHei 优先的 CJK 字体栈，并以 Text `resolution=2` 渲染。八路标签固定为“主音量、BGM、节拍喊声、攻击与错误、受伤与敌亡、Combo 提示、Fever 音效、拾取音效”。
- 从当前 `bg1.psd` 的可见 `Rock` 组导出 `tutorial-bottom-rocks.png`，规格为 `1704 x 112` RGBA，运行时放在 `(89,877)`。教学容器内的顺序为“进度面板 → 静态底栏 → 石子前景 → 操作卡”，因此石子自然遮住底栏对应区域。
- 教学底图只在 Rock 边界框替换为无石子环境，避免前景重复；拆分脚本为 `scripts/rebuild_tutorial_bottom_rocks.py`。无石子底图与独立石子重组后，逐通道最大误差为 `1`、全画面平均误差为 `0.000383` 个 8-bit 色阶。
- 石子没有物理体，随教学容器一起重建或销毁；进入正式关后不显示。音量分类、滑块热区、暂停与 Esc 关闭逻辑均未改变。

## 资源口径

- 当前 core 清单为 `147` 个 Loader 项：`144` 张图片、两条节拍音效与教学 BGM。
- 教学 UI 从 7 张增至 8 张；37 张环境运行资源的统计口径不变。
- `queueCoreAssets()` 当前文件合计 `13,069,079` 字节（约 `12.46MiB`）。
- 当前 `bg1.psd` SHA-256 为 `D4748A87419E2D04FC83015CE5CA5750D95754802942CF39FE599903CDD20B60`；制作源不进入浏览器加载清单。

## 验证

- `npm run build` 通过，TypeScript 检查与 `git diff --check` 通过。
- 第一关实机确认：面板为浅色真实磨砂，背景保持明亮且文字无错字、乱码、重影或裁切；石子覆盖静态底栏两端且没有重复暗边。
- 按 Space 进入第二关后，教学石子前景不残留；第二关 Esc 面板仍能抓取当前粉紫场景并保持浅色磨砂。
- 重新开始后，磨砂捕获纹理和教学前景可重新创建，没有旧纹理键冲突。
- `tutorial-bottom-rocks.png` 本地资源请求返回 HTTP 200，文件大小为 `58,158` 字节。
