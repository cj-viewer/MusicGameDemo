# 2026-08-17：敌我攻击改为柔和自发光

## 需求

敌方攻击改为点状自发光，主角攻击改为线性自发光；泛光需柔和且明亮，避免白描边、宽底线和硬边发光层造成的图层堆叠感。最终按参考任务恢复主角直射的可见尺寸，但不得改变攻击判定、速度、寿命或运动尾迹参数。

## 实现

- 从本地任务“点/线特效自发光”对应目录 `D:\MusicGameDemo-dev-1.0` 迁移攻击自发光配色、合成与玩家直射视觉比例；不复制其中的攻击判定、射程、寿命或其他玩法调整。
- 玩家 / 敌人的短时攻击 PNG 使用单一 ADD Sprite、填充 Tint、Glow 与 Threshold→Blur→ADD Bloom；玩家 Light / Hard 为 `#fff36b / #f28cff`，保安 / 粉丝为 `#52efff / #ff543d`。
- 根据前两轮实机反馈，荧光棒亮芯曾被加长为至少判定段 `3.2x`、减薄至原弹体 `20%`；该中间方案随后因明显过长，被最终源任务比例取代。
- 根据第三轮起点反馈，测得荧光棒源图发光帽外沿的连续中心约为 `(29.5, 27.5)`。运行时按武器当前世界位置、非中心 Origin、正负 `scaleX` 与挥击角计算该点；原长度物理判定段从该点沿弹道前置后开始，最终短亮芯与外晕按源任务方式中心锚定在该判定段上。
- 根据第四轮截图复核，确认错位红圈并非长线亮芯，而是旧踩拍双环与白色方向楔形仍从角色侧边 `attackOrigin` 生成。荧光棒分支现已移除这两种局部几何叠层；音符反馈改从实时发光端附近生成，长线本体继续从同一点发射。警棍原有局部冲击环不变。
- 根据第五轮参考图与旧版 `5181` 实机对比，当前版先读取实时发光端，再让每条弹道沿自身方向前移 `worldSize(24)=28.8px`，作为原长度判定段的起点。此前将亮芯尾端也放在该点是中间方案；最终短亮芯与胶囊外晕和源任务一致，改为以判定段中心为锚。
- 根据最终“不要这么长，按原任务做”的反馈，玩家直射恢复源任务比例：亮芯长度 / 厚度为判定段与原弹体的 `1.35x / 0.52x`，连续胶囊外晕为 `1.95x / 3.2x`，删除 `min(76)` 下限。普通芯仍为 `66%` 近白 / `0.94` Alpha，正确芯为纯白 / `0.96` Alpha，原色外晕为 `0.74` Alpha。敌弹点大小和警棍弧长 / 线宽不变。
- 警棍原有的宽白色晕光底层由连续 Bloom 取代；玩家 / 敌弹既有速度 Trail 的长度、粗细、生成频率和寿命不变，仅将其合成方式改为 ADD。
- 敌弹继续由透明物理宿主维护速度、来源、伤害、寿命与判定，点状视觉只跟随位置并在宿主销毁时同步销毁。

## 影响

本次改变攻击视觉，并让荧光棒物理判定段继续从武器发光端前方内部 `28.8px` 起射，同时清除会伪装成错误起点的旧圆环 / 楔形叠层。玩家直射可见亮芯 / 外晕恢复为源任务尺寸；角色 / 敌人攻击 PNG、敌弹点大小、Trail 参数、弹速、伤害、寿命、判定盒数量 / 尺寸 / 覆盖长度、击退、ComboMeter 弹数、Fever 三向攻击、节拍和调参功能均保持不变。

## 验证

- `npm.cmd run build` 通过。
- 在当前 `http://127.0.0.1:5180/` 与源任务 `http://127.0.0.1:5181/` 使用同一轻攻击输入实机对照：当前白芯已从约 `97 × 2px` 的超长细线恢复为源版约 `41 × 4px`，柔光外晕约 `59 × 26px`，观感与参考任务一致，且未再出现旧红色圆环 / 白色楔形。
- 当前 WebGL 页面与首页均可正常访问（HTTP `200`）；控制台只有 Vite / Phaser 启动信息，无 error / warning。

## 遗留

正式关高密度波次需继续观察对象级 Glow 的性能；若后续出现明显帧率下降，应改为共享发光纹理或批量渲染，但不得恢复多层硬边图形。
