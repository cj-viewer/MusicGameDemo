# 2026-08-12：边缘律动数量、角色比例与饱和度

## 需求

- 适当减少边缘律动条。
- 让单条大小接近场内角色。
- 高亮时不要降低过多饱和度。

## 实现

- 数量由 190 根减少为 140 根：左、右各 38 根，下侧 64 根。
- 宽度改为 `28–32px`；左右高度 `46–58px`，下侧高度 `42–50px`。
- 轻拍饱和度降幅由 `20%` 改为 `8%`，重拍由 `42%` 改为 `18%`。
- 下侧轻 / 重跳高限制为约 `1.16x / 1.4x`，避免放大后的角色级律动条侵入战斗区。

## 影响

- 边缘更透气，单条轮廓更像抽象人群单位。
- 高亮仍有明度差，但保留更多紫粉色，不再明显灰白。
- 不修改角色、场地、节拍、战斗数值或透明度规则。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地实机确认数量减少、条体接近角色大小、高亮紫粉色保留且下侧重拍基本不越界。
- 浏览器控制台无 error / warn。

## 遗留

- 随机布局仍可能出现局部聚集；若需更均匀的观众间距，可后续采用带抖动的分段采样，而不是继续减少总数。
