# 2026-08-12：律动侵入、色差限制与 TopDown 遮挡

## 需求

- 律动条无需避免侵入战斗区，只需没有碰撞盒。
- 宽度调整为上一版的 `0.8x`。
- 明度和饱和度变化区间均不超过 `5%`。
- 律动条和角色 Sprite 使用从上到下的 TopDown 遮挡关系。

## 实现

- 律动条宽度由 `28–32px` 调整为整数范围 `22–26px`。
- 下侧取消独立跳高限制，三侧轻 / 重拍统一约 `1.3x / 1.85x`；律动条保持普通 GameObject，不创建物理 Body 或碰撞器。
- 轻拍颜色变化为明度 `+3%`、饱和度 `-3%`；重拍为 `+5% / -5%`。
- 新增脚底 Y 深度排序。律动条使用底端 Y，玩家和敌人使用碰撞体脚底 Y；所属武器、瞄准反馈和血条跟随角色深度。

## 影响

- 下侧律动条可在大跳时伸入战斗区并遮挡靠近下方的对象，但不会阻挡移动、弹幕或攻击。
- 角色、敌人和律动条的前后关系由画面位置决定，不再由玩家 / 敌人类型的固定 depth 决定。
- 高亮变化更小，仍保持完全不透明和深紫粉色。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地实机确认下侧重拍可视觉侵入、无碰撞接入；颜色变化克制，页面无 error / warn。

## 遗留

- 弹幕、Fever 特效和 HUD 仍使用各自功能层级，不参与角色与律动条的脚底排序。
