# 2026-08-17：粉紫音乐广场物件节拍回弹

## 需求

让正式关已经拆出的 35 个环境物件跟随场景轻 / 重拍一起振动，同时保持运行底图和无物件干净底图完全静止。

## 实现

- 35 个环境图片改用各自底边中点作为缩放锚点，初始显示位置不变。
- `MainScene` 在每个整数拍把当前武器序列的轻 / 重类型传给环境控制器。
- 轻拍以基础比例的 `1.003 x 1.01` 弹出，单程 `80ms`；重拍以 `1.006 x 1.022` 弹出，单程 `110ms`。
- 两类均使用 `Quad.easeOut` 和 yoyo 自动回位；每个新拍先清除旧补间并恢复基准比例，防止长时间运行后缩放漂移。

## 影响

- 只有正式关 35 个透明物件及其层内原始阴影参与回弹。
- `pink-stage-runtime-base.png` 与 `pink-stage-clean-background.png` 不进入补间目标，教学池塘底图也不触发这组动画。
- 不修改碰撞、判定、BGM、角色、敌人、HUD、FPV 或轻重拍规则。

## 验证

- `npm.cmd run build` 通过。
- 浏览器正式关连续采样 24 帧：物件区域随拍点产生逐帧变化，选取的纯底图区域在稳定阶段逐帧差为 `0`。
- 底部左右灌木以画布底边为锚点回弹，没有露出底边空缝；安检口内部、投影和原始色调保持完整。

## 遗留

当前 35 个物件严格同步回弹；若后续需要更自然的分组律动，可单独设计固定错相，但仍不能移动底图。
