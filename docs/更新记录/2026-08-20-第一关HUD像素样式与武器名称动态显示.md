# 2026-08-20：第一关 HUD 像素样式与武器名称动态显示

## 需求

第一关 / 池塘教学阶段的 HUD 需要严格贴合浅绿、深青描边、像素角标的参考风格；武器名称必须继续随当前装备变化，不能被样式改动写死。

## 实现

- 教学阶段的顶部连段面板、四张操作卡、ComboMeter / 武器状态条统一使用浅绿 / 青绿色底、深青像素边框和清晰文字；进入正式粉紫关时恢复粉紫像素皮肤。
- 顶部连段面板和四张操作卡不再直接显示旧透明细线 PNG，而是按当前连招与当前提示文本运行时绘制成厚描边、块面感更强的可爱像素 UI。
- HUD 只负责绘制皮肤和排版，数值、连招提示和武器名称仍由现有刷新函数提供。
- `glowsticks` 读取 `WeaponDef.name` 显示“荧光棒”，`baton` 显示“警棍”；切换装备后立即刷新，不复制一份静态文本。
- 初始 HP 文本不再放置固定占位值，等待 `setHp(hp, maxHp)` 用运行时数据填充。

## 影响

只改变面板颜色、像素边框、字体描边和阶段皮肤；不改变装备切换、攻击输入、判定、伤害、Combo、Fever、暂停、教学完成条件或反馈逻辑。

## 验证

`npm.cmd exec -- tsc --noEmit` 与 `npm.cmd run build` 通过；`git diff --check` 无错误。浏览器中需分别切换荧光棒与警棍，确认名称和连招提示来自当前装备并随切换更新。

## 遗留

无新增运行时资源；若后续调整像素框尺寸，仍须保持动态文本和数据刷新路径不变。
