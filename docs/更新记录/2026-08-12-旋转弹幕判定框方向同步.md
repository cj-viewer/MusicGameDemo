# 2026-08-12：直线与弧线三点方形判定盒

## 需求

将不能旋转的单个长方形 / AABB 判定改为沿弹道分布的 3 个等大正方形判定盒，减少斜向弹幕的视觉外误判。

## 实现

- 在 `MainScene` 增加敌我独立 Hitbox Group，弹幕视觉本体不再直接参加伤害 overlap。
- 敌方长条弹幕、玩家荧光棒直线弹幕沿头部、中部、尾部同步 3 个等大方盒。
- 警棍扫击在弧线前端、中点、尾端同步 3 个等大方盒。
- 方盒边长取对应弹幕最细宽度：敌弹 `6px`，荧光棒与警棍 `8px`。
- 任一方盒命中后通过 owner 引用销毁整枚弹幕和全部方盒，只结算一次伤害。
- 拖尾特效仍不创建物理 Body，不扩大实际伤害区域。

## 影响

- 直线弹幕不再出现固定横向长框；三个方盒会沿任意飞行方向排列。
- 斜向弹幕不再使用包含四角空白的扩大 AABB。
- 警棍弧段的三个方盒沿真实弧线采样，而不是用一条切线矩形近似整段弧线。
- 弹幕速度、寿命、伤害、Trail 和节拍推进规则均未改变。

## 验证

- `npm run build` 通过。
- 浏览器开启 `B` 调试显示，确认斜向直线弹幕沿弹身出现头 / 中 / 尾 3 个等大绿色方盒。
- 验证任一方盒命中后所属弹幕及三个方盒一并销毁，没有三次重复伤害。

## 遗留

- 当前固定为三个采样点；若弹幕长度显著增加，需要重新评估方盒之间的空隙，或按长度扩展采样数量。
