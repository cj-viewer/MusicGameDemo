# 2026-08-14：重拍透明度、下一拍律动配色与非角色配色板

## 需求

- 橙色框的不透明度必须明确按先快后慢增长。
- 外侧律动条每个拍间只跟随下一拍：轻拍前粉紫，重拍前橙色。
- 整理排除角色后的场景与 UI 配色板，并体现颜色面积占比。

## 实现

- 橙色框透明度曲线由 `Cubic.Out` 强化为 `Expo.Out`；粉色框保持 `Expo.In`，两者均从透明度 `0` 起步。
- 律动条取消未来三拍重拍框透明度混合，只读取下一拍类型并直接选择粉紫或完整橙色色相。
- 对教学实机四拍周期采样 8 帧并排除中央角色区域，生成 `outputs/非角色配色板.md`。

## 影响

- 橙色框前段显现更快，后段变化明显放缓。
- 律动条不再因为第二、第三拍存在重拍而提前转橙，拍间颜色语义稳定。
- 配色面积以教学画面的周期平均值呈现，便于后续控制大面积底色与小面积强调色的关系。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 浏览器四拍循环确认律动条按下一拍在粉紫 / 橙色之间切换，橙框使用强化后的先快后慢淡入。
- 浏览器控制台无 error / warning；配色板桌面布局无重叠或裁切。

## 遗留

- 正式战斗、Fever 和弹幕密集阶段会改变强调色的瞬时面积占比，当前数据只代表教学场景的四拍周期平均。
