# 2026-08-12：混音、重拍与节奏条扩展

## 需求

- 降低 BGM、提高节拍叫喊，使两者层级更清楚。
- 将荧光棒重拍放到第 4 下，将警棍重拍放到第 3、4 下。
- 节奏条显示原来 `1.5x` 数量的未来节拍，并增大节拍间距、同步调整汇聚速度。

## 实现

- BGM 音量从 `0.5` 调整为 `0.3`；轻、重叫喊固定音量从 `0.16` 调整为 `0.28`。
- 荧光棒 pattern 改为 `轻 → 轻 → 轻 → 重`；警棍改为 `轻 → 轻 → 重 → 重`。
- 节奏条预览由未来 `2` 拍改为 `3` 拍；相邻拍间距设为 `120px`，总行程为 `360px`。
- 当前 `146.32 BPM` 下，汇聚速度约为 `293px/s`；背板加宽至 `780px`，两侧 HUD 信息相应外移。

## 影响

- 输入判定、叫喊、节奏块、手柄自动输入、自动演示及攻击轻重反馈使用同一套新 pattern。
- 玩家可更早看到下一小节的节拍信息，拍间视觉分隔更清楚；判定窗口和实际拍点不变。
- 正确与错误输入仍不会改变节拍叫喊音量。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地试玩确认未来 3 拍同时可见、间距扩大、左右无裁切，ComboMeter 与武器说明无重叠。
- 荧光棒标题显示 `轻 → 轻 → 轻 → 重`；浏览器控制台无 error / warn。

## 遗留

- BGM 与叫喊的最终响度比例需人工试听确认；不同输出设备可能需要继续微调。
