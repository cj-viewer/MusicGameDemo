# 2026-08-18：第二关 HUD 重排与头顶血条

## 需求

- 把第二关 ComboMeter / 武器组从左下移到标注的底部中央区域。
- 把四拍图案移到顶部目标区域，并避免与 Wave 文字重叠。
- 删除固定左上 HP，把缩小后的实时血条放到玩家头顶并随玩家移动。
- 首轮实机确认后，把底部框进一步收成细条，并继续缩小顶部拍型。

## 实现

- 四拍图案保持无黑色背板，中心移到 2K 约 `(1200,37)`，显示比例缩为旧紧凑版的 `58%`；Wave 文字下移到 `(1280,144)`，旧设计字号由 `20px` 收至 `13px`。
- ComboMeter / 武器组保持底部目标中心 `(1192,1320)` 不动，整组比例缩至旧版 `72%`，同时把基础框高由 `96` 收至 `64`。最终 2K 外框约 `(1016,1274,351,92)`，圆环中心约 `(1108,1332)`，武器名起点约 `(1186,1332)`，不会覆盖左右两侧前景物件。
- HP 改为独立世界容器：外框 `144 x 50`、血条宽 `128`，标签由 `PLAYER HP` 收为 `HP`，标签 / 数值字号为旧设计 `14 / 13px`；容器中心每帧同步玩家位置并向上偏移 `80px`。基础镜头 zoom 下屏幕足迹约 `153 x 53px`。

## 影响

- 只调整第二关正式 HUD 的布局、比例和 HP 坐标空间；第一关 PSD 静态 HUD 与教学 UI 不变。
- HP、低血量、Combo、Fever、武器切换、Wave、节拍脉冲、物理、输入、伤害和镜头参数均不改变。
- 四拍图案、Wave、ComboMeter / 武器和 FPV 继续锁在屏幕坐标；HP 是玩家正式 HUD 中唯一随玩家世界坐标移动的组件。
- 没有新增或删除运行时素材，资源清单与 Loader 口径不变。

## 验证

- `npm.cmd exec -- tsc --noEmit`、`npm.cmd run build` 与 `git diff --check` 通过。
- `http://127.0.0.1:5180/` 实机确认第一关布局未被缩放；进入第二关后，顶部拍型更小，底部 Combo / 武器框更细且不越过两侧物件，固定左上 HP 不再出现。
- 玩家移动和战斗期间，头顶 HP 保持水平居中并同步跟随；浏览器控制台 `0 error / 0 warning`。

## 遗留

- 当前顶部 `58%` 与底部整组 `72%` / 基础高 `64` 已按两轮目视反馈收口；如继续微调，只应修改视觉比例，不应再次移动目标中心或更改玩法状态。
