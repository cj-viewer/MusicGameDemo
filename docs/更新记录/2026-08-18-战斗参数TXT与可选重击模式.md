# 2026-08-18：战斗参数 TXT 与可选重击模式

## 需求

- P 菜单一键记录当前玩家、武器与敌人战斗参数为 TXT，便于之后回传并把快照值改成默认值。
- 荧光棒重击可切换为贯穿屏幕的激光；警棍重击可切换为带击退的飞行月牙波；两个模式分别提供 P 开关且默认保留旧模式。

## 实现

- P 右侧战斗参数新增“模式 / 导出”第三页，包含两个默认关闭的模式开关和“导出当前战斗参数 TXT”按钮。
- TXT 使用 UTF-8 BOM、`schemaVersion=1` 与稳定 `key=value` 键名，记录玩家弹速 / 射程 / 攻击速度、两种模式、武器判定倍率、敌人弹速 / 频率 / 伤害、敌弹突进、死亡音量、粉丝螺旋概率和掉落概率；不记录 BGM 与纯显示设置。
- 激光从荧光棒实时发光端射到画面边缘，路径上每名敌人各命中一次。月牙按瞄准方向飞行，每名敌人最多命中一次并施加 `320 px/s` 击退；正确与 Poor 输入使用不同尺寸 / 行程，伤害仍读取现有评价与 ComboMeter 倍率。
- 两种新表现统一登记和清理；自然结束与游戏结束都停止 Tween 并销毁对象。

## 影响

- 开关关闭时，两把武器轻 / 重攻击全部沿用旧规则；开关开启时只替换实际重击，键盘、鼠标与手柄的重击共用该模式。
- Fever 激活清屏仍只清敌弹，不会误删激光或月牙；Fever 中正确重击仍只沿当前瞄准方向并保留既有附加音波。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- Chrome 实机确认第三页内容、开关状态、真实 Blob 下载文件名与关键键值；激光只命中射线路径敌人，月牙命中一次并传入 `320` 击退速度；两种特效结束后均无残留，控制台无 error / warn。

## 遗留

- 两个模式的尺寸、颜色、行程与击退强度已提供代码默认值，后续可根据导出的 TXT 快照继续统一调参。
