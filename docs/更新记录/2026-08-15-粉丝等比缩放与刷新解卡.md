# 2026-08-15：粉丝等比缩放与刷新解卡

## 需求

- 正式橙色粉丝和玩家同为 `256 x 256px` 角色画布，二者应使用相同运行时比例。
- 粉丝和玩家的手持武器同为 `128 x 128px`，武器比例也应一致。
- 修复粉丝刚刷新就停在原地的问题。

## 实现

- 粉丝本体从错误的 `1.2x` 世界物件倍率改为复用玩家本体倍率 `PLAYER_SPRITE_SCALE≈0.7067`。
- 粉丝专属荧光棒从错误的 `1.2x` 改为复用玩家武器倍率 `PLAYER_WEAPON_SCALE≈0.5653`。
- 将玩家武器倍率提取为动画规格共享常量，避免玩家和粉丝重复维护近似数值。
- 新增敌人 `onSpawned()` 生命周期；对象加入 Arcade `enemyGroup` 后，粉丝重新计算朝玩家方向的带偏差角度并立即写入 `66 px/s` 速度。构造期仍先写入一次初始速度，确保粉丝在首个物理帧就有运动状态。

## 影响

- 粉丝本体和武器的屏幕占比与玩家一致，不再因共享画布尺寸却使用 `1.2x` 而显得过大。
- 粉丝后续移动仍是每拍重选方向、拍间匀速；第 4 拍攻击、弹幕、HP、碰撞框源尺寸、掉落和特效层级不变。

## 验证

- `git diff --check`：通过。
- `npm.cmd run build`：通过（TypeScript 检查与 Vite 生产构建均成功）。
- 本地入口：`http://127.0.0.1:5173/`。
- 本地浏览器进入 Wave 1 后确认粉丝和武器已缩到玩家同档。粉丝由出生点 `(1709, 869)` 移动至首轮采样点 `(1635.02, 844.11)`，位移约 `78.05px`；当帧速度 `(-65.69, -6.44) px/s`，合速度约 `66.00 px/s`，确认刷新后已正常移动而非零速卡死。
