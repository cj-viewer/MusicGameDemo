# 2026-08-20：Boss 弹幕辨色与体型调参

## 目标

- 三连大弹改为蓝色，半月冲击波改为紫色，音符阵列改为绿色。
- 警卫长默认体型进一步增大，并可在 P Menu 中调节。

## 实现

- Boss 三连弹和音符阵列使用独立的程序化复合点弹纹理，分别采用蓝色与绿色外壳、亮芯；半月波采用紫色外晕、主体和亮芯。
- 默认 Boss 体型由警卫显示比例的 `3x` 调整为 `3.5x`。
- Boss 页新增“体型倍率”，以 `0.25x` 步进在 `2.00x–6.00x` 间调整；Boss 已登场时立即同步角色、阴影及碰撞比例。
- 本机保存和战斗参数 TXT 的 `[boss]` 段新增 `sizeMultiplier`，兼容缺少此字段的旧保存。

## 验收

- `npm run build` 通过。
- 本地 `http://127.0.0.1:5173/` 浏览器实机确认三连大弹为蓝色、半月波为紫色、音符阵列为绿色，Boss 默认体型为 `3.5x`；Boss 页十一项参数完整显示且未超出面板。
- 页面控制台 `0 error / 0 warning`。
