# 2026-08-21：教学结束资源释放

- 需求：教学关结束进入正式关前释放前置流程资源，降低正式关的内存与显存压力。
- 实现：片头 Scene 关闭时销毁片头视频与标题对象，并移除对应视频 / 纹理缓存；教学结束时销毁教学背景、角色、UI、弹幕及教学专用运行时纹理；教学结束视频播放完毕后移除视频缓存，并在正式关完成切歌后释放不再使用的教学 BGM。
- 影响：正式关共用的玩家、正式敌人、武器、节拍音效与当前正式关 BGM 不释放，避免资源缺失；若正式关选择与教学相同的 BGM，则保留该音频缓存。Replay 直接进入第一关时不再排队教学结束视频，并立即清理教学专用缓存。
- 验证：`npm.cmd run build` 通过 TypeScript 与 Vite production build；浏览器完成“片头跳过 → 教学跳过 → 教学结束视频跳过 → 第一关入场”及 Replay 路径，控制台 `0 error / 0 warning`。
- 遗留：该改动降低前置资源驻留压力；正式关敌人、弹幕和特效的逐帧负载仍需结合运行时性能采样继续观察。
