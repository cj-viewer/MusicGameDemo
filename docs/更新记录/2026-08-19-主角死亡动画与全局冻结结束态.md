# 2026-08-19：主角死亡动画与全局冻结结束态

## 需求

- 主角死亡时补上死亡动画；动画播放结束后冻结所有元素，主角停留在死亡最后一帧。

## 实现

- `src/game/Player.ts`：`die()` 额外关闭玩家物理碰撞体。
- `src/scenes/MainScene.ts`：`onPlayerDied()` 改为调用 `Player.die()` 随机播放 `death-1 / death-2`；死亡动画完成事件触发 `freezeGameplayAfterDeath()`，暂停 Conductor、音频、物理、补间、动画、Scene Clock 和 FPV，并通过 `gameOverFrozen` 让主场景 `update` 提前返回。`restartGame()` 与 `create()` 恢复时钟和冻结标记，保证 `R` 重开正常。

## 影响

- 战败表现恢复为播放死亡动画后冻结；主角保持死亡末帧。
- 清除弹幕、敌人结束待机、失败提示与 `R` 重开保持不变；不新增运行时素材。

## 验证

- `npm run build` 通过。

## 遗留

- 死亡动画与全场冻结的浏览器实机表现仍需按实机落地记录第 7 节人工验收。
