# 2026-08-17：单文件桌面打包

## 需求

- 把本地项目打包成一键运行的版本，目标机器不需要预装 Node。
- 选型为「单文件 exe + 系统浏览器」：exe 内置静态服务器，双击后自动打开默认浏览器。
- 打包版放宽「需要 1920 × 1080 或更高分辨率」的拦截提示。

## 背景

构建产物入口是 `<script type="module" crossorigin>`，直接用 `file://` 双击 `dist/index.html` 会被 CORS 拦截（模块脚本与资源加载都不放行），因此必须带一个本地 HTTP 服务器。

## 实现

- `src/main.ts`：分辨率守卫加构建期开关 `import.meta.env.VITE_RELAX_RESOLUTION_GUARD === '1'`。网页构建不设该变量，行为完全不变；桌面构建设为 `1`，守卫会被 Vite 直接 tree-shake 掉。
- 新增 `scripts/desktop/server.cjs`：SEA 入口。从内嵌资源包读出全部文件到内存后提供静态服务，支持 MIME 映射、单段 `Range` 请求（视频拖动与媒体流依赖）、`HEAD`、404 与端口顺延（默认 `5199`，被占用时最多顺延 20 次）。未在 SEA 环境下运行时自动退回读磁盘 `dist/`，便于打包前单独验证；`NO_OPEN=1` 可跳过自动开浏览器。
- 新增 `scripts/build-desktop.mjs`：串起 `tsc --noEmit` → `vite build`（带 flag）→ 打包 `dist` → 生成 SEA blob → 复制 Node 运行时 → `postject` 注入。直接以 `process.execPath` 调用 `tsc` / `vite`，不经过 `npm.cmd`——Node 24 禁止无 shell 地 spawn `.cmd`，会报 `EINVAL`。
- 资源包格式：`[8 字节小端 index 长度][index JSON][各文件内容顺序拼接]`，整体作为**单个** SEA asset 注入，避免为 169 个文件各写一条 `assets` 配置。
- 新增 npm script：`package:desktop`（打包）与 `serve:dist`（脱离 SEA 直接跑服务器）。新增 devDependency `postject`。
- `.gitignore` 追加 `release/` 与 `build-desktop/`。

## 影响

- 产物为 `release/节奏星球.exe`，`119.07MB`（Node 运行时 `88.25MB` + 资源包 `30.69MB`，共 169 个文件）。
- 目标机器无需 Node、无需任何运行时；游戏在系统默认浏览器中运行，不是独立窗口。
- 网页构建与线上部署完全不受影响。

## 验证

- 网页构建（不带 flag）产物中仍含守卫文案 `需要 1920`；桌面构建（带 flag）产物中该字符串数量为 `0`，确认只在打包版被移除。
- 服务器脱离 SEA 直接运行可正常提供 `dist/`。
- exe 实跑：首页 `200`；JS、`intro.mp4`、`bgm0.mp3`、角色 PNG、音效 MP3 均 `200`；不存在的路径返回 `404`。
- `Range: bytes=100-199` 返回 `206`，`Content-Range: bytes 100-199/5824033`、`Content-Length: 100`、`Accept-Ranges: bytes`。
- 完整性：`bgm0.mp3`、`sfx-beat-light.mp3`、`intro.mp4` 从 exe 取回的字节与 `dist/` 中 SHA-256 一致。
- 实机：在 `screen.width` 上报为 `0` 的环境中，打包版不再显示分辨率拦截提示，`1920 x 1080` Canvas 正常创建，IntroScene 激活；预热后 104 张贴图 + `beat-light` / `beat-heavy` / `bgm-0` 就绪，跳过片头后 `MainScene` 待加载数为 `0` 并直接进入 `tutorial`、`bgm-0` 正在播放；后台补下 `bgm-1` / `bgm-2` / `bgm-3` 完成，`totalFailed = 0`，控制台无 error。

## 遗留

- `postject` 注入后 Windows 会提示 `The signature seems corrupted!`：本机没有 `signtool` 可先移除 Authenticode 签名。exe 可正常运行，但首次打开可能触发 SmartScreen 提示，需要用户点「仍要运行」。若要消除，需在装有 Windows SDK 的机器上重新打包，或对产物重新签名。
- 只打了 `win32-x64`。SEA 无法交叉编译，其他平台需在对应平台上执行 `npm run package:desktop`。
- 游戏运行在系统默认浏览器中；若默认浏览器过旧（不支持 WebGL / Web Audio）仍会失败。
