# 2026-08-18：第二关四拍图案与轻透 HUD 改版

## 需求

- 删除第二关顶部紧凑四拍 UI 的黑色矩形背景，只留下四个轻 / 重 pattern 图案。
- 将第二关左上 HP 与左下 ComboMeter / 武器状态改为和第一关一致的轻透白线视觉语言，同时保留实时数据、既有功能和位置。
- 第一关继续使用现有 Photoshop 教学 HUD，不把第二关的程序化框带回第一关。

## 实现

- `MainScene.buildPatternPanel(false)` 不再创建 `320 x 64px`、`0x0f172a / 0.68` 的黑色矩形及 `0x334155` 描边；四个图案的坐标、轻 / 重造型、逐拍缩放高亮和武器切换重建保持不变。
- `HUD` 为第二关绘制两块程序化轻透框：左上逻辑矩形 `(20,12,248,58)` 包围实时 HP，左下逻辑矩形 `(128,612,244,96)` 包围 ComboMeter 与武器名。框体使用 `#f2f0e8 / 0.055` 的极淡雾面、`#fffdf1 / 0.34` 的 1px 细边和 Alpha `0.82` 的 2px 断角，左下区域另保留弱分隔线。
- HP 仍使用既有 `HP_X=32、HP_Y=42、HP_WIDTH=220`；ComboMeter 与武器名仍使用 `BAR_Y=668、METER_X=192、WEAPON_NAME_X=246`。健康 / 低血量、Combo / Fever、武器切换和节拍脉冲仍读取真实运行状态。
- 本轮没有新增、删除或迁移运行时素材；第一关 Photoshop 连段、进度、底栏、石子和操作卡保持原样。

## 影响

- 只调整第二关四拍提示和实时 HUD 的视觉材质，不改变输入、pattern、节拍判定、伤害、HP、ComboMeter、Fever、武器切换、FPV、物理边界、关卡流程或资源加载。
- 第一关仍隐藏 gameplay HUD 与 FPV，并继续显示既有 Photoshop 静态 HUD；进入第二关后才显示程序化轻透框和实时数据。
