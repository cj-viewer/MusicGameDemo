# 2026-08-13：草地演唱会绘本立牌第三人称

## 需求

- 参考“马赛克风格草地演唱会舞台”，把右侧等大视口改为用 2D 素材表现的伪 3D 第三人称场景。
- 场景物体像立牌一样立在真实位置，具有合理前后和物理关系；立牌用白色外描边加强层次，形成童话绘本立起来的感觉。

## 实现

- `FpvMiniScene` 改为玩家身后约 `176px` 的第三人称透视，相机视场角 `82°`、地平线 `y=246`、眼高 `105`；玩家仍落在近景，但尺寸更接近第三人称角色占屏比例。
- 用 Phaser Graphics 绘制青绿天空、奶白舞台结构、深青舞台入口、绿色草地、中央浅色通道、地面距离线和柔和暗角；参考图仅作为色彩与构图依据，没有复制到运行时素材目录。
- 根据参考图定向生成并接入三张透明环境美术立牌：带石材纹理和青色发光嵌件的舞台柱、带旋钮/面板/线缆的设备箱、带白黄小花和芦苇的花草丛，保存到 `public/assets/images/environment/storybook/`。源图使用洋红键色，已本地抠除并按对象独立裁切。
- 玩家、敌人、边界立柱和弹幕全部读取主场景现有坐标。相机空间的前向深度决定缩放和渲染顺序，近处自然遮挡远处；真实碰撞、伤害、移动、死亡继续只由左侧 Arcade Physics 结算。
- 玩家与敌人复用当前 2D 纹理并同步左右翻转，额外叠加白色剪影描边、奶白脚底支架和椭圆接地阴影；弹幕同样增加白色卡纸边和阴影。
- 修复角色被横向压扁：不再把动画对象当前 `displayWidth` 和 `displayHeight` 分别投影，而是以目标世界高度和纹理原始宽高比推导宽度，透视只施加统一比例。
- 右侧继续只读，点击不会开始标题或攻击，鼠标移入右侧不会改变主场景最后有效瞄准；Esc 可关闭或恢复整个第三人称视口。

## 影响

- 不修改战斗坐标、碰撞体、伤害、节拍、AI、敌人生成或美术替换接口。
- 右侧从第一人称改为可看见玩家近景的第三人称，主要用于验证 2D 素材在伪 3D 纸片舞台中的表现。
- 为承载最多 240 枚敌方点弹，右侧弹幕立牌池同步扩为 240。

## 验证

- `npm.cmd run build`：通过 TypeScript 检查和 Vite 生产构建。
- Codex 内置浏览器：玩家比例正常、不再横向拉伸；石柱、设备箱、花草三类透明立牌同屏可见，白描边、脚底支架、接地阴影、远近缩放和遮挡正常；控制台无 error / warn。

## 遗留

- 当前舞台远景仍是程序绘制的风格验证稿；后续正式美术可继续补充帐篷、树木和舞台部件透明 PNG，复用现有投影与深度逻辑。

## 固定世界与完整演出广场（第二轮）

- 移除固定在屏幕上的绿色地板和纯色舞台。右侧草坪、中央主路、横向休息区、舞台前广场、北侧入口花园全部改为固定世界坐标的地面多边形；相机移动或转向时，道路交叉口、镶嵌纹样和草地细节统一产生透视与视差。
- 新增完整主舞台、节庆树、帐篷、庭院灯和花槽长椅五类透明像素绘本素材，与既有石柱、设备箱、花草组成固定布局。舞台位于南端，入口花园位于北端，中部帐篷和长椅围绕横向道路布置，所有区域由主路连接。
- 地面采用近裁剪面与左右视锥裁剪，避免相机靠近道路或转向时地面整块消失；物体继续按与相机的前向深度缩放和排序，近处立牌遮挡远处立牌。
- 新素材均保留透明背景和白色剪纸边缘；运行时再叠加统一的白色轮廓、接地阴影与纸片脚座，以保持童话绘本立牌层次。
- 浏览器实机验证了朝南主舞台、朝北入口花园和朝东帐篷休息区三种视角；场景构图随相机方向连续切换，控制台无 error / warn。`npm.cmd run build` 通过。

## 接地与绘本光影（第三轮）

- 去掉所有物体底部独立的三角形脚座，立牌纹理、白色轮廓与底边压线共用同一个地面投影基点，素材底边直接接触道路或草地，不再悬在支架上。
- 接地阴影改为从纹理底边连续伸出的扁椭圆投影；普通立牌的阴影长度按透视高度计算，主舞台使用跨越大部分底边的宽阴影，并在舞台前广场额外绘制一层固定世界坐标的建筑投影。
- 新增舞台冷青色光区和六盏庭院灯的固定地面光池；物体根据到主舞台和广场中心的世界距离叠加轻微明暗层次，远离光源的纸片更暗，靠近舞台的纸片更亮。
- 舞台、帐篷、长椅和设备箱记录固定朝向，相机从侧面观察时横向压缩但不小于原宽的 `42%`，形成“薄纸片侧视”效果；柱子、路灯、树和花草保持近似正面宽度，避免圆柱类物体被压成细线。
- 实机验收重点为：舞台与灯柱底边不再出现空隙或三角脚架，阴影与底边相连；相机转向时物体朝向压缩、道路透视、固定光区和遮挡顺序同步变化。

## 固定纸面空间投影（第四轮）

- 上一轮“按视角压缩且仍正对相机”的实现不符合真实立体绘本。本轮环境对象改用 Phaser `Mesh2D` 四角网格：纸片左右边缘由两个固定世界端点独立投影，面片横轴由配置的固定 `facing` 决定，不再朝摄像机旋转。
- 相机从正面、斜侧或近乎平行方向观察时，面片会自然出现梯形透视、侧向变窄和前后穿插；舞台固定横向，左右树木、帐篷、长椅和花草采用向场地中心围合的斜向排布，形成前景翼片—中景小道具—后景舞台的纸艺布景层次。
- 所有环境 PNG 重新按 `alpha >= 24` 的真实可见边界裁切，并清除 `alpha < 16` 的残留色键像素；主舞台从 `1672×892` 裁为 `1622×802`，庭院灯从 `627×617` 裁为 `231×543`，消除可见底边与世界落地点之间的透明空隙。
- 每块固定面片的投影阴影使用其屏幕底边两个端点生成四边形，从纸片折线向地面延伸；阴影与纸面保持同一深度关系，不再使用跟随 billboard 的椭圆脚影。
- 浏览器实测：舞台正视完整、侧视时固定为薄纸面；树木和休息区道具从斜角观察出现不同宽度、斜边和遮挡，底边与地面连续，控制台无 error / warn。

## 天空剪纸动态层（第五轮）

- 根据现有草地演唱会参考图定向生成宽云、团云、卷云、五鸟群、双鸟和青金流星，并完成洋红键色去除、透明边缘裁切与 PNG 导入。
- 云层使用三档透明度与慢速水平漂移形成远近层次；鸟群从相反方向掠过并有细微上下起伏；两道流星按 `6.4s` 周期错峰斜穿天空，以短淡入淡出避免循环跳变。
- 所有天空元素位于远景天空层，不参与固定环境 `Mesh2D` 投影，也不改变主场景物理、节拍、瞄准和伤害规则。
- `npm.cmd run build` 通过；内置浏览器检查舞台正视与空旷草地区域，画面不再空白，控制台无 error / warn，新增资源无 404。

## 固定纸片视锥连续裁切（第六轮）

- 根据用户录像复现了主舞台在约 `72°` 转至 `57°` 时突然整张消失：旧逻辑在纸片任意一个底角越过近面或侧视锥时会隐藏整个面片。
- 固定纸片现改为相机空间线段裁剪；底边与顶边在近面、左右视锥上的交点同步投影，纹理 `U` 坐标随保留区间插值，因此屏内部分持续存在且不会被拉伸。
- 白色剪纸轮廓和接地阴影继续使用裁剪后的底边，前后深度及固定世界朝向不变。
- `npm.cmd run build` 通过；浏览器复测 `59° / 51°` 视角，主舞台仍连续可见，控制台无 error / warn。
