# 2026-08-20：开场视频替换为单段新片头

## 需求

- 使用用户提供的新视频替换开头所有视频。
- 新视频继续支持空格跳过。

## 实现

- 新视频按 H.264 + AAC、`1920 x 1080 / 60fps`、CRF `23` 和 Fast Start 规范输出为唯一的 `public/assets/video/intro.mp4`。
- `IntroScene` 删除第二段视频加载和串播逻辑；新视频播放完直接进入教学。
- 标题页及视频播放期间继续监听 `Space`，跳过时停止视频并进入教学。
- 删除不再引用的 `public/assets/video/intro-rocket.mp4`。

## 影响

- 标题插画、开始按钮、游戏资源后台预热及教学内的 Space 行为不变。
- 开场视频由两段变为一段，时长约 `24.57s`，文件约 `11.46 MiB`。

## 验证

- `ffprobe` 确认 H.264 + AAC、`1920 x 1080 / 60fps`。
- `npm run build` 通过，本地视频资源返回 HTTP 200。
- 按快速迭代要求未完整播放视频试玩。

## 遗留

- 公开发布前需确认新视频作者、商用范围和再分发许可。
