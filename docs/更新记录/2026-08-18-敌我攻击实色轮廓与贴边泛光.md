# 2026-08-18：敌我攻击实色轮廓与贴边泛光

## 需求

- 参考青色胶囊与橙红光球，把攻击改成有明确底色、可读轮廓和较小亮芯的视觉。
- 自发光只贴在边缘附近，不能扩散到模糊原形，也不能在浅色场景中叠成刺眼白团。
- 仅按后续反馈把玩家红色线弹可见主体缩短 `20%`；其它攻击大小、判定、速度、寿命、伤害、数量和动画时序不变。

## 实现

- 玩家 Light / Hard、保安与粉丝的短时攻击 Sprite 从整层 ADD 改为 `NORMAL + TintModes.FILL` 实色主体，仅保留低强度 Glow 与 Threshold→Blur→ADD Bloom。整体 Alpha 依次为 `0.82 / 0.86 / 0.82 / 0.84`，公共 Blur strength 为 `0.20`。
- 玩家普通 / 踩拍直射各生成一张 `128 x 64` 复合 CanvasTexture：外壳 / 中层 / 核心颜色分别为 `#d92f3d / #ff6470 / #fff6f3` 与 `#d92f3d / #ff7a82 / #fffff7`。按最新反馈把外壳长度从判定段 `1.35x` 缩短 `20%` 为 `1.08x`，厚度仍为原弹体 `0.52x`；中层宽高为外壳 `90% / 82%`，核心为 `76% / 54%`；极窄柔光峰值 Alpha `0.24`、sigma `2.6px`。整张仍显示在既有 `1.95x / 3.2x` 包围内，每颗弹只使用一个无 Tint 的 `NORMAL` Image；纹理中心沿发射反方向平移长度差的一半，让尾端锚点保持不动。
- 保安 / 粉丝点弹分别生成一张 `64 x 64` 复合 CanvasTexture，并按后续反馈从圆形光球改为方向性小水滴。保安外壳 / 中层 / 核心为 `#18b6cf / #7ff7ff / #f2ffff`，粉丝为 `#d92c16 / #ff7832 / #fff6cf`；中层 / 核心按水滴外壳 `82% / 56%` 比例绘制，柔光峰值 Alpha `0.24`、sigma `2.4px`。水滴纹理默认朝右，运行时随弹道旋转，小尾端朝发射者、大圆头朝飞行方向 / 被攻击者；颜色亮度、外部显示包围、弹速、伤害和命中盒不变，每颗弹也只使用一个无 Tint 的 `NORMAL` Image。
- 警棍扫击、重击充能环、贯屏激光、月牙、Fever / 冲刺音波和 Fever 清屏光条都拆为实色主体 / 亮芯与独立低 Alpha ADD 外沿。Trail 只把 Alpha 收为 `0.04–0.09`；FPV 弹点改为 NORMAL，并按敌 / 我使用 `0.78 / 0.84` Alpha。
- 贯屏激光继续使用 `2.8x / ADD 0.06` 外沿、`1.45x / NORMAL 0.86` 主体与 `0.38x / NORMAL 0.92` 内芯；月牙继续使用轻 / 重 `16 / 24` 宽、`ADD 0.06` 外沿，`6 / 9` 宽、`NORMAL 0.86` 主体和 `2 / 3` 宽、`NORMAL 0.90` 内芯。Fever 清屏五条的 Alpha 为 `0.015 / 0.035 / 0.08 / 0.88 / 0.12`，其中白芯使用 NORMAL。
- 线弹与水滴弹的核心、过渡、实色外壳和柔光全部烘进同一张 RGB+Alpha 纹理，不再创建独立 ADD 外晕，也不会叠成空心色环、圆形光球或纯白光团。纹理只在原显示框内重新分配颜色、Alpha 和轮廓；本轮只缩短线弹内部可见主体，并把敌方点弹轮廓改为方向性水滴，不改变外部包围，也不新增仓库图片或 Loader 项。
- 玩家本体 / 武器与存活敌人的受击反馈改为保留贴图纹理的暖粉 `MULTIPLY` 短闪；致死敌人跳过受击染色后按原放大淡出。命中火花和警棍踩拍内环也改为攻击色向白混合的暖色，避免纯白反馈覆盖攻击材质。

## 影响

- 只改变攻击的材质合成、纹理内颜色 / Alpha 分布、命中短闪颜色，以及玩家红色线弹的内部可见长度。发射点、尾端锚点、外部纹理包围、透明物理宿主、短时 Sprite 的 Glow 距离 / Blur 半径 / Threshold、弹速、射程、寿命、伤害、击退、命中盒、弹数、扇形分布与动画时序不变；FPV 通过独立显示宽度同步缩短后的线弹。
- 手持武器原图、拍点判定、Combo 边缘反馈、Fever 边框和 Dash 角色残影保持原表现；程序弹体由原多对象显示收敛为单个 `NORMAL` Image，暖粉命中短闪只替换原纯白填色，不改变持续时间。
- 没有增删 `public/assets` 文件，core 图片、Loader 项与字节口径不变。
