# 2026-08-21：警棍扇形重击描边、短时 Fever 与本机参数回填

## 需求

- 加深警棍左键范围颜色，让亮光和边缘语言接近警棍重击。
- Fever 清屏完成后立即结束并恢复 `20 HP`，删除其他战斗回血。
- 把当前浏览器保存的整份 P Menu 配置固化为代码默认值。

## 实现

- 左键扇形使用深紫实色填充，沿完整边缘叠加低 Alpha 外光、紫色主边和近白亮芯；命中几何不变。
- `ComboSystem` 的 Fever 改为显式短时状态，只由 `760ms` 清屏完成回调结束；同一回调完成唯一一次 `20 HP` 回复。删除按拍倒计时、回充、闪避扣 Fever 时长与正确输入回血。
- 第一关开场满血改走独立关卡初始化入口，不播放战斗回血反馈。
- 读取站点存储键的最后一份完整 JSON，把其中所有字段与代码默认值逐项核对并回填差异。

## 影响

- Fever 强化窗口现在严格等于清屏特效长度；玩家不能在其后继续保留 Fever 增益。
- 代码默认值与当前本机 P 配置一致；已有浏览器保存项仍会正常覆盖代码默认值。
- 未新增或替换运行时素材。

## 验证

- `npm run build`、本地页面、控制台和差异检查见本轮交付。

## 遗留

- 扇形亮度和边缘粗细仍建议用实体显示器人工确认；如需调整，只改视觉 Alpha / 线宽，不改变判定范围。
