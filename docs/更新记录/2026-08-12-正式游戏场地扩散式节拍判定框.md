# 2026-08-12：正式游戏整小节场地节拍预告与教学延迟校准

## 需求

- 除教学关外，删除屏幕上方和下方的拍子提示。
- 将正式游戏的拍点提示改为场地中央内框向大场地框扩散；到达大框时形成可攻击的判定时机，越界后不再显示。
- 内框出现时已有约四分之一场地大小，向外扩散时逐渐变亮，接近大框时达到最高亮度。
- 扩散提示需要提前至少一个完整小节出现；教学连续打拍时顺便自动校准设备输入延迟。
- 周围律动条应更均匀，不能大面积完全重叠。

## 实现

- 教学和正式游戏均关闭底部左右汇聚节奏条；教学保留顶部四拍连段面板、三小节目标和延迟校准，正式游戏继续隐藏顶部连段面板。
- 使用三个与场地同宽高比的扩散内框，分别在未来 `1 / 2 / 3` 拍到达边界；每框从 `0.7x`、完全透明的状态扩散至 `1x`，持续 `3` 拍，尺寸和透明度均采用 `easeInExpo`。
- 轻拍内框为青色 `#67e8f9`、`3px`；重拍为黄色 `#fbbf24`、`5px`。内框到达场地边界时立即隐藏，大场地框短暂同色亮起，不会出现越界残影。
- 教学记录按键种类正确、距原始拍点 `≤180ms` 的原始拍差；其中 `≤120ms` 的稳定样本以中位数和 MAD 去除离群值，校准每次以 `35%` 渐进收敛，最终限制在 `±120ms`，只平移后续输入判定。
- Fever Time 中每次正确鼠标或手柄输入恢复 `10 HP`，上限为最大生命。
- 左上 HP 条律动加大为轻拍 `0.84x → 1.26x`、重拍 `0.62x → 1.50x`；正确攻击镜头缩放减半为轻 / 重 `1.0075x / 1.015x`。
- 律动条保留两条下侧交错轨道和三列左右近似等距轨道，并加入受控随机错落：下侧横向 `±5px`、纵向 `±4px`；左右横向 `±4px`、纵向 `±2.5px`。

## 影响

- 教学和正式游戏均从 HUD 节奏条改为场地空间内的三拍扩散提示，读拍方式保持一致、角色附近视线更集中。
- 节拍时钟、BPM、轻重输入序列、攻击判定窗口、节拍叫喊和边缘人群律动不变。
- 换武器后扩散框会自动读取新武器 pattern，继续区分轻拍和重拍。
- 延迟校准只影响教学完成后的输入判定时间偏移，不移动音乐和视觉拍点，异常样本不会改变校准值。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 浏览器实机验收：教学和正式游戏均无底部节奏条，同屏确认三个框从 `0.7x`、透明状态在 `3` 拍内按 `easeInExpo` 扩散与淡入；教学连续三小节后校准值稳定且不超过 `±120ms`；Fever 正确输入回 `10 HP`，HP 条更明显且镜头缩放减半；控制台无 error / warn。

## 遗留

- 扩散起始尺寸和透明度曲线仍可根据实际演奏手感继续微调。
