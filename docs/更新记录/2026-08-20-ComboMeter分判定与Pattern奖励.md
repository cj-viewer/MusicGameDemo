# 2026-08-20：ComboMeter 分判定与 Pattern 奖励

## 需求

- Perfect / Good 正确踩拍分别增加 `4 / 3` 点 ComboMeter。
- 连续正确完成四段 Pattern 后额外奖励 `10` 点；中途错拍、错键或漏拍均不发完整奖励。
- 三项奖励可在 P 菜单实时调试。

## 实现

- `ComboSystem` 直接按最终点数结算判定奖励，并仅在 `comboCompleted` 时追加完整 Pattern 奖励；旧 `3x` 换算不再参与。
- P 菜单新增“量表 / Fever”页，Perfect、Good、完整 Pattern 三项默认 `4 / 3 / 10`，范围 `0–100`、步进 `1`。
- 战斗参数 TXT 新增 `[comboMeter]` 分区和三项稳定键名。
- ComboMeter 普通进度与 Fever 倒计时的圆环进度弧统一改为橙色 `0xf97316`；圆心由等级 / `F` 改为对应状态的整数百分比。

## 影响

- 全 Perfect 的完整四段共增加 `26` 点，全 Good 共增加 `22` 点。
- Fever 满值、等级、伤害倍率、闪避消耗与清弹效果不变；Fever 中仍以普通阶段 `50%` 的效率把奖励换算为延长时间。
- 圆环位置、尺寸和浅白底轨不变；普通状态显示总量表百分比，Fever 中显示剩余时间百分比。

## 验证

- `npm run build` 通过。
- 状态机自动检查：全 Perfect / 全 Good 四段分别为 `26 / 22`；第三步错键或漏拍均只保留前两拍 `8` 点，不发完整奖励；自定义 `7 / 5 / 20` 后全 Perfect 四段为 `48`。
- 本地浏览器确认 P 面板五页完整显示，“量表 / Fever”默认 `4 / 3 / 10`，加减按钮可即时改值并恢复；控制台 `0 error / 0 warning`。
- 正式关初始 ComboMeter 圆心显示 `0%`；按 `F` 进入 Fever 后进度弧为橙色、圆心实时显示剩余 `89%`，文字未溢出圆环，控制台仍为 `0 error / 0 warning`。

## 遗留

- 无。
