# 2026-08-18：扫屏清弹与分轻重伤害

## 需求

- 敌人死亡声音最高限制为 `100%`。
- Fever 清屏改为从左向右划过全屏的发光条，并提供 C 调试键。
- 两把武器的轻 / 重攻击分别提供伤害参数。
- 保持指定的攻击速度和两个新重击开关默认值。

## 实现

- Esc 敌亡独立滑杆范围改为 `0–100%`。
- 清屏使用五层 ADD 竖向光条，在 `620ms` 内从屏幕左外扫到右外；按屏幕 X 逐列删除敌弹，不遍历玩家弹组。C 直接调用同一效果。
- P 扩为四页；“玩家伤害”新增荧光棒轻 / 重 `10 / 18`、警棍轻 / 重 `12 / 26`，范围 `0–100`、步进 `1`。TXT 新增 `[weaponBaseDamage]`。
- `batonAttackSpeed=1`、`glowstickHeavyLaserEnabled=true`、`batonHeavyCrescentEnabled=true` 保持默认。

## 影响

- 每次武器攻击先按实际轻 / 重输入读取基础伤害，再乘判定倍率和 ComboMeter 倍率。
- C 只用于直接观察 / 测试清弹效果，不会启动 Fever。

## 验证

- `npm run build` 通过。
- Chrome 实测光条经过前后敌弹按位置逐列消失，结束后敌弹归零且光条销毁；玩家伤害页完整显示，敌亡滑杆上限为 `100%`，控制台无 Runtime exception。

## 遗留

- 无。
