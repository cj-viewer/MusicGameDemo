# 2026-08-18 音量设置面板轻透白线改版

## 需求

将 Esc 音量设置面板从深色不透明样式替换为教学 UI 同系列的轻透白线样式，保持主场景原本配色，并保留现有八路音量控制。

## 实现

- 全屏中性黑遮罩降低为 `0.10` Alpha，主面板使用 `0.17` Alpha 的中性薄底。
- 面板采用细白色外框、弱内框与四角断开式角标；标题和分区文字统一为低饱和米白色。
- 八条音量滑杆由彩色粗条统一为 `4px` 浅色细轨、`7px` 白边滑块和弱分隔线。
- 每条细轨仍保留 `28px` 高的透明点击热区，点击、拖动与百分比反馈不因视觉变细而受影响。

## 影响

仅调整 `MainScene` 内 Esc 音量面板的视觉绘制；八个音频通道的数值、范围、暂停恢复、Esc 开关、P 调参面板和全部游戏规则不变。没有新增运行时资产。

同时修正 README、简化玩法案和实机当前规则中遗留的旧音量范围与入口说明：现行八路音量默认值和上限均为 `100%`，Esc 只显示音量面板，战斗参数与 FPV 开关位于 P 调参面板；历史条目不回写。

## 验证

- `npm.cmd run build` 通过。
- 在 `http://127.0.0.1:5180/` 打开 Esc 面板，确认背景未被重新染色；主音量点击由 `100%` 更新到 `50%`，拖动恢复至 `100%`，百分比、滑块和填充同步变化。
- Esc 可正常关闭并恢复游戏；浏览器控制台为 `0 error / 0 warning`，没有新增资源 404。

## 遗留

当前面板使用 Phaser 图形和文字实时绘制；若后续改为 PSD 像素级切图，需要另行确认最终九宫格、字体和多分辨率适配规则。
