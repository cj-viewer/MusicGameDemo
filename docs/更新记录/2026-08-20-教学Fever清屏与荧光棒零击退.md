# 2026-08-20：教学 Fever 清屏与荧光棒零击退

## 需求

恢复教学关 ComboMeter 满格后的 Fever 清屏，并彻底移除荧光棒击退。

## 实现

- 教学关量表满格后与正式关共用 `enterFever()` 和橙金扫屏清弹效果。
- 教学状态下按 `F` 也可直接充满量表，便于快速检查 Fever。
- 荧光棒轻击和发射函数默认击退统一改为 `0`；重击与激光继续保持零击退。
- 警棍的普通、重击和月牙击退保持不变。

## 影响

不改变伤害、弹速、射程、Fever 持续时间或警棍手感。

## 验证

`npm run build` 通过。未进行关卡试玩。

## 遗留

无。
