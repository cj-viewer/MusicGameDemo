# 2026-08-14：攻击特效分层与正式手持武器

## 需求

- 修复攻击时角色本体被白色特效帧替换的问题。
- 将正式玩家缩至当前的 `0.8x`。
- 使用正式荧光棒和警棍贴图，固定绘制在角色身后并随朝向左右瞬切。

## 实现

- `attack_light / attack_hard` PNG 改由独立 `attackFx` Sprite 播放；玩家主 Sprite 在 `200ms` 攻击锁期间继续显示 Idle / Run。
- 玩家显示比例由约 `0.589x` 改为约 `0.471x`，可见高度约 `50.9px`；固定碰撞体同步缩至约 `19.8 x 50.9px`。
- 预加载并使用 `images/weapons/light_stick/player/light_stick_player.png` 与 `images/weapons/baton/player/baton_player01.png`，删除程序矩形武器和独立挥动 Tween。
- 正式武器深度低于玩家本体；朝左位于身体左侧，朝右镜像并瞬切到身体右侧。

## 验证

- `npm.cmd run build` 通过 TypeScript 与 Vite 构建。
- 页面和两张武器、轻重攻击代表帧均通过本地 HTTP 返回 `200`。
- 浏览器自动截图受本地 URL 安全策略限制，未绕过；最终遮挡、持有侧和主观大小需在本地试玩页人工确认。

## 未改变

- 移动速度、`160px / 140ms` 闪避、攻击判定、武器 pattern、弹幕数值、BPM、ComboMeter 与 Pick 缺失状态均不变。

## 二次视觉校准

- 移除自动索敌的白色攻击方向短线。
- 正式武器再缩至上一版的 `0.8x`，比例约 `0.377x`。
- 武器改用贴图中心原点，中心相对角色固定为 `x=±8.96px、y=+3.84px`；朝右时仅改变 X 符号并水平翻转，保证左右严格关于角色中线对称，同时让武器更贴近腰部。

## 三次视觉校准

- 玩家攻击统一从角色中心向当前朝向侧偏移约 `5.12px`；弹幕、警棍扫击和攻击反馈共用该锚点。
- 轻攻白色粒子 / 残影与重攻圆形爆发绘制在角色和武器身后，出手后停留原地，不再跟随角色。
- 特效在 `200ms` 内由 `1.0x` 放大到 `1.35x`，透明度从 `0.95` 淡至 `0`。
