# 2026-08-18：背景层级、内缩判定框与正式保安动画

## 需求

- 地图与背景保持在最底层；正确输入的方形判定框内缩一圈，绘制在地图与环境物件之间。
- 判定框出现时的初始不透明度提高到原来的两倍。
- 玩家仅上下移动时不做 Y 轴节拍缩放。
- 保安替换为与玩家、粉丝一致的正式 Idle / Run 序列帧流程。

## 实现

- 地图底图固定 depth `-20`，35 个环境物件按底边排序于 `-18–-17.5`；判定框固定在中间的 depth `-19`。
- 活动区统一内缩为 `x=72, y=72, 1776 x 936px`，物理边界、出生点、弹丸清理、Fever 边框与判定框共用该区域。
- 判定框的旧初始 Alpha `0.68–1` 翻倍会超过 Phaser 的 `1.0` 上限，故以 `1.0` 开始淡出。
- `guardAnimation.ts` 新增正式保安 Idle / Run 动画注册和播放状态机；本体使用 16 张 `npc_guard01` PNG，以约 `0.3934x` 校准为约 `76px` 的可见高度，攻击 Light 特效同步缩放。

## 影响

- 背景物件不再遮挡角色，但同一背景层内仍保留 TopDown 底边排序。
- 玩家斜向、水平或未移动时继续保留轻拍 `105%`、重拍 `110%` 的脚底锚定律动；仅纯上下输入例外。
- 旧静态保安贴图继续用于 FPV 简化投影，运行时敌人不再依赖它。
