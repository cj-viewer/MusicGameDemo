# 2026-08-14：正式玩家动画状态机替换

## 需求

- 将远端新增的正式玩家动画替换进游戏状态机。
- 战败时在 Death1 / Death2 中随机选择一种播放。

## 实现

- 接入 Idle / Run 各 8 帧、Dash 12 帧、Attack Light / Hard 各 5 帧、Death1 / Death2 各 8 帧。
- Idle / Run 循环；Dash 在 `140ms` 闪避内完整播放；轻 / 重攻击在 `200ms` 内播放并锁定动作，随后恢复移动状态；死亡以 `12fps` 播放一次并停在末帧。
- 正式素材默认朝左，锁定右侧时翻转。
- 统一 `256 x 256px` 画布按 `108px` 可见内容高度缩放至约 `63.6px`；固定碰撞体源尺寸 `42 x 108px`、偏移 `107, 78`，避免透明画布扩大碰撞范围。
- Dash 残影复制当前正式 Dash 帧；手持武器、自动锁定、受击闪白、节拍蹲弹和 TopDown 深度保留。

## 验证

- `npm.cmd run build` 通过 TypeScript 与 Vite 构建。
- 本地浏览器确认正式 Idle、Dash、Attack Light / Hard 正常显示，Dash 残影取自新动画，角色比例接近上一版。
- 浏览器控制台无资源 404、error 或 warning。

## 遗留

- 仓库和所有已知远端引用均没有 Pick 序列帧，本次没有用其他动作冒充；待素材补齐后再接入拾取状态。
