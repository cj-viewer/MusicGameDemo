# 2026-08-20：云朵对话、教学 ComboMeter 与闪现能量门槛

## 需求

- 对话 UI 改为玩家头顶的白色云朵对话框。
- 教学关加入闪现、实时 ComboMeter 和闪现消耗教学。
- 教学与正式关均必须在 ComboMeter 足够时才能闪现。

## 实现

- 对话改为世界坐标云朵气泡，每帧跟随玩家头顶。
- 教学正式开始后在右上显示独立 ComboMeter，同步实时百分比和 Fever 剩余能量，并标注闪现踩拍 / 错拍消耗 `10 / 20`。
- 闪现前先根据当前节拍时机确定费用，再检查普通 ComboMeter 或 Fever 等价剩余能量。不足时闪现完全不启动，当前可见量表会红闪抖动。
- 教学 Shift 卡只有在闪现真正启动时才推进。

## 影响

- 删除旧的空表 `500ms` 闪现放行逻辑。
- 攻击积累、Fever 触发、闪现距离 / 时长 / 音波与清弹效果均不变。
