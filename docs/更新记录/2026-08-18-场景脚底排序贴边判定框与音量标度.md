# 2026-08-18：场景脚底排序、贴边判定框与音量标度

## 需求

- 环境物件按底边 Y 排序；镜头前探不露出场景外；判定框贴合屏幕边缘。
- BGM 实际响度减半但 BGM 控件仍显示 100%；Esc 的所有音量通道默认 100%、可调至 200%。
- 完整边缘粒子只在重拍判定正确时触发。

## 实现

- `PinkStageEnvironment.ts` 对 35 个正式关物件使用 `worldDepth((y + height) * scaleY)`，使物件、角色和敌人共用脚底深度排序。
- `cameraConfig.ts` 将基础 zoom 调为 `1.065`；`MainScene.ts` 设定画布大小的相机边界，并让活动区、判定框和 Fever 框完整覆盖 `1920 x 1080`。
- BGM 基础音量由 `1.0` 改为 `0.5`；八个 Esc 音量通道初始值均为 `100%`，最大值统一为 `200%`。
- 边缘粒子/光屑冲击改由正确重拍直接触发，轻拍不触发。

## 影响

- 不改变 BPM、判定时间窗、角色和敌人移动参数、输入映射、资源加载或 HUD 布局。

## 验证

- `npm.cmd run build` 通过，`git diff --check` 无空白错误；本地 `http://127.0.0.1:5173/` 返回 HTTP 200。
- 已在 Codex 内置浏览器进入教学场景，画布正常加载，镜头边缘未露出场外底色；Esc 面板八条滑杆均显示默认 `100%`。
- 轻/重拍的完整粒子差异已通过触发条件读回确认；BGM 的主观响度仍保留给实际试玩试听。

## 遗留

- 无已知遗留；需人工在实际操作中确认新的 BGM 主观响度。
