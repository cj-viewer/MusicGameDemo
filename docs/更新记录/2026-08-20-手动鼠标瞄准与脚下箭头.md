# 2026-08-20：手动鼠标瞄准与脚下箭头

## 需求

- 在角色脚下增加跟随角色移动、旋转指向鼠标的三角瞄准箭头。
- P Menu 可开启手动瞄准；关闭时保留原自动瞄准。
- 手动模式下，鼠标左 / 右键攻击都沿箭头方向出手。

## 实现

- `Player` 新增金白色三角箭头，只在手动瞄准开启且玩家存活时显示。
- 手动模式每帧把鼠标转换到主镜头世界坐标，并以角色脚底为起点计算瞄准角；攻击输入前再次刷新，避免使用上一帧方向。
- P Menu“模式 / 导出”页新增自动 / 手动瞄准开关，默认自动。开关同步进入本机配置保存与 TXT 导出。

## 影响

- 自动瞄准规则、节拍判定、轻重攻击伤害、武器表现和手柄输入均保持不变。
- 手动模式下所有攻击入口共享鼠标瞄准方向；箭头在关闭手动模式或玩家死亡时隐藏。
- 未新增运行时素材。

## 验证

- `npm run build` 通过。
- 按快速迭代要求未进入关卡试玩。

## 遗留

- 无。
