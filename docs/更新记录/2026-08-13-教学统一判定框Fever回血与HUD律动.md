# 2026-08-13：教学统一判定框、Fever 回血与 HUD 律动

## 需求

- 教学关移除底部节奏条，改为与后续流程一致的场地判定框。
- 判定框从 `0.7x`、完全透明开始，大小和透明度均使用 `easeInExpo`。
- Fever Time 正确输入恢复 `10 HP`；加强左上 HP 条节拍律动，并将攻击镜头缩放强度减半。

## 实现

- 场地三拍内框的激活状态覆盖教学、倒计时和正式游戏；教学 HUD 节奏条关闭，顶部连段与延迟校准 UI 保留。
- 内框从 `0.7x` / alpha `0` 出发，在未来 `3` 拍内以 `easeInExpo` 同步扩大、淡入，到边界即隐藏。
- Fever 正确输入调用 `Player.heal(10)`，并以 `100 HP` 为上限。
- HP 条轻 / 重拍改为 `0.84x → 1.26x`、`0.62x → 1.50x`；攻击镜头最高缩放改为 `1.0075x / 1.015x`。

## 影响

- 教学与实战的读拍提示完全一致；仍保留教学的连段进度和设备延迟校准。
- Fever 同时提供进攻与有限续航收益，满血时不会溢出。
- 更强的 HP 条弹性不改变实际生命比例；更弱的镜头律动减少持续 FOV 呼吸感。

## 验证

- `npm run build` 通过 TypeScript 和 Vite 生产构建。
- 本地浏览器确认：教学无底部节奏条、三框在教学与正式流程均可见；Fever 正确输入恢复 `10 HP`；HP 条振幅增强，攻击镜头推拉减半；控制台无 error / warn。

## 遗留

- Fever 回血与音乐节拍参数仍可在后续实机节奏测试中微调。
