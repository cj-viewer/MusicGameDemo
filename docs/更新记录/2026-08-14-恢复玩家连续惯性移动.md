# 2026-08-14：恢复玩家连续惯性移动

## 需求

- 撤回玩家节拍移动，人物移动恢复到此前的连续惯性手感。
- 保留敌人八方向固定射击。

## 实现

- `Player.update()` 恢复以 `1050 px/s²` 加速、`720 px/s²` 减速逼近 `260 px/s` 目标速度。
- 移除 P 面板中的“玩家节拍移动”开关，并恢复调参面板原有高度和五行布局。
- 移除 `MainScene.playerBeatMovementEnabled`，玩家不再读取节拍移动状态。

## 影响

- 玩家移动不再随拍内 `easeInExpo` 曲线改变速度。
- WASD、左摇杆、移动动画、自动瞄准前方扇区和闪避保持原规则。
- 敌人攻击仍吸附到最近的八方向扇区中线。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- P 面板恢复五行布局，不再显示玩家移动开关。
- 本地页面控制台无 error / warning。

## 遗留

- 无。
