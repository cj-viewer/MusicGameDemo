# 2026-08-18：教学操作卡顺序任务引导

> 历史版本记录：本页保留下列改动当时的行为；其中“重练 / R 从左键重新开始”已被后续的[开场标题图与教学卡会话去重](2026-08-18-开场标题图与教学卡会话去重.md)取代，当前规则以新记录和《实机落地与调整记录》的“当前实机规则”为准。

## 需求

- 第一关四张操作卡不再同时显示或自动轮巡。
- 按“鼠标左键轻攻击 → 鼠标右键重攻击 → Esc 设置 → L / R Shift 冲刺”逐项出现。
- 当前项完成后柔和淡出，再显示下一项；四项全部完成后不再出现。

## 实现

- `MainScene` 为四张操作卡增加独立的顺序任务状态，只允许当前步骤对应的真实操作推进。
- 首张卡延迟 `160ms` 后以 `280ms Sine.easeOut` 淡入；完成后以 `220ms Sine.easeInOut` 淡出，间隔 `100ms` 再淡入下一张。卡片保持 Photoshop 原坐标和 `320 x 64` 尺寸，不位移、不缩放。
- 鼠标左 / 右键必须实际产生轻 / 重挥击；Esc 只在打开设置时完成；L / R Shift 必须成功启动冲刺。`Quote / Enter` 与手柄仍执行原输入，但不代替卡面指定任务。
- 乱序输入和过渡期间的重复输入不缓存、不跳步，也不会被教学 UI 吞掉。
- Esc 打开设置会暂停 Scene Tween，因此先同步记录任务完成，关闭设置恢复场景后再继续 Esc 卡淡出与 Shift 卡淡入。
- 重练会从左键任务重新开始；进入完成页、按 `Space` 跳过、切到第二关、重开或关闭 Scene 时统一清理步骤、Tween 与待处理过渡。

## 影响

- 只改变第一关四张操作卡的显示和完成反馈，不改变攻击评价、节拍判定、设置暂停、冲刺条件、连续三小节教学完成规则、物理或第二关逻辑。
- 没有新增、删除或重新导出素材；图片数量、加载清单、UI 尺寸与位置保持不变。

## 验证

- `npm.cmd exec tsc -- --noEmit` 与 `npm.cmd run build` 均通过。
- 在 `http://127.0.0.1:5180/` 实机确认初始只有左键卡；提前右键仍执行重攻击但不跳步；按左键、右键后依次切换到下一卡；Esc 打开设置并在关闭后继续过渡；单独按 Shift 不推进，按住 WASD 方向输入 + L / R Shift 成功冲刺后四卡全部消失，等待 `6.5s` 也不再循环出现。
- `Space` 进入第二关后无教学卡残留，`R` 重开后从左键任务重新开始；教学卡与背景资源返回 HTTP `200`，浏览器控制台 `0 error / 0 warning`。

## 遗留

- 四卡仍使用 Photoshop 烘焙文字；若以后需要改变键位或加入动态完成标记，应由项目方重新提供可编辑 UI 或拆分文字层。
