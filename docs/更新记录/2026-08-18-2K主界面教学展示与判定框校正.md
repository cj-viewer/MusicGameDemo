# 2026-08-18：2K 主界面、教学展示与判定框校正

## 需求

- 升级 2K 显示，替换主菜单背景并将操作区置于左上。
- 校准保安警棍，修复重拍正确的边框偏移；全部判定框减半初始透明度并随扩张加粗。
- 教学池塘每小节展示一只不持武器、不攻击的粉丝。

## 实现

- 内部画布调整为 `2560 x 1440`，旧 UI 坐标按 `2x` 迁移；背景和环境物件按画布等比铺满。
- 新主菜单资源为 `public/assets/images/backgrounds/title/main-menu.png`；标题、英文副标题和开始按钮固定左上，片头视频仍铺满全屏。
- 保安警棍使用较小的 `0.6x` 相对倍率、右下握把 Origin 和双侧 `±45°` 基准角，挥击只围绕贴身竖直位置展开。
- 三拍预告从 Alpha `0.2` 起始，正确框从 Alpha `0.5` 起始；线宽均随扩张由 `1x` 过渡到 `1.5x`。重拍冲击的边框波和光带切换到屏幕坐标层。
- 教学粉丝使用被动展示模式，隐藏武器、停止位移和攻击，不加入正式敌人组。

## 验证

- `npm.cmd run build` 通过，`git diff --check` 通过，本地 `http://127.0.0.1:5173/` 返回 HTTP 200。Codex 内置浏览器已读回新主菜单和教学池塘：新背景全屏铺开，操作区在左上；池塘中心的粉丝没有武器且静止。2K 内部画布在当前 `1280 x 720` 浏览器中通过 FIT 正常显示。

## 追加：视差、锁定、Fever 发光与编队

- 主菜单增加背景 / UI 两层鼠标视差；保安警棍强制恢复可见并提高到本体前方。
- 教学粉丝每两小节刷新一次，无武器、不攻击但会追向玩家并加入自动锁定候选。
- Fever 橙色扇形和圆形音波增加 ADD、Glow 和 Bloom 自发光。
- 第二波开始每组固定为一粉丝两保安；第二波两组、第三波四组，第四、第五波分别六、八组。

## 追加：安全视差、两拍预告与保安警棍复校

- 主菜单背景额外放大为 `2560 + 96` 乘 `1440 + 64` 的逻辑显示尺寸，足以覆盖背景最大 `18 / 12px` 的鼠标视差；指针处于屏幕边缘或角落时不会露出底图外区域。
- 镜头前探死区收紧为 `3%`，维持 `45 / 30px` 最大偏移和 `220ms` 阻尼；角色移动时的镜头响应更早、更明显。
- 方形节拍预告只显示当前扩张拍和下一拍，整体线条加倍；命中框、Fever 框和重拍边缘冲击框也同步加粗。
- 保安本体显示比例提高 `1.25x`，警棍相对上一版提高 `1.5x`；武器握把锚点调整为 `(104/128,108/128)`，加暖色与轻度自发光，保持贴身、清晰且随朝向镜像。

## 追加：保安警棍表现、BGM 与后期编队修正

- 保安警棍恢复为无 Tint、无 Bloom 的普通原图显示；只保留原素材本身的正常颜色与透明度。
- BGM 的内部基础响度由 `0.5` 再减半至 `0.25`；设置面板仍显示默认 `100%`，并保留 `0–200%` 调节范围。
- 第 4、5 波总数仍为 `18 / 24`，但编队由三人组改为一粉丝一保安的二人组，分别为 9 / 12 对；第 2、3 波维持一粉丝两保安。

## 追加：贴身警棍与中央重拍粒子

- 警棍尺寸在当前基础上再增至 `1.25x`，朝左贴保安左侧、朝右贴保安右侧的贴图边缘；纠正左右镜像后的旋转符号，常态均为向朝向侧倾斜 `60°`，且武器在本体动画之后渲染。
- 正确重拍保留判定框四边原有光屑与四角星爆；额外在场景中央复制一朵 34 条橙白线状 ADD 粒子花，按节拍径向爆开并清晰淡出。

## 追加：警棍移动攻击平滑化

- 持续按下 WASD 使用警棍时，角色本体不再被攻击动画锁帧，跑步动作和物理移动保持连续；警棍挥击、攻击特效、伤害与节拍反馈均维持原样。站定攻击保留完整轻、重攻击动画。

## 追加：警棍连续挥击帧时间优化

- 弧线扫击由双层 ADD 描边绘制，移除每条弧线独立的 GPU Glow / Bloom 过滤器和逐帧尾迹；正确警棍攻击不再触发主镜头缩放回弹。扫击层数、范围、碰撞和伤害均不变，重点消除连续攻击时对移动观感的拉扯和卡顿。

## 追加：警棍旋转与物件顶部节拍花

- 警棍在当前朝向姿态上顺时针再转 `90°`，左朝向视觉为左上；保持贴近贴图边缘且后置渲染。
- 重拍判定框终态线宽收至之前的 `75%`；原有的边框光屑和四角星爆保留。
- 场景中央的正确判定粒子花改为每个正式场景物件顶部的常驻小型线状花，任何节拍均触发，三轻拍小、重拍大。

## 追加：警棍源朝向、菜单信息组与随机烟花粒子

- 警棍常态改为直接使用素材的左上方向，左朝向左上、右朝向镜像为右上，不再叠加错误旋转。
- 主界面将标题、副标题和开始按钮居中收拢在同一个左上圆形信息组内。
- 正确重拍框粒子中随机少量升级为更大、更亮、更远的线状烟花主束，其余保持细小。
