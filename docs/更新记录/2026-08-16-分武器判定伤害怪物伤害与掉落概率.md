# 2026-08-16：分武器判定伤害、怪物伤害与掉落概率设置

## 需求

- 在设置中分别调整每把玩家武器的 Perfect / Good / Poor 判定伤害。
- 分别调整当前保安、粉丝的弹幕伤害。
- 分别调整荧光棒、警棍的掉落概率。

## 实现

- Esc 面板右侧战斗参数改为“速度 / 频率”和“伤害 / 掉落”两个分页；隐藏分页不显示也不接收按钮输入。
- 荧光棒、警棍各自增加 Perfect / Good / Poor 伤害倍率，默认 `120% / 100% / 50%`，范围 `0–300%`、步进 `10%`。实际武器伤害按“原该拍基础伤害 × 判定倍率 × ComboMeter 倍率”结算。
- 保安（含未启用 MidGuard）和粉丝弹幕伤害默认均为 `12`，范围 `0–100`、步进 `1`。新生弹幕读取当前值，设置调整时同步改写已在场的对应敌弹。
- 警棍、荧光棒掉落概率默认均为 `100%`，范围 `0–100%`、步进 `5%`。仍先执行“玩家已持有 / 场上已有同种掉落”的去重规则，再做概率判定。
- 掉落边界显式处理：`0%` 必不掉、`100%` 必掉，中间概率逐次独立掷骰。

## 影响

- Perfect 现在默认比原基础伤害提高 `20%`，Poor 默认只保留 `50%` 基础伤害；Good 保持原伤害。
- 只改变玩家武器单发 / 单段伤害，不改变弹丸数量、ComboMeter 能量、判定窗口、Fever 音波或闪避音波。
- 怪物伤害设置只改变敌弹命中伤害，不改变怪物 HP、弹速、攻击间隔或移动速度。
- 掉落类型绑定保持不变：保安掉警棍、粉丝掉荧光棒。

## 验证

- `npm run build`：TypeScript 类型检查与 Vite 生产构建通过。
- Chrome DevTools 真实点击“伤害 / 掉落”分页后，速度页隐藏且 16 个交互项全部禁用，伤害页显示且 20 个交互项全部启用；默认文字为两把武器 `120% / 100% / 50%`、怪物 `12 点`、掉落 `100%`。
- 保安伤害由 `12` 点击提高至 `13` 后，场上既有保安弹的 `damage` 同步由 `12` 变为 `13`；回调后恢复 `12`。
- 荧光棒 Perfect 点击提高到 `130%` 后，基础伤害 `10` 的单发实测为 `13`；恢复默认后 Poor 单发为 `5`。警棍基础伤害 `12` 的默认 Perfect 单段实测约为 `14.4`。
- 实际调用击杀掉落链路验证：警棍与荧光棒均在 `0%` 时生成数为 `0`、在 `100%` 且通过去重时生成数为 `1`。
- 设置关闭后读回 `panel=false / paused=false`，本轮交互期间没有新增 Runtime exception 或 Log error。

## 遗留

- 参数当前为本局运行时设置，刷新页面后恢复默认值；本轮未新增本地持久化。
