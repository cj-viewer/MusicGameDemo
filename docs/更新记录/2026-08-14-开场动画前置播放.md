# 2026-08-14：开场动画前置播放

## 需求

- 玩家进入页面后先看到游戏标题页，点击开始后带原声播放 `intro.mp4`，播完后再进入现有开始页和教学流程。

## 实现

- 新增 `IntroScene`，使用 `import.meta.env.BASE_URL` 预载 `public/assets/video/intro.mp4`。
- 视频前显示主标题“节奏星球”、副标题“DJ Drop the Beat”和“开始”按钮。
- 只在玩家点击按钮后播放视频，显式设置为非静音、`1.0` 音量，保留 MP4 原音。
- 视频按原比例在 `1280 x 720` 黑色画布中居中显示，播完后切换到 `MainScene`。
- 若媒体仍被浏览器锁定，恢复按钮并提示“点击继续”。
- 视频解码失败时直接进入原开始页，避免流程卡死。

## 影响

- 开局流程变为：游戏标题页 → 带原声开场动画 → 原开始页 → 教学。
- 教学 BGM、节拍时钟和玩法参数不变。

## 验证

- `npm run build` 通过 TypeScript 和 Vite 生产构建，`dist/assets/video/intro.mp4` 完整生成。
- 本地服务器首页和 `/assets/video/intro.mp4` 均返回 `200`，视频 `Content-Type` 为 `video/mp4`，长度 `16285258` 字节。
- 当前环境无浏览器自动化工具，实际画面、声音和播完切换待人工目视确认。

## 遗留

- 开场视频的版权/授权信息由素材提供者确认；对外发布前应补入资源授权表。
