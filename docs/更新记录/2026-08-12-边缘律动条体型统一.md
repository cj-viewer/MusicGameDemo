# 2026-08-12：边缘律动条体型统一

## 需求

- 每根边缘律动条的体型差异不要过大。
- 宽度保持近似，高度只做轻微区分。

## 实现

- 宽度由 `14–30px` 收敛为 `20–24px`。
- 左右两侧高度改为 `30–42px`，下侧高度改为 `28–38px`。
- 数量、位置随机、重叠、颜色、完全不透明和轻重拍动画保持不变。

## 影响

- 静态边缘轮廓更统一，不再出现特别细、特别宽或高度差异过大的单条。
- 群体仍有轻微自然错落，不会变成完全机械的等高栅栏。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地实机确认宽度近似、高度轻微错落，重拍跳动后下侧仍基本位于预留带内。
- 浏览器控制台无 error / warn。

## 遗留

- 当前位置仍会在每次运行时随机；若需固定构图，可后续加入固定随机种子。
