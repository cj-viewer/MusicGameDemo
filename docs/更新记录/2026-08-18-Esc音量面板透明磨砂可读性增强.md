# 2026-08-18：Esc 音量面板透明磨砂可读性增强

## 需求

- 保留 Esc 大音量面板的透明、轻盈与白线设计感。
- 压低面板后方的教学卡、HUD 和背景文字，避免后景文字与面板标签叠读。
- 四张教学操作卡继续只按既有顺序运行一轮，本轮不修改教学状态机。

## 实现

- 全屏遮罩使用 `0x071714 / 0.20`。
- 面板后方增加 `0x04100e / 0.20` 的单层柔影，并启用 `Blur(1, 10, 10, 0.45, 2)`。
- `600 x 650` 面板依次叠加 `0x172421 / 0.72` 隐私底与 `0x233a36 / 0.46` 主雾面。
- 雾面顶部使用 `0xeaf5ef / 0.08`、底部使用 `0x78968d / 0.02` 的轻渐变；外框 / 内框 Alpha 为 `0.68 / 0.22`。
- 层级固定为“全屏遮罩 → 柔影 → 隐私底 → 主雾面 → 轻渐变 → 框线 → 文字与控件”，保证后景文字被压低而前景标签保持清晰。

## 影响

- 这是 Phaser 图形、渐变与对象级柔影组成的程序化磨砂近似，不捕获场景，也不是真实 `backdrop blur`。
- 没有新增图片、字体或其他运行时资源；Loader 项数、资源数量与体积统计不变。
- 八路音量的默认值、范围、滑杆 `28px` 透明点击热区、点击 / 拖动、百分比反馈、暂停恢复和 Esc 开关均不改变。
- Esc 仍只打开八路音量设置；速度 / 频率、伤害 / 掉落、教学 / 正式关 BGM 槽、FPV 与敌弹节拍突进仍由 P 调参面板承载。

## 验证

- `npm.cmd run build` 通过。
- 在 `http://127.0.0.1:5180/` 第一关让教学卡位于面板后方，再打开 Esc：面板标题、八路标签和百分比清晰，教学卡文字只保留不可叠读的弱轮廓。
- 在第二关复杂背景上打开 Esc：场景原色仍有少量透入，没有明显偏绿 / 偏蓝染色或背景文字叠读。
- 点击与拖动八条滑杆时，数值、滑块和填充同步；再次按 Esc 后从暂停帧继续。浏览器控制台无 error / warning，网络面板无新增资源请求。

## 遗留

- 当前方案不做真实背景采样与动态模糊。如以后改为 CaptureFrame、RenderTexture 或独立 PSD 切图，应重新评估 WebGL / Canvas 兼容、1920 × 1080 性能、暂停与重开生命周期，以及资源许可和加载清单。
