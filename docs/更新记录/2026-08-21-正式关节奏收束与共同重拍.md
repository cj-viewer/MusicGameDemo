# 2026-08-21 正式关节奏收束与共同重拍

## 目标

减少正式战斗中同时争夺注意力的独立计时系统，让刷怪、场景律动、长按攻击、闪避奖励和完整连招围绕同一套四拍网格工作。教学关不做改动。

## 实现

- 正式关每小节首拍播放低频重音，玩家、普通敌人、17 个白名单场景物件、HUD 与 FPV 同时使用重拍脉冲。
- 普通正确重击只保留短时判定框；完整四拍 Pattern 的最后一步统一触发双层合成收尾音、场景 / HUD / FPV 重拍和边缘粒子爆发；玩家与敌人的共同重拍固定由小节首拍驱动。
- 所有波次首批与后续批次改为等待小节首拍生成；P Menu 的秒数间隔先换算为完整小节数。
- 正式关警棍长按按照当前 BPM 量化为整数每拍发数，每发严格落在拍内等分点；教学继续使用原自由计时。
- 正式关闪避改为 `700ms` 独立冷却且不消耗 ComboMeter；踩拍闪避释放清弹 / 伤害音波，错拍闪避只提供基础位移与无敌。教学继续使用原 ComboMeter 消耗和音波规则。

## 文档校正

同步代码中的当前默认值：警棍长按 `7.0 次/秒`，波次批量 `2–5` 名、间隔 `2–4s`，Boss 体型 `4x`，教学踩拍 / 错拍闪避消耗 `5 / 20`。当前 Fever 扫屏为 `760ms`，Boss 波清空后冻结胜利，不再循环 Wave 5。

- `npm run build`：通过。
- 浏览器正式关节奏与操作差异：待本轮实机验收。
