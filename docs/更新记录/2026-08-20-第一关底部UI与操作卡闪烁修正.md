# 2026-08-20：第一关底部 UI 与操作卡闪烁修正

## 需求

- 第一关底部两组石子不能作为 UI 前景层绘制。
- 第一关底部 ComboMeter / 武器面板需要对齐最新红框目标区域。
- 第一关左侧四张操作卡需要在对应输入发生时闪一下：左键、右键、Esc、L / R Shift。

## 实现

- `MainScene` 不再把 `tutorial-bottom-rocks` 加入教学 UI 容器；石子不再作为 UI 面板的一部分覆盖画面。
- 第一关底部状态条改为独立布局 `268 x 42` 设计单位，整体仍为 `87%`，位置改到最新红框目标区域；武器名、百分比和进度圆环仍读取实时数据。
- 第一关与第二关底部状态条的圆形百分比、中心分割线和武器文字改为按面板宽度自动对半排布：圆形位于左半区中心，文字位于右半区中心，不再使用手调偏移，避免文字出框。
- 四张操作卡增加一次性浅色闪光层：鼠标左键闪第一条，鼠标右键闪第二条，Esc 打开设置时闪第三条，L / R Shift 按下时闪第四条。

## 影响

只改变底部 UI 绘制层级、位置、对齐方式和提示闪光；不改变攻击判定、节拍判定、设置暂停、闪避条件、教学完成条件、ComboMeter、武器切换、伤害、物理或第二关逻辑。

## 验证

- `npm.cmd exec -- tsc --noEmit` 与 `npm.cmd run build` 已通过；`git diff --check` 无错误。
- 本地服务 `http://127.0.0.1:5180/` 返回 HTTP `200`。浏览器需硬刷新后确认第一关底部石子不再作为 UI 层出现、底部状态条落在红框区域内、四张操作卡按对应输入闪一下且不改变教学逻辑。

## 遗留

无。
