# 2026-08-16：敌人纵向律动、评价层级与 BGM 默认音量

## 需求

- 放大敌人的节拍缩放幅度，但不允许横轴缩放。
- 将角色位置生成的攻击准确度评价渲染到角色本体之后。
- BGM 默认响度在当前默认有效值基础上提高 `1.5x`，并把 Esc 面板的 BGM 默认显示归一为 `100%`。

## 实现

- 后续调整为玩家、保安、粉丝和预留中型保安统一使用脚底锚定的 Y 轴上弹：轻拍升至基础高度 `105%`、重拍升至 `110%`，再分别在 `170ms / 220ms` 内恢复，绝不低于基础高度。横轴始终保持基础比例，因此左右朝向镜像不受律动影响。
- `PERFECT / GOOD / POOR` 浮字在创建时写入玩家 Sprite depth 减 `0.004`，使浮字在角色本体之后，仍保留现有弹起、停留和上浮淡出效果。
- BGM 滑杆初值改为 `100%`；内部基础音量由 `0.0375` 调为 `0.084375`。旧默认 BGM 实例响度为 `0.0375 × 1.5 = 0.05625`，新默认为 `0.084375 × 1.0 = 0.084375`，恰为 `1.5x`；默认 `150%` 主音量继续同时作用于两者。

## 影响

- 角色与敌人的跟拍更可见，脚底不漂移，且不会横向拉伸、干扰贴图镜像、碰撞体或移动方向。
- 攻击准确度反馈不再压住角色、武器或出手画面。
- 新开页面时 Esc 的 BGM 滑杆显示 `100%`，实际默认 BGM 比上一版更响；BGM、主音量与其他音效分类仍可独立调节。

## 验证

- 执行 `npm.cmd run build`。
- 本地页面检查玩家和敌人的轻 / 重拍均为脚底锚定的纵向果冻，左右转向时宽度和镜像稳定；攻击时准确度浮字位于玩家本体后方；Esc 初次打开显示 BGM `100%`，试听确认 BGM 默认提高。

## 遗留

- 默认响度的主观听感仍以实际设备试听为准；如需微调，应只调整 `BGM_VOLUME`，保持 Esc BGM 默认显示 `100%`。
