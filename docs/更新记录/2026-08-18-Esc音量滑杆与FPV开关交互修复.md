# 2026-08-18：Esc 音量滑杆与 FPV 开关交互修复

## 需求

- 修复 Esc 音量面板已经显示，但九路滑杆与 FPV 开关无法响应鼠标的问题。
- 保证主镜头发生前探或偏移后，Esc 音量面板与 P 调参面板的可见控件仍与实际输入热区重合。
- 只修复 UI 命中，不改变音量路由、数值范围或暂停规则。

## 实现

- Esc 音量面板和 P 调参面板统一使用与主镜头相同的 `scrollFactor=1`。
- 每次打开面板时，将对应容器重新锚到 `camera.scroll + CAMERA_BASE_SCROLL`，使面板渲染位置与每个子控件的输入命中使用同一相机变换。
- 九路音量滑杆继续支持直接点击轨道和按住连续拖动；原有更新路径同步刷新百分比文字、填充长度、滑块位置和实际音量。
- FPV 开关点击后立即刷新“已开启 / 已关闭”文字与按钮颜色，关闭面板后由当前开关状态决定观察窗是否显示。

## 影响

- 只改变 Esc / P 面板的容器滚动因子、打开时锚点和由此恢复的 UI 命中。
- 九路音量的默认值、上限、分类路由与叠乘关系不变；FPV 尺寸、位置和投影逻辑不变。
- Conductor、BGM、物理、动画、补间、敌人调度、教学与玩法输入的暂停 / 恢复顺序不变；面板自身的滑杆、按钮和 FPV 开关在暂停期间继续响应，且不会提交攻击输入。
- 没有新增或修改运行时资源、Loader 项、P 参数或 TXT 键。

## 验证

- 已复核代码路径：两个面板都使用 `scrollFactor=1`，并在每次打开时按主镜头滚动位置重新锚定；滑杆与 FPV 开关继续调用既有数值 / 状态更新函数。
- `npm.cmd run build` 与 `git diff --check` 均通过。
- 在 `http://127.0.0.1:5180/` 硬刷新后进入教学与正式关：九路滑杆逐项点击均会立即更新百分比、填充和滑块位置；BGM 滑杆连续拖动可从 `100%` 平滑变到 `160%`，松开后不粘连。
- FPV 按钮已实测“已开启 → 已关闭 → 已开启”；关闭 Esc 面板后，正式关观察窗会按当前状态隐藏或恢复。P 面板按钮可命中，P → Esc 切换后音量面板仍可交互。
- 面板打开期间主场景保持暂停，点击设置控件未提交攻击；关闭后主场景继续运行。浏览器控制台只有 Vite / Phaser 启动信息，`0 error / 0 warning`。
