# 2026-08-14：混音再平衡与 ComboMeter 闪避

## 需求

- BGM 响度缩放到上一版的 `75%`，轻拍叫喊提升到上一版的 `150%`。
- 闪避不再消耗体力，改为根据是否踩拍消耗 ComboMeter。
- 闪避距离翻倍、时间缩短到 `70%`，并在过程三分之二处释放 Fever 同款圆形清屏。

## 实现

- BGM 内部基础音量由 `0.05` 改为 `0.0375`；轻拍叫喊由 `0.28` 改为 `0.42`，重拍保持 `0.28`。
- 闪避距离由 `80px` 改为 `160px`，时长由 `200ms` 改为 `140ms`。
- 拍点前后 `0.12s` 内判为正确闪避，扣 `10` 点（半级）；窗口外扣 `20` 点（一级）。Meter 不足时最低扣到 `0`，不阻断闪避。
- Fever 激活期间，相同消耗映射为缩短 `1.6 / 3.2` 拍剩余时间，并立即刷新倒计时环。
- 删除玩家体力字段、每拍回复、体力环与“体力不足”提示。
- 每次闪避约在 `93ms` 释放重拍 Fever 同款 `190px` 全圆波；波前负责清弹和单次敌人伤害，不再奖励 ComboMeter。

## 影响

- 闪避成为更远、更快但会消耗进攻资源的基础生存动作；空表仍能闪避，避免完全失去防御能力。
- 清屏不再依赖踩拍，但踩拍能把资源成本减半。
- 设置面板 BGM / 音效百分比范围与默认显示值均不改变。

## 验证

- `npm.cmd run build` 通过 TypeScript 检查与 Vite 生产构建。
- 本地浏览器进入教学后，以移动 + Shift 触发闪避；画面确认角色约 `160px` 位移，途中出现完整橙色圆形波前，控制台 `0 error / 0 warning`。
- 自动化时 ComboMeter 为 `0`，已确认空表仍可闪避；`10 / 20` 点扣除和 Fever 时长折算由代码路径与 TypeScript 检查确认。音量主观平衡仍需人工试听。

## 遗留

- 正确 / 错误闪避当前只按节拍窗口判断，不要求敌弹擦身或实际规避伤害。
