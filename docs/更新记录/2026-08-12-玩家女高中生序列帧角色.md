# 2026-08-12：玩家女高中生序列帧角色

## 需求

- 将玩家由静态 `player.png` 替换为像素女高中生序列帧角色（jf_dev 分支的角色工作合入 dev-1.0）。
- 其余玩法、音频、节拍与工程规则全部以 dev-1.0 现状为准，不引入 jf_dev 的音乐系统。

## 实现

- 素材：Anime Schoolgirl Sprite Sheet BASIC（Dlou Saiyan，120x120 网格）按《资源与素材规范》逐帧裁切校准后接入：
  - `idle` 2 帧、`run` 4 帧统一内容高度 `55px`，脚底基线在帧底边；`down` 倒地单帧 `72 x 15px`。
  - 运行时目录 `public/assets/images/characters/player/{idle,run,down}/`，旧 `player.png` 移除。
- 缩放基准：旧静态玩家可见高度约 `63.6px`（`79.5px x 0.8`），新角色缩放约 `1.156x` 保持同一可见占比；受击判定沿用"全帧矩形"设计，世界尺寸约 `24 x 64px`（角色更瘦，判定同步变窄）。
- 新增 `src/game/playerAnimation.ts`：动画注册、缩放常量与动作切换（idle/run/down），玩家纹理单独使用 NEAREST 过滤保持像素锐利，不改全局渲染配置。
- `Player`：改用 Sprite；移动/闪避时播放 `run`，静止播放 `idle`；素材朝右、瞄准左侧时 `setFlipX` 翻转（与警棍持有侧逻辑一致）；每拍轻微蹲弹（`1.06x / 0.95x`，`150ms`）；战败切换倒地帧并隐藏手持武器；闪避拖尾由绿色圆点改为角色残影（青色调、`0.55` 透明度、跟随 TopDown 深度）。
- 武器示意跟随鼠标（按实机反馈迭代两版后定稿）：握把固定在瞄准线起点（角色中心向瞄准方向约 `16.8px`），棒身实时指向鼠标方向、与白色瞄准短线重合。荧光棒由左右对称双棒简化为**单根红棒**（`24 x 6px`），警棍为单根紫棒（`40.8 x 7.2px`）。挥击时从偏转角在 `200ms` 内收敛回瞄准线，无结束跳变。原"待机武器不跟随鼠标角度旋转"规则由本次需求取代。
- 工程：`.claude/launch.json` 的 `runtimeExecutable` 由硬编码 node 路径改为 `node`（PATH 解析，跨机器可用）。

## 影响

- 玩家外观、拖尾与战败表现变化；受击判定盒由约 `43 x 66px` 变为约 `24 x 64px`（更贴合可见角色，被弹幕命中难度略降）。
- 武器示意不再左右对称悬空，改为握在瞄准线上跟随鼠标；仅视觉表现变化，弹幕攻击覆盖范围与挥击时长不变。
- 移动、闪避、攻击、连段、音频、HUD、敌人与波次规则不变。

## 验证

- `npm run build` 通过 TypeScript 检查与 Vite 生产构建。
- 本地实机确认：待机/移动动画与朝向翻转正确、踩拍蹲弹生效、闪避残影与倒地姿势正常、资源无 404、控制台无 error / warn。
