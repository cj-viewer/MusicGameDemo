# 2026-08-15：回滚 NPC 美术目录清理并建立资产索引

## 需求

- 读取远端 `90b3adc`“美术资产目录清理”提交，并回滚其中的美术目录分类。
- 保证所有现有美术资源仍在正确类别下，运行时加载路径可追溯。

## 实现

- 审计确认 `90b3adc` 只将正式粉丝和安保的动作目录从 `npc/<角色>/<动作>/` 移至 `npc/<角色>/animation/<动作>/`，并删除了一个空占位文件。
- 选择性恢复 65 个 NPC PNG / GIF 文件到无 `animation/` 中间层的原动作目录；不恢复已删除的 `placeholder.txt`，避免重新引入无运行时价值的占位资产。
- `fanAnimation.ts` 和 `guardAnimation.ts` 同步改为新的权威路径，保证粉丝 Run / Light / Hard 与安保 Light 特效仍可被 Phaser 预加载。
- 新增 `docs/美术资产索引.md`，列出 160 个图片 / GIF 资源的顶层分类、角色动作分类、运行时引用和旧素材状态。

## 影响范围

- `public/assets/images/characters/npc/npc_fan01/`
- `public/assets/images/characters/npc/npc_guard01/`
- `src/game/fanAnimation.ts`
- `src/game/guardAnimation.ts`
- `docs/资源与素材规范.md`、`docs/美术资产索引.md`、文档和更新索引。

## 验证

- 文件数量保持 65 个 NPC 美术文件；动作帧与预览 GIF 均未删除或覆盖。
- `npm.cmd run build` 通过后，浏览器本地预览确认无资源 404、error 或 warning。
- 代码搜索确认正式 NPC 不再引用 `npc_fan01/animation/` 或 `npc_guard01/animation/` 的旧目录。

## 遗留

- 旧玩家、旧粉丝和未接入的保安武器均已在索引中标为来源素材；除静态 `guard.png` 外不会被当前波次加载。清理这些旧素材必须在确认授权、历史追溯和后续替换计划后另行处理。
