# 2026-08-14：胜利场景化、无限轮次与踩拍冲刺震荡波

## 需求

- `VICTORY` 使用纯色背景并放到所有场景元素之下，融入场景色调。
- 无限第五波继续累计波次编号，形成轮次记录。
- 正确踩拍冲刺释放缩小版 Fever 全圆音波，可伤害敌人并清除敌弹。

## 实现

- `VICTORY` 改为低饱和淡紫文字，添加 `430 x 116px` 深紫纯色背板；背板 / 文字 depth 为 `0.2 / 0.21`，低于场地框、角色、敌人、弹幕和 HUD。循环波次中它们继续随拍呼吸：轻 / 重拍背板缩放 `1.025x / 1.045x`，文字缩放 `1.06x / 1.10x`。
- 新增独立显示轮次计数。前五波显示 `Wave 1–5`；无限循环第五波时依次显示 `Wave 6、Wave 7……`，实际敌人配置继续使用第五波的 `32` 只。
- 冲刺耗时由 `300ms` 缩短为 `200ms`，距离仍为 `80px`。踩拍冲刺终点不再使用独立震荡环，直接复用 Fever 全圆音波的橙色波前、音效、逐帧清弹和单次伤害逻辑；仅把作用半径由 `190px` 减半为 `95px`。错拍冲刺不产生音波。

## 影响

- 胜利提示不再遮挡战斗对象，成为持续挑战时的场景背景标识。
- Wave 数字可作为无限模式的基础冲榜轮次；暂未加入本地/在线排行榜存储。
- 冲刺距离、持续时间、体力消耗、无敌与踩拍窗口保持不变。

## 验证

- `npm.cmd run build` 必须通过。
- 浏览器确认 VICTORY 背板与文字位于角色、弹幕和 HUD 下层。
- 模拟连续生成第五波，确认顶部显示从 `Wave 5` 递增到 `Wave 6`。
- 在玩家附近生成敌人与敌弹，触发踩拍冲刺音波后确认敌人按 `14 × Combo 倍率` 扣血、敌弹被清除；范围外对象不受影响。
- 实机校验通过：首次清空第五波时为 `intermission + Wave 5 + VICTORY visible`；`2.15s` 后为 `playing + Wave 6 + 32 enemies`，VICTORY 继续显示。层级读回为背板 `0.2`、文字 `0.21`、场地框 `1`、敌人约 `2.12`、弹幕 `4`、HUD `10`。
- 实机复测通过：胜利背板 / 文字的轻拍瞬时缩放为 `1.025 / 1.06`，重拍为 `1.045 / 1.10`；`Wave 6` 的 32 只真实敌人循环正常。Combo 倍率为 `1` 时，`95px` 内真实敌人扣 `14 HP`；两枚测试敌弹仅保留 `95px` 外的一枚。控制台 `0 error / 0 warning`。

## 遗留

- 当前仅提供累计 Wave 轮次，排行榜持久化和玩家榜单尚未实现。
