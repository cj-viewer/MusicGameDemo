# 2026-08-16：错误输入弱化与 Fever 三向攻击

## 需求

- 错误输入时，两把武器都只保留一条攻击；荧光棒的长度和飞行距离减半，警棍的弧段长度和扫击覆盖角减半。
- 荧光棒按每 1 级 Combo 增加 1 发、最多 5 发；警棍按每 2 级 Combo 增加 1 段、最多 3 段。
- Fever 中在当前瞄准方向外，增加左后方、右后方两个等间隔攻击方向。

## 实现

- `MainScene.performWeaponAttack` 以正确输入、错误输入分别计算数量和缩放；错误输入仍播放实际按下的轻 / 重攻击动画和音效，不会串用目标节拍类型。
- 荧光棒错误弹丸以相同速度飞行，按“当前时刻至正常销毁拍”的剩余距离计算半程销毁，同时把视觉和三段直线判定盒长度缩至 `50%`。
- 警棍错误扫击仅保留中层，将弧段长度与轻 / 重扫击的覆盖半角均乘 `0.5`；半径、方向和 `150ms` 生命周期不变。
- 正确攻击的数量改为：荧光棒 `min(5, level + 1)`，警棍 `min(3, 1 + floor(level / 2))`。Fever 内的正确输入将同一组攻击复制到 `0° / +120° / -120°` 三个方向；原有 Fever 音波只触发一次。

## 影响

- 错误输入保留最低限度的攻击反馈，但射程、覆盖和压制能力显著降低。
- Combo 对两种武器的成长曲线不同：荧光棒更连续，警棍每两级增加一层。
- Fever 的三向攻击会为每个方向完整生成其当前 Combo 对应的弹幕 / 弧段层数。

## 验证

- `npm run build` 通过。
- 运行时验收：分别在 Combo 等级 `0–5`、普通状态和 Fever 状态下确认数量、错误输入缩放、三方向间隔与命中行为。

## 遗留

- 本次不改变伤害、击退、Fever 音波伤害、武器挥击动画或 Combo 获取规则。
