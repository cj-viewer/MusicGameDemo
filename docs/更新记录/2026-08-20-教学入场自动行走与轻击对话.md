# 2026-08-20：教学入场自动行走与轻击对话

## 需求

- 教学开始时不显示 UI，且玩家不能操作主角。
- 主角从左边自动走到中间偏左，然后显示三句对话。
- 鼠标左键或键盘轻击键推进对话，对话结束后再显示现有教学 UI。

## 实现

- `MainScene` 在原教学流程前新增自动行走和对话两个状态。
- 主角以 `2.8s` 补间从活动区左侧走到画面中间偏左，期间播放跑步动画并锁定所有玩家操作。
- 到位后显示粉紫半透明对话框，按需求原文依次显示三句台词；鼠标左键或 `Quote` 键逐句推进。
- 第三句结束后对话框淡出，再调用原教学初始化，恢复操作并显示原有 PSD UI、操作卡和教学角色。

## 影响

- 只改变进入教学时的前置节奏；原有教学连招、延迟校准、教学完成确认和正式关流程不变。
- 教学前置阶段同时隐藏 FPV 和手动瞄准箭头，Esc / P 不会打开设置。

## 验证

- `npm run build` 通过。
- 按快速迭代要求未进入教学关试玩。

## 遗留

- 未做主观观感调整；入场时长、站位和对话框细节可在后续实机观看后微调。
