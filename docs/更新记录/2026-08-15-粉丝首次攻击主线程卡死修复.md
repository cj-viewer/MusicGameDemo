# 2026-08-15：粉丝首次攻击主线程卡死修复

## 需求

- 修复敌人出现后、可能正要第一次攻击时整局卡死的问题。

## 定位

- Wave 1 出生和前三拍均正常，粉丝已按 `66 px/s` 移动。
- 第一次第 4 拍中，保安弹幕已完成生成；主线程随后停在粉丝 `playFanAttackEffect()` 内，无法执行特效调用后的下一行。
- 因此卡死与出生位置、初始速度、碰撞、敌弹或 FPV 无关，准确触发点是粉丝 Hard 特效的 Phaser Animation `.play()`。

## 实现

- 移除粉丝 Light / Hard 独立特效的 Phaser Animation 注册与 `.play()` 路径。
- `playFanAttackEffect()` 改用场景时钟，将 Hard 的 `02–07` 六帧等分到原 `500ms` 总时长内逐张切换。
- 重复触发会先移除上一次计时器，最后一帧结束后自动隐藏 Sprite；粉丝本体 Run 动画保持不变。

- Wave 1 两名敌人继续移动，场上累计出现 4 枚敌弹，未再次锁住主线程。
