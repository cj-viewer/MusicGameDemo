# 2026-08-12：武器挥击、警棍持有侧与弹速

## 需求

- 手持武器在 `0.2s` 内完成挥击，不再卡下一拍。
- 警棍根据瞄准左右瞬时切换到角色对应一侧。
- 略微提高荧光棒弹幕速度。

## 实现

- 荧光棒和警棍的挥击 Tween 固定为 `200ms`；连续攻击仍会停止并重启旧 Tween。
- 警棍挂点按当前瞄准半平面设为角色中心左 / 右 `17px`，待机和挥击期间均每帧更新。
- 荧光棒直线弹速从 `320 px/s` 提高到 `360 px/s`。

## 影响

- 挥击表现不再因攻击发生在拍点前后而改变时长。
- 警棍只切换持有侧，不跟随瞄准角度持续旋转；弧形攻击轨迹与命中范围不变。
- 弹幕速度提高 `12.5%`，数量、扇区、寿命、伤害和击退不变。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地试玩可启动；攻击后约 `200ms` 恢复待机武器布局，浏览器控制台无 error / warn。

## 遗留

- 警棍左右瞬切的视觉自然度和 `360 px/s` 弹速仍需人工试玩确认。
