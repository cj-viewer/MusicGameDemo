# 2026-08-16 / 闪避拖影 10ms 连续采样

## 需求

- 角色闪避向前位移时，拖影应连续生成，初始采样间隔设为 `0.01s`。

## 实现

- `Player` 的 `DODGE_TRAIL_INTERVAL_MS` 从 `30ms` 调整为 `10ms`。
- 每帧更新会补齐本帧跨过的全部 `10ms` 采样点，并按闪避的 `Quint.easeOut` 位移曲线插值得到各自位置；不会受 `60fps` 等渲染帧率限制而退化为约 `16.7ms` 一次，也不会把补齐的多张残影堆在当前角色位置。
- 拖影仅覆盖实际 `140ms` 位移过程；Dash 动画在位移结束后保留的 `100ms` 收势不生成新的残影。

## 影响

- 单次完整闪避固定产生起点及 `10–140ms` 的共 `15` 个角色残影，使 `160px` 位移段的视觉连接更连续。
- 位移、无敌、Dash 动画总时长、ComboMeter 消耗与踩拍音波规则均不改变。

## 验证

- `npm.cmd run build`
- 实机连续触发左右 Shift：位移段应形成连续残影，停止位移后只保留既有残影淡出，不继续产生新残影。
