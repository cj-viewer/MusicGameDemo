# 2026-08-19：教学角色与战斗表现修正

## 需求

- 修正教学角色朝向，重复生成前让当前角色死亡退场，并支持玩家攻击；刷新周期改为 16 拍。
- 移除底部 HUD 的 `ComboMeter` 字样；提高闪避 / Fever 音波自发光；让场景小粒子随拍产生自发光起伏。
- 掉落武器改为实际贴图，并保留闪白、增加律动发光环；让保安阴影随朝向并略向下偏移。

## 实现与影响

- 教学角色翻转规则统一为右朝向镜像，加入玩家攻击判定组；死亡仅播放死亡退场，不结算正式波次、掉落或击杀事件。每 4 小节（16 拍）先退场，`220ms` 后生成新角色。
- `ComboMeter` 标签隐藏，数值与进度圆环保留。闪避及 Fever 圆形 / 扇形音波的 Glow、Blur 和 Bloom 提高，但清弹范围、伤害和时序不变。
- 35 组场景粒子花新增随拍变化的 Glow；掉落荧光棒 / 警棍改为对应玩家武器贴图，仍在每拍闪白，并以发光圆环律动。
- 保安阴影沿当前朝向偏移 `6` 世界单位、向下偏移 `7` 世界单位；其它三类角色阴影保持原对位规则。
- 场景散落粒子花的常驻 Glow 增至 `1.35`，轻拍 / 重拍峰值分别增至 `2.8` / `4.8`，并同步扩大光粒尺寸与不透明度。
- 第一关顶部四拍节奏条在正确命中时新增 `6px`、两次往返的短促上下震颤，不影响其它 HUD 位置。
