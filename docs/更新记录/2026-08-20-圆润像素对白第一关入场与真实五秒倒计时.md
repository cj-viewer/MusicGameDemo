# 2026-08-20：圆润像素对白、第一关入场与真实五秒倒计时

## 需求

- 对话框保持像素风，但更圆润可爱，并支持文字自动换行。
- 上移 ComboMeter，删除教学中位于其正上方的 UI。
- 教学结束视频后增加第一关自动走入与两句对白，再开始正常五秒倒计时。
- 倒计时攻击不增加 ComboMeter。

## 实现

- 对话框改为白底黑字的圆润像素气泡，加入粗边、块状阴影、猫耳、尾巴和粉色角标；固定文字宽度并启用高级自动换行。
- 正式 ComboMeter / 武器状态组整体上移约 `52px`；教学不再创建 PSD 静态状态条。
- 第一关新增 `levelIntroWalk` 与 `levelDialogue` 锁定状态：玩家用 `2.8s` 从左侧走到中央，再以轻击推进两句指定对白。
- 倒计时改为真实 `1000ms` 间隔，总长 `5s`。倒计时期间只冻结正确攻击与完整 Pattern 的量表收益，攻击和节拍反馈仍正常；开波时清除倒计时连招并恢复收益。

## 影响

- 改变教学与第一关入场 UI、正式 ComboMeter 位置和第一波开始前流程。
- 波次内容、伤害、闪现费用与教学完成条件不变。
