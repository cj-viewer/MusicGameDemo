# 2026-08-16 / 加强闪避拖影并延长 Dash 收势

## 需求

- 将角色闪避拖影的初始不透明度提高到当前的两倍。
- 放慢闪避动画播放，让位移结束后仍能看见一小段 Dash，再过渡到其他动作。

## 实现

- 残影初始 Alpha 从 `0.55` 提升到 `1.0`。两倍计算值为 `1.10`，但 Phaser 的对象 Alpha 上限为 `1.0`，因此采用最大可见值。
- Dash 的 12 帧动画总时长从 `240ms` 改为 `360ms`，播放速度同步降低三分之一。
- 实际闪避位移继续为 `140ms`，动作锁跟随动画保持到 `360ms`，因此位移结束后继续保留 `220ms` 的 Dash 收势；收势结束后才恢复 Run / Idle。
- 拖影仍只在位移 `140ms` 内按 `10ms` 时间轴生成，收势阶段不产生额外残影。

## 影响

- 残影更亮、更易读，位移轨迹保持连续；不会改变闪避距离、无敌、ComboMeter 消耗或踩拍音波。
- Dash 的视觉节奏更从容，但角色可移动和可再次操作的时点维持原闪避位移完成后的规则。

## 验证

- `npm.cmd run build`
- 连续触发左右 Shift：确认位移段残影从不透明开始淡出；角色抵达终点后仍播放 Dash，约 `220ms` 后才切换 Run / Idle。
