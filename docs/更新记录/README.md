# 更新记录

这里保存每次可交付改动的短记录，便于快速查看“这次改了什么、影响哪里、如何验证”。精确历史和当前参数仍以 [实机落地与调整记录](../实机落地与调整记录.md) 为准。

## 命名规则

```text
YYYY-MM-DD-主题.md
```

每个文件至少包含：需求、实现、影响、验证、遗留。一次改动涉及多项相关功能时可合并为同一文件；不相关改动应拆分。
