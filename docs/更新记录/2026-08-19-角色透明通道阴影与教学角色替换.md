# 2026-08-19：角色透明通道、阴影与教学角色替换

## 需求

- 修复玩家轻击、正式粉丝与安保轻 / 重攻击特效的透明通道。
- 为玩家、粉丝、安保和教学角色加入 `256 x 256px` 同画布阴影，由程序控制透明度与层级。
- 用新教学角色替换旧展示粉丝，接入 Idle / Run / Roll、轻重特效和口吐弹幕。
- 替换粉丝与安保的场景统一配色 Idle / Run。

## 实现

- 导入透明通道修复版：玩家 Light 5 帧、粉丝 Light 5 / Hard 6 帧、安保 Light 5 / Hard 7 帧，并删除替换后不再加载的旧尾帧。
- 新增四张角色阴影，运行时 Alpha 统一为 `0.45`，深度为所属角色脚底深度 `-0.004`；阴影保持基准尺寸，不随拍点果冻律动缩放。
- 新增教学角色 Idle 8、Run 8、Roll 12、Light 5、Hard 6；角色无手持武器，以正式粉丝速度的 `68%` 追随，每两小节翻滚刷新，按粉丝默认 `0.25 次/拍` 从嘴部发射点弹并交替播放 Light / Hard。
- 安保 Hard 第 6 帧源文件为 `255 x 255px`，运行时按真实纹理宽高补偿到 `256px` 同画布足迹，不改写项目方源图。

## 影响

- 正式敌人的移动、攻击频率、伤害、弹速、波次、掉落与武器参数不变。
- 教学角色现在会攻击，但不加入正式敌人物理组；仍可被玩家自动瞄准。
- core 由 161 张图片增至 202 张图片；连同 3 个音频共 205 个 Loader 项、`14,476,033` 字节（约 `13.81 MiB`）。仓库图片 / GIF 总数为 259，其中角色 192。

## 验证

- 本地 `http://127.0.0.1:5173/` 进入教学与正式 Wave 1：教学角色动作、嘴部点弹、轻重特效和四类阴影正常；粉丝 / 安保配色替换生效；攻击特效无黑底。
