# 2026-08-16：BGM 与判定统一降至 132 BPM

## 需求

试玩时希望把当前节奏降至 `132 BPM`，同时保持 BGM 鼓点、Conductor、判定和循环边界同步。

## 实现

- `MainScene` 的统一 Conductor BPM 改为 `132`。
- 保存每首 BGM 的原始实测 BPM；`bgm1 / bgm2 / bgm3 / bgm0` 分别按 `132 / 145`、`132 / 176.47`、`132 / 146.32`、`132 / 153.846` 播放。
- 首拍 `delay` 使用变速后的墙钟偏移；若启动时已越过首拍，则把墙钟滞后量换算回源文件时间再传给 `seek`。每首曲目仍在自己的 `loopBeats` 边界重新对齐。

## 影响

- 音乐、拍点提示、输入判定、按拍计时与曲目循环保持同相，并整体放慢到 `132 BPM`。
- Phaser 的实时变速会使音高随播放倍率下降；本次没有重制 BGM 文件或做保音高时间拉伸。
- 攻击判定窗口仍为拍点前后各 `0.1s`，没有额外放宽。

## 验证

- 运行 `npm.cmd run build`。
- 本地试听教学与正式关卡，并检查开局首拍、曲目切换和至少一次循环边界没有跑拍或叠音。

## 遗留

- 若试听确认低音高不理想，后续应以保音高方式预处理音源，再重新测量各文件的源 BPM、首拍偏移和循环拍数。
