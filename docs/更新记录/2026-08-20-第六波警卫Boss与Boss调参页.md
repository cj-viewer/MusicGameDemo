# 2026-08-20：第六波警卫 Boss 与 Boss 调参页

## 需求

- 正式关最后一波加入使用警卫精灵、放大三倍且移动较慢的 Boss，并携带小弟登场。
- Boss 使用屏幕下方固定长血条，拥有三连大弹、半月冲击波、近身践踏和音符弹阵四种攻击表现。
- P Menu 新增 Boss 参数页。

## 实现

- 前五波保持 `2 / 6 / 12 / 18 / 24`，清空第五波进入 Wave 6；默认生成 `1200 HP / 28 px/s` 的三倍警卫长与 6 名交替类型小弟。Boss 波次清空后显示胜利，并回到第五波循环编队。
- HUD 新增固定屏幕的 `760px` 旧 UI 坐标长血条。Boss 远程循环包括 `3x` 大弹丸三连击、7 采样碰撞体的缓慢半月波，以及由数十颗独立伤害点弹组成、从右向左移动的音符阵列；近身时优先释放圆形践踏并击退玩家。
- P Menu 增加第六个“Boss”标签，提供最大生命、移动、攻击间隔、伤害、三类弹速、践踏半径 / 击退与小弟数量十项参数，并写入现有本机保存与 TXT `[boss]` 段。

## 影响

- 修改波次推进、敌人类型、Boss 弹幕与玩家强制击退；未新增运行时图片，Boss 复用警卫动画和阴影资源。
- 普通五波编队、普通敌人参数、掉落与现有玩家武器规则不变。

## 验证

- `npm run build` 通过 TypeScript 与 Vite 生产构建。
- 本地浏览器确认 Boss 为警卫显示比例三倍、携带 6 名小弟，全局血条固定在屏幕下方；P Menu 六个标签均可见，Boss 页十项默认值完整显示；页面控制台无 error / warning。

## 遗留

- 高密度音符阵列与第五波循环后的长期性能、四类攻击的最终难度仍需持续实机调参。
