# 2026-08-14：BGM 减半、怪物曲线移动与无限第五波

## 需求

- BGM 实际声音减半，但设置仍显示默认 `100%`。
- 怪物移动改为先减速后加速，保持原有每拍移动距离。
- 第五波首次完成后显示 `VICTORY`，并无限循环生成第五波。
- Combo 环、武器名、FPV 框和 Wave 文字跟随节拍缩放。

## 实现

- BGM 内部基础混音从 `0.1` 降为 `0.05`；BGM 通道默认值、滑杆位置和对外百分比保持 `100%`。
- 保安和粉丝按整拍归一化 `easeInExpo` 曲线移动。每帧对曲线区间积分，跨拍帧会分段计算；保安和粉丝每拍距离分别保持旧 `30/105 px/s`、`30/210 px/s` 分段规则在当前拍长下的结果。
- 首次清空第五波时常驻显示 `VICTORY`，状态进入 `intermission`；`2s` 后再次调用第五波生成逻辑，此后每次清空都继续重复第五波的 `32` 只敌人。
- HUD 每拍同步缩放 Combo 可见环、中心数字、ComboMeter 标题、武器名与 Wave 文字；轻拍 `1.10x`、重拍 `1.16x`，按 `Back.easeOut` 回到 `1x`。
- FPV 相机 viewport 每拍做纵向内缩再恢复：轻拍上下各 `6px`，重拍各 `10px`，不改变右下锚点、主相机、输入或判定。

## 验证

- `npm.cmd run build` 已通过；本地浏览器读回 BGM 内部 `0.05`、面板显示 `100%`。
- 怪物曲线积分为 `1`；当前 `beatDur=0.39000039s` 时旧保安 / 粉丝路程为 `19.200 / 29.700px`，新曲线使用同一总路程。
- 模拟清空第五波后立即读回 `intermission`、`VICTORY visible`、敌人数 `0`；`2.1s` 后为 `playing`、`waveIdx=4`、敌人数 `32`，胜利字样仍可见。
- 重拍瞬间 Combo 环、武器名、Wave 文字均为 `1.16x`；FPV viewport 高度由 `153px` 内缩为 `133px`，随后回弹；控制台 `0 error / 0 warning`。

- 无。
