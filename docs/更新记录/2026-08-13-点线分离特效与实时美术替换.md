# 2026-08-13：点线分离特效与实时美术替换

## 需求

- 保留更新后 `dev-1.0` 的角色动画、BGM、节拍反馈、设置和 FPV，同时接回此前验收的攻击特效。
- 玩家荧光棒使用高亮直光束；敌人使用多层描边点弹，点与线完全分离并保持固定前后关系。
- 警棍使用更轻薄、半透明面积更大的紫色弯月刀光。
- 在网页内增加可实时替换背景和角色美术的小型测试工具。

## 实现

- 工作区从旧基线 `94d1ba2` 快进至上游 `dev-1.0` 提交 `ab33987`，再将本地功能适配到新的动画、统一世界缩放、三点方形判定、设置暂停和 FPV 结构。
- 荧光棒改为最长 `720px` 的瞬时射线。正确输入 5 道、错误输入 1 道；命中最近敌人时在轮廓表面截断，并增加短促光电反馈。
- 保安/粉丝每次发射六枚分层点弹，分别使用青白胶囊和暖红圆点；保留深色外描边与白色内核，取消所有线状拖尾，同屏限制 `240`。
- 警棍刀光按统一 `0.8x` 世界倍率绘制四层渐细 ribbon，主体和白芯收窄，外光保持更宽且低透明。
- 新增 `src/game/ArtAssetTool.ts` 与 `MainScene` 运行时纹理接口，可替换背景、玩家、保安、粉丝并恢复默认。动画角色被覆盖时使用静态图，恢复后继续默认动画；`R` 重开保留、浏览器刷新清空。

## 影响

- 不改变上游 `146.32 BPM`、输入窗口、BGM、玩家/粉丝默认序列帧、波次数量、设置暂停或 FPV 开关。
- 敌方一次攻击由单枚 12 伤害长条变为六枚单枚 4 伤害点弹；节奏速度和 8 拍寿命保持不变。
- 玩家荧光棒不再生成移动弹体或 Trail，命中改为发射瞬间结算最近目标。警棍碰撞、段数、扫角和 `150ms` 行程保持不变。
- 临时换图只存在浏览器内存，不等同正式素材入库，也不会覆盖 `public/assets/`。

## 验证

- `npm.cmd run build`：通过 TypeScript 检查和 Vite 生产构建。
- 本地浏览器验收：新版教学页正常进入，默认玩家动画可见；背景与玩家静态换图即时生效，`R` 重开保留替换，四类素材可全部恢复默认；页面控制台无 error / warn。

## 遗留

- 实时换图目前是单张静态纹理测试，不导入序列帧文件夹、图集、锚点或逐动作缩放配置；正式动画素材仍需按《资源与素材规范》接入。
- 完整三小节教学后的光束命中、六点阵列与刀光仍需人工实机复验。
