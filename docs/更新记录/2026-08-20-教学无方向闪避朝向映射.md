# 2026-08-20：教学无方向闪避朝向映射

## 需求

教学中没有方向输入时，按 Shift 也应能闪避：把当前瞄准朝向映射到八方向后，向其反方向后撤。

## 实现

- `Player.tryDodge()` 保留已有 WASD / 左摇杆方向优先级。
- 当方向向量为零时，刷新当前瞄准角度，按 `45°` 量化到八方向，并加 `180°` 生成闪避方向。

## 影响

- Shift 单键可以向当前瞄准方向的反方向闪避，适用于教学与正式关。
- 能量门槛、踩拍 / 错拍消耗、无敌、位移距离与有方向输入时的逻辑均不改变。

## 验证

- `npm.cmd run build` 通过。
