# 2026-08-18：分轻重速度与后段波次减量

## 需求

- 两把玩家武器的轻击、重击分别提供攻击速度参数。
- 保留波次递增梯度，同时减少第 3、4、5 波敌人。
- 正式关默认播放 `bgm2`。

## 实现

- P“速度 / 频率”页新增荧光棒轻 / 重、警棍轻 / 重四项动作速度，默认 `100%`，范围 `50–200%`、步进 `10%`；分别缩放对应攻击的角色特效、武器挥动和动作锁。
- 前五波人数改为 `2 / 4 / 6 / 10 / 16`，第五波后继续循环 `16` 只。
- 正式关默认 BGM 槽改为 `1`，对应 `bgm2.mp3`；教学仍使用 `bgm0.mp3`。
- TXT 新增四个分项速度键，旧统一速度键保留为兼容默认。

## 影响

- 警棍弧段飞行速度仍是独立参数，不随警棍轻 / 重挥击速度改变。
- 每波仍保持保安与粉丝各半，波次总数仍严格递增。

## 验证

- `npm run build` 通过。
- Chrome 实测 `50% / 200%` 轻重速度对应 `400 / 100ms` 动作锁；第 3/4/5 波为 `6/10/16`；正式关槽位和标签为 `1 / bgm2.mp3`，控制台无 Runtime exception。

## 遗留

- 无。
