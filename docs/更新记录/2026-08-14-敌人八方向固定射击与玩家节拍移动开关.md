# 2026-08-14：敌人八方向固定射击与玩家节拍移动开关

## 需求

- 敌人攻击角映射到八方向扇区中线，保证实际射出角固定。
- 玩家移动使用敌人同款拍内速度曲线，并在 `P` 调参面板提供开关。

## 实现

- `MainScene.quantizeEnemyAttackAngle()` 将瞄准角四舍五入到最近的 `45°` 整数倍。
- 小型保安、粉丝和中型保安在锁定、朝向、预警和发射阶段统一使用量化角；`spawnEnemyProjectile()` 再做一次防御性量化。
- 玩家节拍移动默认开启：基础速度仍为 `260 px/s`，每帧乘整拍归一化 `easeInExpo` 速度倍率；持续输入一整拍的累计距离保持不变。
- `P` 面板新增“玩家节拍移动”开关；关闭后恢复原来的 `1050 / 720 px/s²` 加速和减速。

## 影响

- 敌弹只会沿水平、垂直或四条对角中线射出；出生偏移、贴图、速度、Trail 与头中尾判定盒保持同角。
- 玩家节拍移动只改变拍内速度分配，不改变平均速度、输入方向、碰撞边界、动画判断或闪避。
- 手柄左摇杆仍保留模拟方向，不强制吸附到八向。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- P 面板默认显示“玩家节拍移动：已开启”，点击可切换为“已关闭”并恢复惯性移动。
- 八方向量化测试只产生 `0° / ±45° / ±90° / ±135° / 180°`。
- 本地页面控制台无 error / warning。

## 遗留

- 本次保留摇杆模拟方向；若需要视觉和移动方向也固定八向，需要另行调整输入量化规则。
