# 2026-08-12：默认音量、ComboMeter 与场内对象缩放

## 需求

- 默认音量改为 `150%`。
- 将圆形表盘文字改为 `ComboMeter`。
- 让场边律动条更宽、更丰满并提高不透明度。
- 将场内角色和物体等比例缩小到 `0.8x`。

## 实现

- 默认主音量从 `300%` 改为 `150%`，滑块范围继续为 `0–300%`。
- 表盘标签由 Fever 时显示的 `FEVER` 改为常驻 `ComboMeter`；Fever 时切换为橙色，中央 `FEVER TIME!` 不变。
- 边缘律动条提高到约 190 根，宽度改为 `14–30px`，基础不透明度改为 `0.40–0.68`，继续随机重叠和区分轻重拍跳动。
- 新增统一 `WORLD_OBJECT_SCALE = 0.8`，同步缩放角色、碰撞体、手持武器、掉落、敌我弹幕、血条、警棍扫击和场内反馈特效。

## 影响

- 场内对象更小，画面留白和弹幕可读空间增大；碰撞体与视觉保持一致。
- 移速、伤害、BPM、输入窗口、场地范围、HUD 与边缘律动带尺寸不变。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地浏览器确认默认音量 `150%`、`ComboMeter` 常驻、角色 / 物件 `0.8x` 以及更宽更实的边缘律动条生效。
- 攻击仍可执行，浏览器控制台无 error / warn。

## 遗留

- 边缘律动条仍使用每次运行随机布局；如需固定舞台轮廓，可后续加入固定随机种子。
