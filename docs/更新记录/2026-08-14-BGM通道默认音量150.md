# 2026-08-14：BGM 通道默认音量提高到 150%

## 需求

- 将 BGM 音量调为 `150%`。
- 维护所有受影响的项目文档，并将本地成果推送到在线 `dev-1.0` 分支。

## 实现

- BGM 通道默认值由 `1.0` 改为 `1.5`，Esc 设置面板默认显示由 `100%` 改为 `150%`。
- BGM 内部基础混音继续使用 `0.0375`；默认 BGM 实例音量因此为 `0.05625`，随后仍统一经过默认 `150%` 的主音量节点。
- 主音量默认 `150%`、音效通道默认 `100%` 及各滑杆范围保持不变。

## 影响

- 新开页面或刷新游戏时，BGM 通道从 `150%` 开始播放；玩家仍可在 Esc 设置面板中将其调整到 `0–200%`。
- 不改变轻重拍叫喊、程序音效、BPM、首拍偏移或 `616` 拍循环校相规则。
- README、简化玩法策划案、实机落地记录、验收项和更新记录索引已同步；历史记录保留对应版本当时的数值。

## 验证

- `npm.cmd run build` 已通过 TypeScript 检查和 Vite 生产构建。
- 本地开发服务 `http://127.0.0.1:5173/` 返回 HTTP `200`；代码读回 BGM 通道默认值为 `1.5`。

## 遗留

- BGM 主观听感仍需在目标扬声器或耳机上实机确认；若继续调整，只修改 BGM 通道默认值，避免误伤音效通道。
