# 2026-08-14：重拍框初始可见度与边缘律动同步转橙

## 需求

- 橙色重拍框从小到大时具有更高的初始透明度。
- 重拍前，外侧律动条按橙框透明度变化速率同步转为橙色；轻拍恢复原色。

## 实现

- 轻拍框最小透明度保持 `0`，重拍框最小透明度设为 `0.18`。
- 两类框继续使用同一个三拍 `Expo.In` 扩散和淡入进度。
- 每帧读取未来三拍中最显眼的重拍框透明度，作为全部律动条朝橙色色相过渡的比例。
- 色彩过渡只沿最短 HSV 色相路径进行，保留律动条当下的饱和度和明度；重拍 pulse 使用完整橙色色相，轻拍 pulse 使用原紫粉色。

## 影响

- 重拍预告更早可见，外侧人群与场内橙框形成同一条视觉预告链。
- 律动条仍保持 `100%` 不透明；宽高、重叠、压缩、跳高、TopDown 深度及无碰撞规则不变。
- 轻拍框、场地大框、命中粗框和节拍判定逻辑不变。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 本地观察重拍框从透明度 `0.18` 起步，律动条按同一透明度进度转橙，轻拍恢复紫粉色。
- 浏览器控制台无 error / warning。

## 遗留

- 需要继续人工观察不同显示器上 `0.18` 的清晰度与舒适度。
