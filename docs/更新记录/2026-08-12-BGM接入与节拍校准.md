# 2026-08-12：BGM 接入与节拍校准

## 需求

- 为当前 Web 原型接入 BGM，并使其与战斗节拍时钟对齐。
- 将实际检测到的音乐节拍参数同步为当前原型规则。

## 实现

- 新增 `public/assets/audio/music/bgm3.mp3`，由 `MainScene` 以 `bgm` 缓存键加载。
- Conductor 启动后播放 BGM；通过 `delay` 或 `seek` 使文件内 `0.026s` 处的首拍与 Conductor 第 0 拍对齐。
- 节拍参数设为 `146.32 BPM`、`4/4`，BGM 音量为 `0.5`；场景重开前停止旧 BGM，避免叠音。

## 影响

- 每拍约为 `0.410s`、每小节约为 `1.640s`；攻击判定窗口仍为拍点前后各 `0.2s`，武器 pattern、波次和敌人参数不变。
- BGM 运行时目录确定为 `public/assets/audio/music/`；轻重节拍采样继续位于 `audio/sfx/`。

## 验证

- `npm ci` 和 `npm run build` 已通过；TypeScript 检查与 Vite 生产构建成功。
- 本地开发服务器返回 HTTP 200。

## 遗留

- 需在人工试玩中确认 BGM 首拍与判定条的主观听感完全同步。
