# 2026-08-18：玩家远程射程 P 面板

## 需求

确认玩家远程武器是否无限射程，并在 `P` 调参面板提供无限射程开关与有限模式最远距离。

## 实现

- 原规则不是无限：荧光棒弹会在判定拍的下一拍销毁，射程会随输入早晚波动。
- `P` 面板新增无限射程开关，默认关闭。
- 有限模式默认最远距离为 `164px`，可按 `20px` 调为 `40–2000px`。弹丸按出生后的实际累计距离销毁，不再依赖整数拍寿命。
- 错误输入在有限模式下仍为设定距离的 `50%`。无限模式下，正常弹和错误弹都只在命中或飞出战斗区时销毁。

## 影响

有限射程从“按拍点估算”改为“固定距离”，因此不再受 Perfect / Good 输入早晚影响。弹速、弹丸数、视觉长度、命中盒、伤害、击退、Fever 三向攻击和战斗区边界不变。

## 验证

- `npm run build` 通过 TypeScript 检查与 Vite 生产构建。
- 本地服务首页返回 HTTP `200`；实机检查 `P` 面板默认值、有限射程上下限、错误弹 `50%` 距离与无限开关。
