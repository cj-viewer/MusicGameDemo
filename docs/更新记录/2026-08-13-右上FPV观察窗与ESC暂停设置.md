# 2026-08-13：FPV 观察窗与 ESC 暂停设置

## 需求

- 将实验分支的第一人称分屏视角以独立右上小窗接入当前 `dev-1.0`，不得改变既有玩法、HUD、判定或操控。
- 设置面板仅能由 `Esc` 开关，提供主音量和 FPV 小窗开关；打开设置时游戏须彻底暂停。
- 后续视觉收敛：HP 与 ComboMeter 集中到左下；FPV 移至右下并缩为原来 `0.5x`，沿鼠标原始瞄准方向观看；场地轻拍与 FPV 边框统一粉紫，重拍改橙色，正确踩拍强化场地框反馈。

## 实现

- 新增 `src/scenes/FpvMiniScene.ts`。它以独立 Phaser Scene 和独立相机渲染右下 `240 x 153px` 的 FPV 观察窗（相对上一版 `160 x 102px` 为 `1.5x`），锚定屏幕右下、右/下边缘仅留 `20px`；它只读取 `MainScene` 暴露的玩家朝向、敌人及敌我弹幕，不注册键盘、鼠标或手柄输入，也不写入主场景状态。
- `Player` 额外保留未经辅助瞄准修正的 `rawAimAngle`；FPV 严格以该角度投影，所以玩家本体仍可使用原有 90 度辅助瞄准攻击，而观察窗始终朝鼠标（或右摇杆）的实际方向观看。
- HP 条移至左下并与 ComboMeter 同一水平基线，长度收敛为 `124px`；原有 HP 数值、横向血量比例与轻重拍纵向律动规则不变。
- Combo 环中心向右移动 `22px`，等于自身 `44px` 外径的一半，因此与 HP 条保持清晰间隔。
- 场地边界、轻拍内框与 FPV 边框统一使用低饱和粉紫 `#e879f9`，重拍内框和到拍边框使用橙色 `#f97316`。正确输入或教学自动演示额外生成一层 `8px / 11px` 的粉紫 / 橙色场地框，在 `240ms / 310ms` 内轻微外扩并淡出。
- `src/main.ts` 注册 FPV Scene，`MainScene` 在创建时启动它。标题页、设置页和开关关闭时，小窗相机隐藏；游戏开始后恢复显示。
- 原 `Alt` 音量面板替换为 `Esc` 设置面板，保留 `0–300%` 主音量滑块并新增 FPV 开关。`Alt` 不再绑定任何功能。
- 打开面板时暂停 Conductor、Phaser 音频、Arcade Physics、动画、Tween 与 Scene Clock，并用 `gamePaused` 阻断主更新、攻击、闪避、重开、调试和手柄输入；关闭时按同一状态恢复，Conductor 会将暂停时长补偿到节拍起点，避免 BGM/节拍相位漂移。

## 影响

- 战斗规则、拍点、攻击、移动、敌人 AI、HUD 与原有键鼠/手柄映射不变。
- 右下窗口是额外的视觉投影；关闭它不会停用任何游戏内容。它的方向不再跟随辅助瞄准的锁敌结果。
- 设置期间不推进游戏时间、物理或声音；关闭后从暂停帧继续。

## 验证

- `npm.cmd run build`：通过 TypeScript 检查和 Vite 生产构建。
- Codex 本地试玩：确认 HP 与 ComboMeter 同线、`240 x 153px` FPV 锚定屏幕右下、Esc 设置面板和粉紫/橙色框均正常；浏览器控制台无 error/warn。

## 遗留

- 当前 FPV 窗口为可选的战斗观察视图，不属于新的可操控视角；如后续要发展为可玩模式，应另行定义输入归属和玩法规则。
