# 2026-08-18：合并任意拍连招与敌亡爆炸并保留紧凑 HUD

## 需求

- 将上游最新的任意拍起手连招与敌人死亡爆炸合入当前版本。
- 保留已经按实机反馈定稿的紧凑 HUD、无未来拍全场框、无战斗镜头摇动和局部环境回弹规则。

## 实现

- `ComboSystem` 使用独立的连招状态：任意正确轻攻击可在鼓点起手，后续按当前武器 pattern 在紧接着的下一拍推进；错拍、错键或目标拍后 `200ms` 漏拍都会失败。
- 正式四拍 UI 待机隐藏、起手显示、完成隐藏；失败时只让 UI 红闪和横向抖动。四拍继续使用 `58%`、中心 `(1200,130)`，Combo / 武器组继续使用 `72%`、最终外框约 `(1058,1338,265,72)`，不创建 `arenaBeatCues`。
- `Conductor` 每拍使用统一短鼓点，正确连招输入播放裁短轻 / 重喊声，BGM 基础混音为 `0.125`。
- 敌人死亡时按类型生成青色或橙红色双层冲击环、放射长条、主爆炸粒子和高速火花，并自动销毁。
- 正式环境继续只有 17 个白名单物件按拍回弹；中央人物与栏杆及其它 18 个物件和运行底图静止，主镜头不恢复攻击缩放或反馈摇动。

## 影响

- 改变连招起手、逐拍推进、漏拍处理、正式四拍 UI 显隐、背景鼓点、BGM 基础混音和敌人死亡视觉。
- 不改变攻击伤害、弹数、速度、寿命、命中盒、掉落、波次、角色移动、环境资源、HUD 最终尺寸与位置。
