# 2026-08-20：双关卡 HUD 缩小与半透明对白框

## 需求

- 第一关背景图替换为项目方提供的 `11111.png`；第一关底部 ComboMeter / 武器状态条改到最新黄框目标位置和大小；圆形量表、百分比和“荧光棒 / 警棍”文字继续从运行时读取并保持清晰可读。
- 所有剧情对白中的黑框白底气泡，以及战败后的中央失败提示，改为与池塘 / 粉紫广场更协调的浅色半透明框。
- 第二关顶部四拍图案按最新截图略向上挪，避免遮住门口下方图像；第二关底部 ComboMeter / 武器组独立缩短并放入新的底部红框位置。第一关底部状态条长度不跟随本轮第二关改动。
- 本轮只调整 UI 面板样式、比例和绘制，不改变输入、连招判定、ComboMeter、Fever、HP、Wave、武器切换、对话推进或战斗逻辑。

## 实现

- `src/game/HUD.ts`
  - 第一关 ComboMeter / 武器组改为约 `266 x 42` 设计单位、整体 `87%` 的短条，并放入黄框目标位。
  - 第二关 ComboMeter / 武器组拆成独立显示矩形，基础框约 `278 x 42` 设计单位、整体 `87%`，只覆盖最新第二关底部红框目标。
  - 圆环半径为 `16`，圆心百分比为 `12px`，武器名为 `20px`，断角与中隔线保持细线样式。
  - 为避免在粉色地面和底部灌木上丢字，状态条增加更稳定的半透明承托和厚像素阶梯描边，并给百分比与武器名加更清楚的细描边；实时逻辑不变。
  - 教学关继续直接复用同一套实时状态条，因此第一关和第二关只共享样式，不共享额外静态文字或硬编码状态。
- `src/scenes/MainScene.ts`
  - 正式关四拍图案整体比例收为 `88%`，圆形、菱形、间距和警棍长按提示同步缩小，并整体上移到最新顶部目标框内。
  - 剧情对白框去掉黑色粗描边和白色实底，改为浅色半透明雾面、白色细线断角和粉色像素角标；对话行文、自动换行、位置跟随和推进输入保持不变。
  - 战败提示不再使用文字自带黑色背景与黑色粗描边，改为同套浅色雾面像素提示框；框体按文字尺寸自适应，进一步提升灰绿承托、白线和文字深色细描边对比，并整体上移避开底部状态条。死亡动画、冻结全部系统与 `R` 重开逻辑保持不变。
