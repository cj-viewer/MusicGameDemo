# 2026-08-14：轻微广角与 Cinemachine 风格镜头前探

## 目标

- 保持现有场景内容、玩法坐标和 UI 布局不变，略微扩大主场景 FOV。
- 玩家向屏幕上下左右或四角移动时，让主镜头柔和地向对应方向前探。

## 落地

- 主摄像机基础 zoom 设为 `0.965`，并用负基础 scroll 重新居中，可见世界范围约为 `1326.4 x 746.1px`。
- 玩家相对场地中心的 X/Y 位置分别计算：中央 `0.24` 归一化范围为死区；超出后通过 `smoothstep` 映射到水平 `30px`、垂直 `20px` 的最大前探。
- 实际镜头位置以 `220ms` 指数阻尼追逐目标，所以边缘移动、四角合成和回到中央都不会瞬间跳变。
- 原有踩拍镜头缩放改为乘在 `0.965` 基础值之上，保持原轻 / 重相对强度并正确回落。
- HUD、动态 HUD 特效、教学顶部连段、教学完成层、倒计时、ESC 设置面板和 P 调参面板使用 `scrollFactor 0` 并以 `1 / 0.965` 反向缩放，固定在原屏幕像素位置与尺寸；独立 FPV Scene 不参与主镜头偏移。

## 验证

- `npm.cmd run build` 通过。
- 浏览器读回 zoom `0.965`；中央 / 右侧 / 左侧 / 右下角的稳定 scroll 分别约为 `(-23.2,-13.1)`、`(6.7,-13.1)`、`(-53.0,-13.1)`、`(6.7,6.9)`。
- HUD、ESC 面板和 P 面板的 scrollFactor 均为 `0`；控制台 `0 error / 0 warning`。
