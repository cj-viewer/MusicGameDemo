# 2026-08-20：全局 UI 面板统一为可爱像素风

## 需求

- 将小游戏内所有 UI 相关面板统一到参考图的可爱、简约、马赛克像素风。
- 教学 / 池塘关贴合浅绿背景，正式 / 粉紫关贴合粉紫场景。
- 只替换面板样式，不改变任何输入、判定、反馈机制、音量路由、暂停、联网或战斗逻辑。

## 实现

- 教学关 UI：连段面板、进度 / 校准面板、四张操作卡与底部 ComboMeter / 武器条统一为浅绿像素面板、深青描边、青色按钮和清晰深青文字。
- 正式关 UI：Wave / 四拍提示、玩家头顶 HP、底部 ComboMeter / 武器条与 FPV 小窗统一为粉紫像素面板、紫色描边和清晰深紫 / 浅粉文字。
- 系统面板：Esc 音量面板、P 调参面板、失败提示、标题页按钮、双人联机大厅与联机战斗 HUD 改为同一像素 UI 语言，去掉旧黑框 / 白底 / 过亮白字的割裂感。
- 保留原有 UI 的动态数值、按钮、拖动、开关、暂停、联网同步与所有战斗反馈逻辑；底部 ComboMeter / 武器条仅按最新红框目标调整显示矩形，不写死武器名称或百分比。
- 面板外形统一改为更明显的双阶梯像素缺口、块状边缘凸点和厚描边，避免回到细线框或黑框白底风格。

## 影响

- 仅影响视觉样式与字体清晰度。
- 不新增运行资源，不改变已有资源加载清单。
- 不改变玩家攻击、敌人攻击、Combo、Fever、关卡切换、Esc / P 面板交互、FPV 开关或联机同步逻辑。

## 验收

- 教学关、正式关、标题页、Esc 音量面板、P 调参面板、失败提示、FPV、双人联机大厅和联机战斗 HUD 均不再出现旧版黑框白底面板。
- 所有中文 UI 字体清晰可读，颜色与当前关卡背景有足够对比。
- Esc 音量滑杆、FPV 开关、P 调参项、失败重开、标题页开始 / 联机按钮和双人联机输入仍保持原功能。
- `npm run build` 通过；本地开发页 `http://127.0.0.1:5180/` 返回 HTTP 200。视觉细节需硬刷新后在浏览器中按教学关、正式关、Esc / P、失败提示和联机界面逐项确认。

## 遗留

- 本轮不重画角色、敌人、攻击特效或场景资产。
- 若后续要把 UI 从程序绘制升级为整套图片资源，需要另行登记素材来源、授权和加载清单。
