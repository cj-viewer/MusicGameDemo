# 2026-08-14：统一轻重框曲线并提前重拍峰值

## 需求

- 橙色框与粉色框使用相同类型的不透明度变化曲线。
- 橙色框只通过稍早达到峰值来增强辨识度。

## 实现

- 轻拍与重拍透明度统一使用 `Expo.In`。
- 两种框初始透明度均保持 `0`。
- 橙色框将透明度进度除以 `0.9` 并钳制到 `1`，因此在扩散周期的 `90%` 处达到峰值，最后 `10%` 保持满亮。

## 影响

- 轻重框的淡入趋势一致，不再使用相反的 easing 类型。
- 橙色框仍比粉色框更早进入满亮状态，但差异保持克制。
- 三拍扩散、下一拍律动条配色、镜头和判定均不改变。

## 验证

- `npm run build` 通过 TypeScript 检查和 Vite 生产构建。
- 浏览器实机确认轻重框淡入趋势一致、橙色框稍早达到峰值。
- 浏览器控制台无 error / warning。

## 遗留

- 后续只需调整 `ARENA_BEAT_HEAVY_ALPHA_PEAK_PROGRESS` 即可修改提前量。
