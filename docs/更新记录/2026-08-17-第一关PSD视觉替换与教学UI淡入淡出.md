# 2026-08-17：第一关 PSD 视觉替换与教学 UI 淡入淡出

## 需求

- 使用项目方提供的 `bg1.psd` 替换第一关现有视觉。
- 对左键轻攻击、右键重攻击、Esc 设置和 Shift 冲刺四条教学 UI 增加柔和的淡入淡出动画。
- 不改变输入、三小节判定、延迟校准、节拍、物理边界或第二关玩法。

## 实现

- 源 `bg1.psd` 为 `1920 x 1080`、8-bit RGB，SHA-256 为 `8DD1F4919B2ADE2E5943ACBBF2F9BBFB0610DF266346EDDDAC772AEC1702CF5A`。只把环境层合成为运行时 `pond-stage-background.png`；UI 与 PSD 隐藏层不烘焙进背景，浏览器不加载 PSD。
- `tutorial-pattern-panel.png` 继续使用 `578 x 278` 源图，运行时矩形为 `x=114.070983、y=86.035871、w=354.689738、h=170.594718`。
- 新增 `tutorial-progress-panel.png`（`247 x 163`，左上 `(167,249)`）与 `tutorial-bottom-status.png`（`1556 x 50`，左上 `(188,890)`）。其中进度、校准、生命、Combo 与武器文字是 Photoshop 视觉稿烘焙的静态初始内容，不读取实时数据；真实三小节和延迟校准继续在后台执行。
- 新增四张 `320 x 64` 操作卡：轻攻击 `(130,450)`、重攻击 `(128,549)`、设置 `(128,648)`、冲刺 `(128,747)`。四卡不位移、不缩放，只改变 Alpha。
- 教学入场延迟 `160ms` 后，四卡以 `120ms` 错开，用 `340ms Sine.easeOut` 淡入到 `0.82`，再用 `450ms` 回落到 `0.42`。随后按轻攻击、重攻击、设置、冲刺的顺序单焦点轮巡：`260ms` 提亮到 `1`、停留 `700ms`、`440ms` 回落到 `0.42`，条间 `160ms`，每轮约 `6.24s`。
- 进入教学确认状态时四卡在 `260ms` 内整体淡出；重练重新构建。Space 跳过、进入第二关或 Scene 关闭时停止并清理相关 Tween 和对象。
- 第一关隐藏旧 gameplay HUD 与 FPV；进入第二关后恢复。底部 Photoshop 状态条只承担视觉稿展示，不代替真实 HUD 数据。

## 影响

- 当前美术资源总数由 `209` 增至 `215`，其中 `images/ui/` 由 `1` 张增至 `7` 张。
- core 清单由 137 张图片增至 143 张图片；加上两条节拍音效与教学 BGM，当前共 `146` 个 Loader 项、`13,218,393` 字节（约 `12.61MiB`）。
- 第一关环境和教学信息层更新；角色、攻击、敌人、BGM、输入、判定、校准、不可见战斗边界、教学完成选择及第二关环境均不改变。
