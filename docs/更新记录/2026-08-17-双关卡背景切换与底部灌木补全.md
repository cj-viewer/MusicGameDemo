# 2026-08-17：双关卡背景切换与底部灌木补全

## 需求

把用户提供的绿色池塘图放到教学关，把当前粉紫音乐广场移到正式关；修复粉紫场景最下方左右灌木透明素材只保留中间片段、画布两侧和底边露空的问题。

## 实现

- 新增 `pond-stage-background.png`，以静态 `Image` 铺满教学关 `1920 x 1080` 画布。
- `PinkStageEnvironment.ts` 同时维护教学池塘与正式关粉紫分层环境；`startTutorial()` 显示池塘，`finishTutorial()` 进入正式关倒计时时切换粉紫场景。
- 重新生成并替换 `object-37-foliage-bank-bottom-left.png` 与 `object-38-foliage-bank-bottom-right.png`。左侧素材改为 `830 x 201`、原位 `(0, 880)`；右侧素材改为 `798 x 201`、原位 `(1120, 880)`，两者均连续触及对应侧边与画布底边。
- 两套环境仍保持 `-20 / -19` 深度、不创建物理体；角色、节拍、BGM、倒计时、HUD 和碰撞状态不重建。

## 影响

- 教学关和正式关现在具有不同背景；完成教学后的环境切换立即可见。
- 粉紫场景底部左右不再因透明物件内容过窄而露出空白。
- 不改变战斗数值、输入、敌人、弹幕、掉落、FPV 或物理边界。

## 验证

- `npm.cmd run build`：通过 TypeScript 检查与 Vite 生产构建。
- 浏览器实机：教学关显示绿色池塘；经同一 `finishTutorial()` 入口预览正式关时切换为粉紫分层场景，左右底部灌木连续覆盖至侧边与底边。池塘底图、粉紫底图及两张修复后的灌木资源均返回 HTTP 200，页面正常渲染。
