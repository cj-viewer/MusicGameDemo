# MusicGameDemo 简化玩法策划案（当前原型）

> 本文只描述当前可运行原型。长期设想见《2D音乐弹幕游戏策划案（持续更新）》，历史调整见《实机落地与调整记录》和 `docs/更新记录/`。

## 一、当前验证目标

- 验证“自由走位 + 自动 / 手动瞄准 + 任意鼓点起手的武器四段连招 + 两类武器 + 节拍弹幕”的循环。
- 验证教学池塘与正式粉紫广场两套环境、四步操作教学、波次编队、ComboMeter 和 Fever 清弹。
- 内部画布固定为 `2560 x 1440`（2K）；低分辨率屏幕由 Phaser FIT 等比缩放，不阻止进入游戏。
- 程序 UI 以旧 `1280 x 720` 设计坐标乘 `2`，项目方 PSD 以 `1920 x 1080` 源布局乘 `4/3` 显示到 2K。

## 二、流程与操作

1. 标题页使用 `backgrounds/intro/intro-title-background.png` Cover 铺满并保留安全出血；开始按钮实际中心为 `(2120,460)`、尺寸 `440 x 120`。
2. 点击开始后播放唯一的 `intro.mp4`，播放完进入教学。标题页或视频期间按 `Space` 可直接跳过片头。
3. 教学开始时无 UI 且不接受玩家操作；主角从左侧自动走到中间偏左，然后用鼠标左键或 `Quote` 轻击依次推进六句对话。最后一句结束后才显示教学 UI 并恢复控制。
4. 教学 UI 出现后，玩家完成 3 个完整四拍 Pattern 并成功启动 1 次闪避，会依次看到能量流逝、踩拍增加、闪避消耗、攻击加成和满格大招等六句说明。推进最后一句或按 `Space` 结束教学时，先清空教学角色留下的全部弹幕，再进入教学结束动画。
5. 教学结束后播放 `tutorial-complete.mp4`；自然播完或按 `Space` 跳过后切换第一关场景。主角固定朝右，从左侧自动走到屏幕中央，以轻击推进两句对白：“打败这些保安和围堵的粉丝”“我就可以去内场见DJ Princess了！”。
6. 两句对白结束后开始真实 `5s` 倒计时。倒计时期间允许攻击与节拍判定，但正确攻击不增加 ComboMeter；第一波开始时恢复量表收益。
7. 正式关按波次持续战斗。每波首批与后续批次都在小节首拍生成，代码默认每批随机 `2–5` 名；P Menu 的 `2–4s` 间隔会先量化为完整小节。清空第五波后进入第六波 Boss 战；清空 Boss 与随行小弟后不显示 `VICTORY`，先在原地显示一句同款对白，关闭后等待 `2s`，主角才不可控地跑向画面顶部中央并淡出，完成后进入冻结结束态。

| 输入 | 当前行为 |
|---|---|
| `W A S D` / 左摇杆 | 带惯性的八向移动；反向输入时立即清零原速度并向新方向加速 |
| 鼠标左键 / `Quote`（`"` 键） | 轻攻击；警棍保持原武器形状并弹回玩家周围敌弹 |
| 鼠标右键 / `Enter` | 重攻击；警棍第 3 拍按住蓄力、第 4 拍松开集中释放，手动瞄准时沿脚下箭头方向攻击 |
| 左 / 右 `Shift` 或 `LB` | 沿当前移动方向闪避 |
| `RB` | 自动提交当前连招所需输入；不在连招中时提交轻攻击起手 |
| `Esc` | 打开 / 关闭音量设置；P 面板打开时切换到音量设置 |
| `P` | 打开 / 关闭六页战斗调参面板 |
| `R` | Replay：跳过教学，直接从第一关入场开始 |
| `F` | 调试时充满 ComboMeter |
| `C` | 调试时触发 Fever 同款从左向右清弹光条 |
| `Space` | 跳过开场标题 / 视频；从教学跳到结束动画；在结束动画中跳过并进入第一关 |

默认使用自动瞄准且不显示方向指示。自动模式从所有有效目标中选择综合优先级最高者；移动方向前方总角度 `45°` 的扇区内，有效距离按一半计算，因此真实距离为普通目标两倍时仍可获得相同距离权重，教学角色也会加入候选。P Menu“模式 / 导出”可开启手动瞄准；开启后角色脚下显示跟随角色移动、始终旋转指向鼠标世界位置的三角箭头，轻重攻击统一沿箭头方向出手。关闭后立即恢复原自动瞄准并隐藏箭头。

## 三、教学关与 UI

### 3.0 入场演出与对话

- 进入教学池塘后先不创建任何教学 UI，同时禁用移动、攻击、冲刺、手动瞄准箭头与设置面板。
- 主角面向右侧，用 `2.8s` 从画面左侧自动走到中间偏左；这段时间使用跑步动画，镜头不跟随角色做边缘前探，节拍器静音且 BGM 保持播放。第一关入场的同类不受控行走遵循相同静音规则。
- 停下后在主角头顶显示较小的白底黑字、圆润粗边、带猫耳和粉色像素角标的可爱像素气泡；正文和“继续”提示均使用更粗字重，气泡跟随主角世界位置，文字超过内部宽度时自动换行。台词依次为“终于到了节奏星球。”“听说这里的人除了走路任何行为都是按照节奏的。”“让我来先学习一下。”“我需要按照节奏击打。”“闪避可以让我短暂无敌。”“试着完成三个小节和一次闪避吧！”。
- 对话只接受鼠标左键或 `Quote` 轻击推进；第六句再次推进后淡出对话框，随即创建原有教学 UI、教学角色和操作卡并恢复玩家控制。教学入场、能量说明、第一关入场和 Wave 3 武器教学只要气泡存在，节拍器就静音；气泡关闭后恢复设置中的节拍音量，BGM 不受影响。运行时剧情对白均以句号或感叹号结束。

### 3.1 PSD 环境和分层

- 池塘底图只包含环境；项目方 PSD 中的教学面板、石子和操作卡保持为独立透明资源；三小节进度面板与静态底栏均不再显示。
- 所有源 PSD 坐标按 `4/3` 转成当前 2K 坐标，运行时不再使用 1920×1080 作为画布口径。
- 教学容器绘制顺序为：石子前景 → 操作卡，操作卡位于最上层。
- 教学关隐藏正式 HP、Wave、状态文字、FPV 和 PSD 静态底栏；直接复用上移后的正式第一关 ComboMeter / 武器状态组，其百分比、橙色进度弧与 Fever 剩余能量均读取真实状态。

### 3.2 四步操作卡

- 六句入场对话结束后，左键轻攻击、右键重攻击、Esc 设置和 L / R Shift 闪现四张卡延迟 `160ms` 同步开始 `280ms` 淡入，并全部常驻到教学结束。
- 操作卡只承担提示，不再按顺序推进或逐张消失。教学目标由 3 个完整四拍 Pattern 和 1 次真正成功启动的闪避共同判断；三个 Pattern 可累计完成，量表不足的 Shift 输入不产生位移，也不计作完成。
- 达成目标后暂停玩家操作，在角色头顶复用同一像素对话框依次讲解能量流逝、踩拍补充、闪避消耗、攻击加成、满格大招和武器拾取；共七句，最后一句推进后销毁教学 UI 并进入结束动画。

### 3.3 连段练习和教学角色

- 连段固定为轻、轻、轻、重；教学面板图形和文字直接来自透明稿，逐步高亮只裁剪当前格，不重绘面板。
- 教学累计完成 `3` 套完整四拍连招即可满足节拍部分，中途失败不会扣除已经完成的套数。输入时机仍用于延迟校准，校准只平移后续判定时钟，不改变音乐时钟或提示节拍。
- 教学角色不持武器，使用精简后的 Idle / Run 各 4 帧和 Roll 6 帧正常播放；它以正式粉丝移动速度的 `68%` 追随玩家，每 `16` 拍先死亡退场、再以翻滚动作生成，并可被自动锁定和玩家攻击。其死亡不结算正式波次或掉落。
- 教学角色沿用粉丝默认 `0.20 次/拍`、直射速度和尺寸，从嘴部发射单颗粉色基础攻击泡泡；教学泡泡不会触发粉丝三弧散射。命中仍显示与第一关相同的受击短闪和冲击，但教学伤害固定为 `0`，不会扣除 HP。每次实际攻击交替播放 Light 5 帧 / Hard 6 帧的透明特效，表现口吐弹幕；进入第一关倒计时立即恢复 `100 / 100 HP`。

## 四、节拍、判定与画面提示

- `4/4`；教学关和第一关节奏 BPM 独立设置，默认均为 `132`。输入序列随当前武器变化：荧光棒为轻、轻、轻、重；警棍前两次轻击均为近战扇形，后两步为重击按下 / 松开。任意踩中鼓点的轻攻击开始一套连招，后续仅按该套连招的下一步判断，不绑定全局小节拍位。
- 攻击窗口为拍点前后各 `0.2s`。校准后绝对误差 `≤100ms` 为 `PERFECT`，`100–200ms` 为 `GOOD`；超出窗口、当前步骤的输入类型或按下 / 松开阶段错误，或下一步拍点后 `0.2s` 仍未输入都判定失败。警棍第 3 拍的按下与第 4 拍的松开分别独立判定，过早松开会立即判定 Miss，超过第 4 拍宽限仍未松开也按漏拍失败。任意错误输入都会清空当前连招状态；漏拍不生成攻击但同样清空连招。
- 右键 / Enter 的重攻击必须同时命中判定窗口与当前 Pattern 的重击步骤才会产生攻击。错拍、错步骤、同拍重复点击或长按起手失败只显示节拍错误，不生成重击，也不启动后续长按发波；长按超过松开判定仍未释放时立即停止后续发波。
- 两把武器共用“四拍一句”的输入结构。荧光棒前三拍正确轻击连续建立火力，第四拍重击统一结算；警棍前两拍用扇形近战压制近身敌人，后两步用重击按下 / 松开完成该句。
- 仅在连招内正确踩中鼓点时播放原有轻/重“嘿”；播放起点裁到各素材响度峰值前的短起声，移除更前方的低能量前段。除 BGM、每拍统一背景鼓点和这两种正确输入“嘿”外，常规攻击、错误攻击、受击、Combo、Fever、拾取和敌亡均不触发场景音效。
- Perfect / Good 按正确攻击结算；最终伤害为“当前武器轻 / 重基础伤害 × 判定倍率 × ComboMeter 倍率”。默认判定倍率为 `1.2 / 1.0 / 0.5`。
- 教学和正式关都不创建全局常驻的未来拍扩散提示。正确输入仍显示起始 Alpha `0.5` 的短时判定框；连招首拍命中后，第 2–4 步恢复旧版小节预告框：三框按剩余目标拍、原 `0.7x → 1x`、`2.4` 拍指数曲线缩放，进入提前输入窗口时完成一半视觉路程，并按该步轻 / 重类型着色。正确框、Fever 临时边框和重拍边缘冲击均锁在屏幕坐标，不随镜头前探漂移。
- 正式关普通正确重击不再触发整圈边缘粒子；只有完整四拍 Pattern 的最后一步触发低频收尾音、场景 / HUD / FPV 重拍脉冲和边缘粒子共同爆发。玩家与敌人的共同重拍固定由小节首拍驱动。教学反馈不变。
- 反馈分三级：警棍普通扇形近战保持短促、局部；同一扇形命中多个敌人也不追加全屏反馈。完整 Pattern 与 Wave Clear 才使用全场边缘、环境和 HUD 的大反馈。
- 教学与正式关都不显示常驻战斗区描边、边缘跳变色块、任何未来拍整场扩散框或底部汇聚节奏条。

## 五、玩家、闪避与反馈

- 玩家使用精简后的 Idle / Run 各 4 帧、Dash 6 帧正常播放；两套死亡各保留 4 帧，轻 / 重攻击特效各保留 5 帧。受击时以保留原贴图纹理的暖粉色 `MULTIPLY` 短闪 `140ms`，不再整张填成纯白。
- 玩家、粉丝、保安和教学角色均使用 `256 x 256px` 同画布阴影，程序统一设置 Alpha `0.45`。阴影位于场景之上、攻击特效 / 武器 / 角色之下，并保持固定基准尺寸，不随角色拍点果冻律动缩放；普通保安阴影沿当前面朝方向偏移 `6` 世界单位、并向下偏移 `7` 世界单位。Boss 阴影缩放为角色比例的 `55%`，固定向右补偿旧素材的左偏，不随朝向切换位置，并稳定处于 Boss 脚下图层。
- 玩家和敌人以脚底为锚随轻 / 重拍只向上做 Y 轴果冻律动：轻拍高度 `105%`、`170ms` 回归；重拍 `110%`、`220ms` 回归。仅有上 / 下移动输入时，玩家不执行这项 Y 轴缩放。
- 闪避距离 `160px`、位移 `140ms`，Dash 动画 / 动作锁共 `360ms`，位移结束后继续收势 `220ms`。拖影只在实际位移阶段出现。
- 教学沿用 ComboMeter 门槛：拍点前后 `0.12s` 内消耗 `5` 点，窗口外消耗 `20` 点，量表不足时拒绝启动。正式关闪避改用独立 `700ms` 冷却，不消耗 ComboMeter，也不会因量表不足失去基础逃生能力。
- 教学成功闪避仍在约 `93ms` 后释放半径 `190px` 的全圆音波。正式关只有踩拍闪避释放该清弹 / 伤害音波；错拍闪避仍位移并提供无敌，但没有音波奖励。
- 玩家战败时，先随机播放一套 `800ms` 死亡动画；动画播完后冻结全部时间、物理、补间、动画与音频，玩家停在死亡末帧，存活敌人停在原地，清除场上敌我弹幕和命中盒，并显示“你怒闯演唱会失败。按R再试一次。”。

## 六、武器与 ComboMeter

### 6.1 荧光棒

- 轻 / 重基础伤害默认 `10 / 18`，弹速 `1040 px/s`；玩家弹速调参上限为 `1600 px/s`。
- 正确攻击基础 `1` 发，每升 1 个 ComboMeter 等级增加 1 发，最多 `5` 发；错误输入只保留中线 1 发。
- 无限射程默认开启；关闭时默认最远 `164px`，错误输入的长度和飞行距离为当前有限值的 `50%`。
- 重击“贯屏激光”默认开启：充能延迟 `0ms`，粗细 `56px`，仍读取当前重击伤害、判定和 ComboMeter 倍率。
- 前三拍正确轻击把协同火力记录为 `1 / 2 / 3` 层；第四拍正确重击按层数分别追加 `20% / 40% / 60%` 伤害。满 3 层且贯屏激光开启时，主激光两侧各追加一束 `±8°`、伤害为主束 `55%` 的支援光；错拍、漏拍、换武器或开新波次清空蓄势。
- 荧光棒轻击线弹、重击线弹与贯屏激光均不击退敌人。
- 玩家直射为细长线性自发光：一张运行时 `128 x 64` CanvasTexture 同时烘入饱和红色外壳、亮红过渡、近白实体核心和仅超出轮廓一小圈的柔光，每颗弹只显示一个 `NORMAL` Image，不叠独立 ADD 外晕。外壳长度由原判定段 `1.35x` 缩短 `20%` 为 `1.08x`，厚度仍为原弹体 `0.52x`；过渡宽高为外壳 `90% / 82%`，核心为 `76% / 54%`，整张显示包围仍为 `1.95x / 3.2x`。缩短时锁住既有尾端锚点，只让前端内收；判定段、三点命中盒、弹速和寿命不变。

### 6.2 警棍

- 轻 / 重基础伤害默认 `12 / 20`。
- 左键恢复近战伤害。手持警棍贴图、握把、镜像和挥击动作保持不变，攻击瞬间结算准星方向的深紫实心扇形；扇形距离内且角度覆盖到的所有敌人各受击一次，并沿攻击方向获得原警棍轻击击退。范围边缘使用与重击一致的低强度外光、紫色主边与近白亮芯，但整体仍更短、更快消退。
- 左键不读取、销毁或改变任何敌弹，Boss 弹和普通弹都保持原轨迹。P Menu 的“警棍轻击范围角度 / 距离范围”作为满 ComboMeter 上限。
- ComboMeter `0–5` 级时，正确轻击角度从 P Menu 上限的 `50%` 线性成长到 `100%`；默认 `180°` 上限对应约 `90 / 108 / 126 / 144 / 162 / 180°`。距离从默认上限 `300px` 的 `88%` 温和成长到 `100%`；Fever 清屏期间按满级范围结算。错拍轻击在当前等级基础上使用 `70%` 角度与 `50%` 距离。
- 玩家有 WASD 移动输入时，警棍攻击只播放武器和特效，角色继续 Run；站定攻击仍播放完整攻击动作。

### 6.3 ComboMeter、Fever 和掉落

- 每次正确踩拍按判定增加 ComboMeter：Perfect `+4`、Good `+3`。连续正确完成当前武器的完整四段 Pattern 后再奖励 `+10`；其中任一步错拍、错键或漏拍都会中断连招，不发这 `10` 点完整奖励。全 Perfect / 全 Good 的完整 Pattern 分别共得 `26 / 22` 点。
- ComboMeter 影响弹幕数量与伤害倍率；正确四拍、Fever 和正确输入可触发瞬时反馈，但不会留下常驻扩散框。
- 普通状态 ComboMeter 默认以 `1.0 点/秒` 持续流逝，最低为 `0`；达到满格并触发 Fever 的同一帧，Meter 立即清为 `0%`，不再用量表圆环缓慢显示 Fever 剩余拍数。
- 教学与正式关 ComboMeter 满格时都会进入 Fever：贯穿画面高度的橙金光条以 `760ms` 从左向右清除敌弹，玩家弹保留。Fever 不再按拍数持续，光条完成清屏的同一刻立刻结束并恢复 `20 HP`；战斗中没有其他回血。教学结束进入第一关时仍把生命重置为关卡初始满血，但不视为战斗回血。
- 玩家初始永久拥有荧光棒。清空 Wave 2 并等待 `2s` 后先暂停第三波生成，在场地中央固定掉落警棍，并复用玩家头顶气泡依次显示“拾起新的武器吧。”“新的武器会带来新的节奏型。”；玩家关闭第二句后才建立并启动 Wave 3。警棍需由玩家走近拾取，拾取后永久加入库存并自动装备，同时播放双层扩散环、八向光束、武器图标和“已装备 · 警棍”的短时换装反馈；之后鼠标滚轮只在已拥有武器间循环切换，换武器会中止当前四拍连招。教学关不解锁或切换警棍，警棍不再由普通保安随机掉落。
