# MusicGameDemo 简化玩法策划案（当前原型）

> 本文只描述当前可运行原型。长期设想见《2D音乐弹幕游戏策划案（持续更新）》，历史调整见《实机落地与调整记录》和 `docs/更新记录/`。

## 一、当前验证目标

- 验证“自由走位 + 自动瞄准 + 任意鼓点起手的武器四段连招 + 两类武器 + 节拍弹幕”的循环。
- 验证教学池塘与正式粉紫广场两套环境、四步操作教学、波次编队、ComboMeter 和 Fever 清弹。
- 内部画布固定为 `2560 x 1440`（2K）；低分辨率屏幕由 Phaser FIT 等比缩放，不阻止进入游戏。
- 程序 UI 以旧 `1280 x 720` 设计坐标乘 `2`，项目方 PSD 以 `1920 x 1080` 源布局乘 `4/3` 显示到 2K。

## 二、流程与操作

1. 标题页使用 `backgrounds/intro/intro-title-background.png` Cover 铺满并保留安全出血；开始按钮实际中心为 `(2120,460)`、尺寸 `440 x 120`。
2. 点击开始后依次播放 `intro.mp4` 与 `intro-rocket.mp4`，随后进入教学。标题页或任一视频期间按 `Space` 可跳过全部片头。
3. 教学完成连续三套完整连招后，轻攻击进入正式关，重攻击重练；教学中按 `Space` 可直接进入正式关倒计时。
4. 正式关按波次持续战斗，清空第五波后继续重复第五波编队并累计 Wave 编号。

| 输入 | 当前行为 |
|---|---|
| `W A S D` / 左摇杆 | 带惯性的八向移动 |
| 鼠标左键 / `Quote`（`"` 键） | 轻攻击 |
| 鼠标右键 / `Enter` | 重攻击 |
| 左 / 右 `Shift` 或 `LB` | 沿当前移动方向闪避 |
| `RB` | 自动提交当前连招所需输入；不在连招中时提交轻攻击起手 |
| `Esc` | 打开 / 关闭音量设置；P 面板打开时切换到音量设置 |
| `P` | 打开 / 关闭四页战斗调参面板 |
| `R` | 重新开始 |
| `F` | 调试时充满 ComboMeter |
| `C` | 调试时触发 Fever 同款从左向右清弹光条 |
| `Space` | 跳过标题 / 视频，或从教学直接进入正式关 |

自动瞄准不显示方向短线。默认从所有有效目标中选择综合优先级最高者；移动方向前方总角度 `45°` 的扇区内，有效距离按一半计算，因此真实距离为普通目标两倍时仍可获得相同距离权重。教学展示粉丝也会加入候选。

## 三、教学关与 UI

### 3.1 PSD 环境和分层

- 池塘底图只包含环境；项目方 PSD 中的教学面板、进度面板、底栏、石子和操作卡保持为独立透明资源。
- 所有源 PSD 坐标按 `4/3` 转成当前 2K 坐标，运行时不再使用 1920×1080 作为画布口径。
- 教学容器绘制顺序为：进度面板 → 静态底栏 → 石子前景 → 当前操作卡。石子因此位于底栏白线上方，操作卡仍在最上层。
- 教学关隐藏实时 HP、ComboMeter、武器状态和 FPV，只显示 PSD 静态底栏；静态图上的 `100 / 100`、ComboMeter 方格和“荧光棒”不是运行数值。

### 3.2 四步操作卡

- 顺序固定为：左键轻攻击 → 右键重攻击 → Esc 设置 → L / R Shift 成功冲刺。
- 同一时刻只显示当前卡；淡入 `280ms`、完成后淡出 `220ms`，步骤之间留 `100ms`，首张卡在进入教学后延迟 `160ms` 开始。
- 前两张必须实际提交对应攻击，Esc 必须真正打开设置，最后一张必须成功启动冲刺；乱序操作照常执行玩法，但不提前推进教学卡。
- 卡片从开始淡入时就记为“本页面会话已出现”。完成页重练或按 `R` 后，已出现的卡不会再次出现；四张都出现后不再循环。完整刷新页面才重置这份会话记录。

### 3.3 连段练习和展示粉丝

- 连段固定为轻、轻、轻、重；教学面板图形和文字直接来自透明稿，逐步高亮只裁剪当前格，不重绘面板。
- 连续完成 `3` 套完整连招即完成教学；任意踩中鼓点的轻攻击均可起手，后续输入只按连招步骤判断。输入时机也用于延迟校准，校准只平移后续判定时钟，不改变音乐时钟或提示节拍。
- 教学展示粉丝每 `2` 个小节刷新，不持武器、不攻击；它会以正式粉丝移动速度的 `68%` 追随玩家，并可被自动锁定。

## 四、节拍、判定与画面提示

- 固定 `132 BPM`、`4/4`；背景每拍使用相同短鼓点，不区分轻重。输入序列随当前武器变化：荧光棒为轻、轻、轻、重，警棍为轻、轻、重、重。任意踩中鼓点的轻攻击开始一套连招，后续仅按该套连招的下一步判断，不绑定全局小节拍位。教学初始使用荧光棒，因此教学稿显示轻轻轻重。
- 攻击窗口为拍点前后各 `0.2s`。校准后绝对误差 `≤100ms` 为 `PERFECT`，`100–200ms` 为 `GOOD`；超出窗口、当前连招步骤轻重类型错误，或下一步拍点后 `0.2s` 仍未输入都判定失败。任意错误输入都会清空当前连招状态并以原 Poor 攻击结算；漏拍不生成攻击但同样清空连招；未处于连招时，踩中的重攻击也仅按 Poor 攻击结算。
- 仅在连招内正确踩中鼓点时播放原有轻/重“嘿”；播放起点裁到各素材响度峰值前的短起声，移除更前方的低能量前段。除 BGM、每拍统一背景鼓点和这两种正确输入“嘿”外，常规攻击、错误攻击、受击、Combo、Fever、拾取和敌亡均不触发场景音效。
- Perfect / Good 按正确攻击结算；最终伤害为“当前武器轻 / 重基础伤害 × 判定倍率 × ComboMeter 倍率”。默认判定倍率为 `1.2 / 1.0 / 0.5`。
- 教学和正式关都不创建全局常驻的未来拍扩散提示。正确输入仍显示起始 Alpha `0.5` 的短时判定框；连招首拍命中后，第 2–4 步恢复旧版小节预告框：三框按剩余目标拍、原 `0.7x → 1x`、`2.4` 拍指数曲线缩放，进入提前输入窗口时完成一半视觉路程，并按该步轻 / 重类型着色。正确框、Fever 临时边框和重拍边缘冲击均锁在屏幕坐标，不随镜头前探漂移。
- 正确重拍的边框粒子保留，随机少量粒子会强化为更长、更亮的烟花主束。
- 教学与正式关都不显示常驻战斗区描边、边缘跳变色块、任何未来拍整场扩散框或底部汇聚节奏条。

## 五、玩家、闪避与反馈

- 玩家使用 Idle / Run 各 8 帧、Dash 12 帧；受击时以保留原贴图纹理的暖粉色 `MULTIPLY` 短闪 `140ms`，不再整张填成纯白。
- 玩家和敌人以脚底为锚随轻 / 重拍只向上做 Y 轴果冻律动：轻拍高度 `105%`、`170ms` 回归；重拍 `110%`、`220ms` 回归。仅有上 / 下移动输入时，玩家不执行这项 Y 轴缩放。
- 闪避距离 `160px`、位移 `140ms`，Dash 动画 / 动作锁共 `360ms`，位移结束后继续收势 `220ms`。拖影只在实际位移阶段出现。
- 拍点前后 `0.12s` 内闪避扣 `10` ComboMeter，窗口外扣 `20`；ComboMeter 为 0 时，两次有效闪避至少间隔 `500ms`。Fever 中对应冷却改为 `1.6 / 3.2` 拍。
- 闪避开始约 `93ms` 后释放半径 `190px` 的全圆音波，清除敌弹并按 Fever 重拍同款伤害结算，不返还 ComboMeter。
- 玩家战败时，玩家与存活敌人停止位移并保持 Idle，清除场上敌我弹幕和命中盒，保留场景并显示重开提示。

## 六、武器与 ComboMeter

### 6.1 荧光棒

- 轻 / 重基础伤害默认 `10 / 18`，弹速 `360 px/s`。
- 正确攻击基础 `1` 发，每升 1 个 ComboMeter 等级增加 1 发，最多 `5` 发；错误输入只保留中线 1 发。
- 无限射程默认开启；关闭时默认最远 `164px`，错误输入的长度和飞行距离为当前有限值的 `50%`。
- 重击“贯屏激光”默认开启：充能延迟 `0ms`，粗细 `56px`，仍读取当前重击伤害、判定和 ComboMeter 倍率。
- 玩家直射为细长线性自发光：一张运行时 `128 x 64` CanvasTexture 同时烘入饱和红色外壳、亮红过渡、近白实体核心和仅超出轮廓一小圈的柔光，每颗弹只显示一个 `NORMAL` Image，不叠独立 ADD 外晕。外壳长度由原判定段 `1.35x` 缩短 `20%` 为 `1.08x`，厚度仍为原弹体 `0.52x`；过渡宽高为外壳 `90% / 82%`，核心为 `76% / 54%`，整张显示包围仍为 `1.95x / 3.2x`。缩短时锁住既有尾端锚点，只让前端内收；判定段、三点命中盒、弹速和寿命不变。

### 6.2 警棍

- 轻 / 重基础伤害默认 `12 / 26`。
- 正确攻击基础 1 段，每升 2 个 ComboMeter 等级增加 1 段，最多 `3` 段；错误输入只保留中线 1 段。
- 轻击角度默认 `180°`、距离 `111px`；Poor 只把覆盖角缩到 `50%`。
- 重击“击退月牙波”默认开启，正确重击最远 `424px`，Poor 为当前值 `50%`，末段减速后急停。
- 扫击视觉为 `NORMAL` 紫色实线主体与窄浅色内芯，外侧另画一条低 Alpha `ADD` 贴边光；不为每层创建 Glow / Bloom、逐帧尾迹或镜头缩放回弹，范围、伤害和命中体不变。
- 玩家有 WASD 移动输入时，警棍攻击只播放武器和特效，角色继续 Run；站定攻击仍播放完整攻击动作。

### 6.3 ComboMeter、Fever 和掉落

- ComboMeter 影响弹幕数量与伤害倍率；正确四拍、Fever 和正确输入可触发瞬时反馈，但不会留下常驻扩散框。
- Fever 满格时，贯穿画面高度的橙金光条以 `620ms` 从左向右清除敌弹，玩家弹保留；Fever 中每次正确输入额外恢复 `10 HP`。
- 保安掉落警棍，粉丝掉落荧光棒，默认概率均为 `100%`。玩家已持有或场上已有同种掉落时，不再进行同种掉落判定。

## 七、敌人、弹幕与波次

### 7.1 保安与粉丝

- 保安 / 粉丝移动速度为 `44 / 66 px/s`，每拍只重选一次带随机偏差的方向，拍间匀速移动。
- 两类敌弹默认速度均为 `144 px/s`、伤害均为 `12`，节拍突进默认关闭；打开后只重分配每拍内路程，不改变总位移。
- 保安默认 `1 次/拍` 单发青色点状自发光弹；粉丝默认 `0.25 次/拍`，每次有 `10%` 概率生成三弧共 30 个橙红点弹，否则量化方向单发。
- 正式保安使用 Idle / Run 各 8 帧，显示比例相较此前再放大 `1.25x`；警棍再放大 `1.25x`，以握把为锚跟随左右朝向镜像，保持原色且不加 Tint / Bloom，攻击时挥击 `200ms`。
- 粉丝使用正式 8 帧 Run，攻击时显示 `NORMAL` 橙红实色 Hard 特效、叠加克制的贴边 Glow / Bloom，并挥动专属荧光棒。存活敌人受击时以保留贴图纹理的暖粉色 `MULTIPLY` 短闪 `120ms`；致死命中不再套受击闪色。敌人被击败时在死亡位置触发一次性爆炸粒子与冲击环，保安使用青色系、粉丝使用橙红色系，短暂扩散后自动销毁。
- 敌方弹幕使用单张运行时 `64 x 64` CanvasTexture：中层 / 核心半径为实色外球的 `82% / 56%`，保安依次使用 `#18b6cf / #7ff7ff / #f2ffff`，粉丝依次使用 `#d92c16 / #ff7832 / #fff6cf`；柔光与三段颜色烘在同一纹理内，每颗弹只显示一个 `NORMAL` Image。浅粉地面上必须同时看出饱和轮廓和暖白 / 冷白核心，不能夹成纯白光球或空心色环。玩家攻击保持缩短后的线性胶囊语言；点光包围和线光 `1.95x / 3.2x` 外部纹理包围不变。

### 7.2 波次编队

| 波次 | 总数 | 编队 |
|---|---:|---|
| Wave 1 | 2 | 1 粉丝 + 1 保安 |
| Wave 2 | 6 | 2 组三人编队；每组中央粉丝 + 两侧保安 |
| Wave 3 | 12 | 4 组三人编队；每组中央粉丝 + 两侧保安 |
| Wave 4 | 18 | 9 组一粉丝 + 一保安的配对编队 |
| Wave 5 | 24 | 12 组一粉丝 + 一保安的配对编队 |

首次清空第五波后每隔 `2s` 重复第五波的 24 只敌人，顶部 Wave 继续累计。

## 八、正式关环境、HUD 与镜头

- 正式关使用 `pink-stage-runtime-base.png` 和 35 张透明环境物件，源布局统一按 `4/3` 映射到 2K。底图 depth `-20`，正确判定框 `-19`，环境物件按底边排序但限制在 `-18` 至 `-17.5`，不会遮住角色。
- 环境物件按拍回弹：轻拍 `100.3% x 101%`、单程 `80ms`；重拍 `100.6% x 102.2%`、单程 `110ms`，随后 yoyo 回归。每个物件顶部还有小型橙白粒子花，轻拍比例 `0.9`、重拍 `1.38`。
- 正式关顶部四段节奏条默认隐藏。任意踩中鼓点的轻攻击起手后显示，四个当前武器图案恢复 `7aae97b` 的无底板样式，并由紧凑版 `58%` 放大至 `116%`、中心约为 `(1200,130)`；当前待输入步骤在每拍缩放，正确轻 / 重输入分别短闪青色 / 黄色，完成连招后隐藏。连招出错或漏拍时，节奏条先红闪、横向震动，再隐藏。倒计时阶段不显示“准备…”，开波后的 Wave 文字位于上方 `(1200,38)`。
- 正式 ComboMeter / 武器组使用轻透白线程序框，整体由 `72%` 放大至 `144%`，基础框仍为 `184 x 50` 设计单位，中心保持 `(1190,1374)`，最终 2K 外框约为 `(925,1302,530,144)`；Combo 圆环、武器名、Fever 与实时反馈逻辑不变。旧左上 HP 框不再显示；HP 改为 `144 x 50` 世界单位的小框，血条宽 `128`，中心跟随玩家原点并向上偏移 `80px`。
- 右下 FPV 为 `480 x 306`，距屏幕边缘 `40px`；可在 Esc 设置中开关。教学关不显示 FPV。
- 战斗活动区为 `(96,96,2368,1248)`。主镜头基础 zoom `1.065x`，死区为活动区 `3%`，水平 / 垂直最大前探约 `45 / 30px`，约 `220ms` 阻尼；四拍图案、Wave、ComboMeter / 武器、设置、P 面板和 FPV 保持屏幕锚定，玩家 HP 是玩家正式 HUD 中唯一随世界坐标移动的组件。

## 九、音频、设置与调参

- 教学默认 `bgm0.mp3`，正式关默认 `bgm2.mp3`；所有 BGM 按 `132 / 源 BPM` 同时缩放声音与 Conductor，首拍偏移和循环边界按倍率对齐。BGM 内部基础混音由 `0.0625` 翻倍为 `0.125`；Conductor 每拍播放同一枚旧荧光棒轻攻击音色的短鼓点，响度为此前 `3x`，连招命中才播放裁短前段的轻/重“嘿”。
- Esc 面板共九路滑杆：主音量、BGM、节拍喊声、攻击与错误、受伤与敌亡、Combo 提示、Fever 音效、拾取音效、敌人死亡音效。前八路默认 `100%`、范围 `0–200%`；敌人死亡音默认及上限均为 `100%`。
- 设置面板按旧 `600 x 650` 设计放大到实际 `1200 x 1300`。先抓取背后画面，再应用 `blur(14px) saturate(82%) brightness(106%)`、`#f2f0e8 / 0.18` 浅色雾面与白色 Alpha `0.10 → 0.035` 渐变；不使用深色全屏遮罩。中文使用 Microsoft YaHei 系列并以 `resolution=2` 渲染。
- 设置和 P 面板出现时，节拍时钟、BGM、物理、动画、补间和玩法输入均暂停；P 面板打开时按 Esc 直接切换到音量面板。
- P 面板有四页：速度 / 频率、玩家伤害、敌人 / 掉落、模式 / 导出。四种玩家攻击动作速度默认 `100%`；保安 / 粉丝攻击频率默认 `1 / 0.25 次/拍`；粉丝三弧概率默认 `10%`；敌弹节拍突进默认关闭。
