# 简化玩法策划案（原型版）

> 本文档从《2D音乐弹幕游戏策划案》中抽取**纯玩法部分**，用于无美术资源阶段的原型开发。
> 所有视觉元素用简单几何体替代。验证目标：**"自由走位 + 固定节拍开火 + 轻重连段"这套核心循环是否好玩**。

## 一、原型范围

### 保留（本次实现）

| 系统 | 内容 |
|---|---|
| 节拍系统 | 120 BPM、4/4 拍，全局节拍时钟驱动一切攻击行为，合成音效充当节拍器 |
| 玩家移动 | WASD 八向自由移动，不受节拍限制；鼠标自由瞄准 |
| 轻重连段 | 左键=轻、右键=重；按小节循环连段，打错锁定本小节，空拍无惩罚 |
| 两把武器 | 双持荧光棒（轻轻重轻）、伸缩警棍（轻重重轻） |
| ComboMeter | 正确+2%，打错清零，5 级伤害加成（+10%~+30%） |
| 闪避 | 空格朝移动方向冲刺，无敌帧；体力环 90 点；踩拍消耗减半并释放清弹震荡波 |
| 敌人 ×3 | 小型保安（警棍近战突进）、中型保安（激光笔锁定直线弹幕）、大型粉丝（摄像机直线+扇形弹幕） |
| 武器掉落 | 击杀小型保安掉落警棍，拾取后自动演示一小节 |
| 判定条 UI | 屏幕下方单中心点判定条：节奏块（○轻 ◆重）从两侧向中心汇聚，到达中心即拍点 |
| Fever Time | Meter 满 100% 触发，持续 4 小节；攻击附带清屏音波（轻=扇形、重=圆形） |
| 战斗循环 | 单房间、3 波敌人，清空获胜；HP 归零失败，R 键重开 |

### 砍掉（原型不做）

- 美术风格 / 题材包装 / 剧情演出 / 四格漫画开场
- 三关卡结构、小游戏关、Boss 战、小地图
- 保安/粉丝阵营区分（只按攻击方式选 3 种代表敌人）
- 防暴盾牌、巨型灯牌、长焦摄像机之外的武器连段
- 长按输入、背景律动

## 二、核心规则速查

### 节拍与判定

- 节拍时钟：120 BPM，每拍 0.5s，每小节 4 拍（2s）。
- 输入判定窗口：拍点前后各 **0.2s**（原型初值，可调）。
- 节拍器音效：每小节第 1 拍高音，其余低音（程序合成，无需音频资源）。
- 判定条：单中心判定点，节奏块在拍点前 2 拍从判定条两侧生成、向中心移动，
  两块在中心汇聚的瞬间即拍点；命中时在中心合并爆闪，漏拍则淡出，错误锁定期间的块变暗失效。

### 攻击连段（每小节循环）

| 武器 | 第1拍 | 第2拍 | 第3拍 | 第4拍 |
|---|---|---|---|---|
| 双持荧光棒 | 轻·左挥 | 轻·右挥 | 重·双棒横扫（大范围） | 轻·旋转收尾（360°） |
| 伸缩警棍 | 轻·横扫 | 重·蓄力（无伤害） | 重·突进（位移） | 轻·终点重击 |

- **正确输入**：窗口内 + 按键正确 + 本小节未锁定 → 立即执行该拍攻击。
- **错误输入**：窗口外按键 / 轻重按错 → 本小节剩余拍全部失效，下一小节自动恢复；播放刺耳错误音 + 角色闪红。
- **未输入**：无任何惩罚，后续拍可正常输入。

### ComboMeter

- 每次正确输入 +2%；空拍不影响；打错**直接清零**。
- 换武器后的当前小节 + 自动演示小节为保护期（不清零，但正确输入照常加进度）。

| 等级 | 进度 | 伤害加成 |
|---|---|---|
| 1 | 20% | +10% |
| 2 | 40% | +15% |
| 3 | 60% | +20% |
| 4 | 80% | +25% |
| 5 | 100% | +30% |

- UI：判定条中央圆圈显示等级，外圈显示到下一级进度。

### Fever Time

- **触发**：ComboMeter 积累到 100%（5 级）自动进入，持续 **4 小节（16 拍）**；结束后 Meter 清零重新积累。
- **效果**：期间每次成功攻击（含连段本身效果）额外释放清屏音波：
  - 轻攻击 → 朝瞄准方向的**扇形音波**（半角 55°，半径 230）；
  - 重攻击 → 以玩家为中心的**圆形音波**（半径 190）。
  - 音波波前抵消途经的所有弹幕，并对敌人造成一次伤害（轻 10 / 重 14，乘 Combo 加成）。
- **演出（判定条处的节拍反馈）**：
  - 进入瞬间："FEVER TIME!" 弹出 + Meter 处三重冲击环 + 上行琶音 + 屏幕震动；
  - 持续期间：每拍 Meter 处橙色脉冲环 + 判定条边框橙色闪烁 + 场地边框随节拍呼吸发光；
  - Meter 圆环变为橙色倒计时环（显示 F），结束时下行提示音。
- **积累感**：非 Fever 期间，每拍在 Meter 处按当前等级发出渐强的脉冲环（等级越高越亮越大）。
- 原型调试键：**F** 直接充满 Meter。

### 闪避

- 空格触发，朝当前 WASD 方向（无输入则朝鼠标方向）位移 2 个角色身位，easeOutQuint 曲线，带拖影。
- 位移期间无视弹幕与敌人碰撞（无敌），不可穿墙。
- 体力环 90 点，每拍恢复 10 点；未踩拍消耗 30，踩拍（拍点 ±0.12s）消耗 15 且在终点释放震荡波，**清除半径内所有弹幕**。
- 体力 <30 时体力环变暗红警示。

### 敌人（自由移动、节拍开火）

| 敌人 | 几何体 | 行为 | 节拍行为 |
|---|---|---|---|
| 小型保安 | 蓝色小方块 | 追击玩家 | 1拍横扫 → 2拍蓄力预警 → 3拍突进 → 4拍终点重击 |
| 中型保安 | 蓝色三角 | 保持中距离 | 1拍激光线锁定跟踪 → 2拍固定方向发射直线弹幕 → 3拍再锁定 → 4拍再发射 |
| 大型粉丝 | 粉色大圆 | 保持远距离 | 1~3拍每拍朝玩家发射 1 枚直线弹幕 → 4拍发射扇形弹幕（5 枚） |

- 所有弹幕在拍点生成，弹速恒定；激光锁定阶段画出瞄准线预警。

### 武器掉落与自动教学

- 小型保安死亡掉落伸缩警棍（地上旋转的黄色矩形），走近自动拾取替换。
- 拾取后：当前小节为切换保护期 → 下一完整小节系统按完美节奏自动演示连段（朝玩家瞄准方向）→ 再下一小节交还控制。

### 数值初值（原型可调）

| 项 | 值 |
|---|---|
| 玩家 HP | 100 |
| 玩家移速 | 260 px/s |
| 荧光棒轻/重/收尾伤害 | 10 / 22 / 18 |
| 警棍轻/突进/重击伤害 | 12 / 8 / 26 |
| 敌人 HP：小保安/中保安/大粉丝 | 40 / 60 / 90 |
| 敌人弹幕伤害 | 8~12 |
| 敌人近战伤害 | 10~15 |
| 波次 | 第1波：2小保安；第2波：2小保安+1中保安；第3波：1小保安+1中保安+1大粉丝 |

## 三、几何体视觉规范

| 元素 | 表现 |
|---|---|
| 玩家 | 绿色圆 + 白色瞄准短线 |
| 玩家近战攻击 | 扇形弧线闪光（轻小重大），旋转收尾为整圆环 |
| 敌人弹幕 | 红/橙小圆点 |
| 激光预警 | 半透明红线 → 发射时变亮 |
| 蓄力预警 | 敌人身体闪烁白色 |
| 震荡波 | 扩散的空心圆环 |
| 判定条 | 底部单中心点：○=轻（左键）、◆=重（右键）节奏块从两侧向中心汇聚，中心点随节拍脉冲，错误锁定时块变暗、中心点变红 |
| 掉落武器 | 地面旋转黄色矩形 + 浮动动画 |

## 四、验证问题（原型要回答的）

1. "移动自由 + 开火锁拍"是否产生独特的操作乐趣，还是感觉束手束脚？
2. ±0.2s 判定窗口是否合适？
3. 打错锁一小节的惩罚强度是否合理？
4. 敌人节拍攻击的预警是否可读？多敌人时弹幕节奏是否能被"阅读"？
5. 踩拍闪避+清弹的奖励是否足够诱人？
