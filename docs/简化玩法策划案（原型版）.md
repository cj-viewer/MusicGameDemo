# 简化玩法策划案（当前原型版）

> 最后核对：2026-08-14
>
> 本文档只描述 `dev-1.0` 当前可运行原型。长期目标与未落地设计见《2D音乐弹幕游戏策划案（持续更新）》，精确参数与逐次改动见《实机落地与调整记录》。三份文档冲突时，以当前代码和《实机落地与调整记录》的“当前实机规则”为准。

## 一、当前验证目标

验证“自由走位 + 固定节拍攻击 + 轻重连段 + 节拍弹幕”是否能形成清晰、可读的战斗循环。

当前范围：单场地、五波敌人、两把武器、键鼠和手柄操作、ComboMeter、Fever Time、与节拍对齐的 BGM，以及玩家和粉丝敌人的独立序列帧。多房间、Boss、剧情、正式音乐关卡、玩家拾取动画，以及保安的正式动画接入尚未实现。

开局流程为：先显示游戏标题“节奏星球”、副标题“DJ Drop the Beat”和“开始”按钮；玩家点击后带原声播放一次开场动画，播放完成后直接进入教学。标题页和视频播放期间均可按空格跳过片头并直接进入教学。

## 二、操作

| 输入 | 行为 |
|---|---|
| `WASD` | 带惯性的八向移动 |
| 自动瞄准 | 默认锁定综合优先级最高的敌人；移动方向前方总角度 `45°` 的扇区内，敌人的有效距离按实际距离一半计算 |
| `"` 键 / `Enter` | 轻攻击 / 重攻击 |
| 鼠标左键 / 右键 | 轻攻击 / 重攻击 |
| 左 `Shift` / 右 `Shift` | 沿当前移动输入方向闪避 |
| `Esc` | 打开 / 关闭设置面板；面板打开时游戏完全暂停，可分别调主音量、BGM、音效和右下 FPV 观察窗 |
| 左摇杆 | 模拟量移动；右摇杆不再控制瞄准 |
| `LB` | 闪避 |
| `RB` | 攻击；自动采用当前拍要求的轻或重输入 |
| `R` | 重新开始 |
| `F` | 调试：直接充满 ComboMeter |
| `P` | 打开 / 关闭调参面板；可调整弹速、BGM 槽并开关敌方弹幕节拍突进 |
| `Space` | 在标题页或开场视频期间跳过片头，直接进入教学 |

鼠标移动不再控制瞄准，但保留鼠标左 / 右键作为轻 / 重攻击；键盘轻重攻击同样要求玩家区分输入。手柄不使用 `RT` 攻击，`RB` 只合并轻重按钮，不绕过节拍窗口。自动瞄准使用加权距离：扇区外敌人按实际距离计分，当前移动方向前方左右各 `22.5°`（总角度 `45°`）内敌人按实际距离除以 `2` 计分，分数最低者被锁定。因此前方距离为 `2` 的敌人与扇区外距离为 `1` 的敌人同优先；没有敌人时保持最后一次有效移动方向。

片头播放完毕或按空格跳过后直接进入教学场景，不再显示第二层全屏标题字幕或“点击开始”。教学关左下显示低透明度精简操作卡：左栏以同一基线排列 `WASD / 移动` 和左右 `Shift / 冲刺`，右栏排列双引号键或鼠标左键 / 轻攻击、`Enter` 或鼠标右键 / 重攻击、`Esc / 设置`。操作卡不重复显示自动锁定说明或四拍顺序，只用于视觉教学；它位于底图之上、角色之下，进入正式游戏后隐藏。顶部连段面板不再重复显示“左键等于轻、右键等于重”。连续三个小节完成后，轻攻击直接进入正式关，重攻击重新进行教学；手柄 `RB / LB` 分别映射为进入 / 重练。

## 三、节拍与判定

- `132 BPM`、`4/4` 拍，每拍约 `0.455s`、每小节约 `1.818s`。四首 BGM 均按 `132 / 各自源 BPM` 的倍率播放，因此音乐、Conductor、判定和视觉拍点等比例放慢；每首曲目的源文件首拍偏移在播放时按倍率换算，并继续与节拍时钟第 0 拍对齐。
- 攻击窗口为整数拍前 `0.2s`、拍后 `0.1s`；同一拍最多结算一次输入。
- 教学要求连续三个完整小节全对；教学期间收集按键种类正确、距离原始拍点 `≤180ms` 的输入时间差，其中 `≤120ms` 的稳定样本以中位数和离群值剔除估算设备延迟。校准值限制在 `±120ms`，只平移后续输入判定时钟，不改变 BGM、拍点提示或音效时钟。
- 正确输入会执行完整攻击并积攒能量；错误输入仍攻击，但只保留中间弹丸且不积攒能量。
- 错误输入不会清空 ComboMeter，也不会禁止本小节后续攻击；空拍无惩罚。
- 教学与正式游戏均使用场地判定框，教学不再显示底部汇聚式节奏条；教学练习期间继续保留顶部四拍连段、三小节要求和延迟校准。进入正式关时彻底销毁顶部连段背板、图标和文字，之后切换武器也不重建。场地中央同时显示未来 `1 / 2 / 3` 拍的三个缩放框。每个方框从场地 `0.7x` 尺寸出发，在 `2.4` 拍内按单条归一化 `easeInExpo` 曲线扩大（原三拍周期的 `80%`，因此出现晚 `20%`、平均速度为 `1.25x`）：曲线强度由攻击提前窗口动态校准，距拍点还有 `0.2s` 时恰好走完 `0.7x → 1x` 的一半视觉路程、到达 `0.85x`，随后以连续的由慢到快速率抵达边界；全程不在窗口起点换曲线或突变。轻拍粉紫框与重拍橙色框的初始透明度均为 `0`，两者统一按 `Expo.In` 淡入，橙色框将透明度进度压缩到原时长的 `90%`，稍早达到峰值。每个方框到达大框边界的瞬间就是对应拍点，随后立即隐藏且不会越过场地框；正确输入额外触发对应颜色的粗边框轻微外扩并淡出。
- 轻重喊声跟随当前武器的四拍序列，不因输入正确与否改变：轻拍基础音量为 `0.42`（上一版 `0.28` 的 `150%`），重拍保持 `0.28`。为补偿素材前置起声，轻、重喊声分别提前 `70ms / 74ms` 播放；重喊声在素材时间 `330–360ms` 淡出，避免跨到下一拍。

## 四、玩家、闪避与反馈

| 参数 | 当前值 |
|---|---:|
| HP | 100 |
| 最高移速 | `260 px/s` |
| 加速 / 减速 | `1050 / 720 px/s²` |
| 闪避距离 / 时间 | `160px / 140ms` |
| 正确 / 错误闪避消耗 | ComboMeter `10 / 20` 点（半级 / 一级） |
| 闪避判定窗口 | 拍点前后各 `0.12s` |

- 左下 HP 血条与 ComboMeter 归为同一信息区，二者处于同一水平基线；Combo 环向右移动其自身宽度的一半（`22px`），并跟随当前武器轻重拍进行更明显的律动。轻拍前纵向压缩到 `0.84x`、拍点弹到 `1.26x`；重拍前压到 `0.62x`、拍点弹到 `1.50x`。颜色沿用轻拍 `3%`、重拍 `5%` 的明度 / 饱和度变化限制；横向长度始终只表示剩余 HP，数值文字不缩放。
- 武器名位于 ComboMeter 圆环右侧，以 `22px` 粗体显示，并统一只使用“荧光棒 / 警棍”两个短名称；右上角不显示常驻设置提示。
- 闪避必须存在移动输入，不会改为朝锁定目标方向移动。
- 闪避期间忽略敌人与弹幕碰撞，终点受场地边界限制。
- 闪避不再使用体力；正确 / 错误闪避分别扣 `10 / 20` 点，最低扣到 `0`。ComboMeter 已为 `0` 时，两次成功启动的闪避至少间隔 `500ms`；非空时仍按原输入节奏响应。Fever 激活期间等比例缩短 `1.6 / 3.2` 拍剩余时间。
- 每次闪避进行到总时长的三分之二（约 `93ms`）直接释放 Fever 重拍同款全圆音波与音效，波前、`190px` 半径、清弹和伤害结算全部复用 Fever 圆波逻辑。音波伤害为 `14 × 当前 Combo 伤害倍率`，每个敌人只结算一次，且不返还 ComboMeter。
- 玩家受伤后有 `600ms` 受伤无敌；玩家与敌人受击时，本体 Sprite / Image 分别使用纯白填充闪烁 `140 / 120ms`，并保留火花、震屏等反馈。
- 玩家使用正式红发角色状态机：静止循环 `Idle` 8 帧，移动循环 `Run` 8 帧，闪避播放 `Dash` 12 帧。`Attack Light / Hard` 的 5 帧 PNG 是纯攻击特效层，必须与角色 `256 x 256px` 画布同中心、同翻转并在播放期间跟随角色，绘制在角色和武器身后。Light 素材没有透明渐变，运行时统一使用 `0.45` 不透明度；Hard 保留素材自身 Alpha 渐变并放大至角色基准的 `1.18x`。两者另叠加 ADD 自发光副本，重击使用更高 Alpha 和更大的扩散倍率。实际轻攻击始终播放 Light，实际重攻击始终播放 Hard，错误输入也不串用。弹幕、警棍扫击、踩拍强调和 Fever 音波仍从角色中心向朝向侧轻移的统一攻击锚点生成。闪避位移仍在 `140ms` 内完成，Dash 动画持续 `240ms`，即在位移结束后保留 `100ms` 收势；冲刺拖影每 `30ms` 采样一次。战败随机播放 `Death1 / Death2` 其中一套 `800ms` 动画；除玩家外的场景层同时用 `28px` 随机块在 `820ms` 内溶解为纯黑，死亡角色始终绘制在溶解层上方并停在末帧。
- 正式玩家帧均为 `256 x 256px` 透明画布，Idle / Run 的可见内容高度约 `100–116px`、脚底约在源图 `y=186`。1080p 内部画布使用约 `0.7067x`，内部可见高度约 `76.3px`、固定受击体约 `29.7 x 76.3px`；等比显示到旧 720p 窗口时仍约为 `50.9px / 19.8 x 50.9px`，维持此前视觉大小。透明画布不参与碰撞。
- 内部开发画布固定为 `1920 x 1080`，低于该物理分辨率时不启动游戏；全局使用 Nearest Neighbor / 像素整数渲染。战斗区边界为 `x=141–1779`、`y=18–939`（`1638 x 921px`），屏幕左、右、下三侧各腾出 `123px` 专用律动带；玩家、敌人和掉落均限制在战斗区内。
- 三侧共约 140 根深紫粉色竖直律动条：左、右各 38 根，下侧 64 根。下侧使用两条交错轨道，保留横向 `±5px`、纵向 `±4px` 的随机错落；左右使用三列近似等距轨道，保留横向 `±4px`、纵向 `±2.5px` 的随机错落。各轨道安全间距仍足以避免大面积完全重叠。单根宽 `22–26px`；左右高度 `36–40px`，下侧高度 `42–50px`。所有条全程保持 `100%` 不透明且没有碰撞盒，跳动时允许侵入战斗区。轻拍提升约 `3%` 明度、降低 `3%` 饱和度；重拍提升约 `5%` 明度、降低 `5%` 饱和度。每个拍间只跟随下一拍：轻拍前始终保持粉紫色；重拍前也保持粉紫色，只在攻击判定窗口开启前最后 `0.2s` 内向橙色过渡。攻击判定从拍点前 `0.2s` 开始，所以转色从拍点前 `0.4s` 开始、到拍点前 `0.2s` 完成，并保持到重拍落点；第二、第三个预告框不参与律动条配色。三侧均使用轻 / 重约 `1.3x / 1.85x` 跳高。
- 律动条、玩家、保安和粉丝按脚底 Y 动态排序：屏幕下方对象遮挡上方对象。玩家手持武器和敌人血条使用所属角色相邻深度，整体仍参与同一 TopDown 遮挡关系；自动索敌不绘制攻击方向指示线。
- 1080p 内部画布的程序化场内对象使用 `1.2x` 倍率（旧 `0.8x × 1.5`），屏幕占比保持不变；正式红发玩家、攻击特效和正式武器使用各自显式比例。玩家移动、伤害、BPM 和判定窗口不因分辨率迁移而改变；敌人速度以本节当前 `44 / 66 / 72 px/s` 匀速规则为准。HUD、场地与律动带由旧 720p 排版统一按 `1.5x` 迁移，圆形能量表标题常驻为 `ComboMeter`。

## 五、武器

### 荧光棒

- 四拍输入：`轻 → 轻 → 轻 → 重`。
- 正确输入的弹丸数为 `ComboMeter 等级 + 1`：等级 `0–5` 对应 `1–6` 枚；错误输入只发射瞄准方向正中的 1 枚。
- 第一枚固定在瞄准中线，此后每升一级按左、右交替增加 `±7.5°、±15°、-22.5°` 偏移弹丸。每枚 `30.4 x 8px`，弹速 `360 px/s`，在下一个整数拍消失。
- 击退方向沿弹丸方向，速度 `150 px/s`，持续 `160ms`。
- 玩家持有正式荧光棒贴图 `light_stick_player.png`，按约 `0.5653x` 显示；旋转原点为素材握把末端 `(101/128, 98/128)`，固定在角色腰部中线、内部下移 `22.5px`。武器绘制在角色前方，另一朝向使用负 `scaleX` 围绕 Origin 做几何镜像，禁止用 `flipX` 翻 UV。

### 警棍

- 四拍输入：`轻 → 轻 → 重 → 重`。当前四拍均执行警棍弧形扫击，不附带角色位移。
- 正确输入的弧段数同样读取 ComboMeter：等级 `0` 只启用中层，等级 `1` 增加内层，等级 `≥2` 再增加外层；错误输入只保留中层。完整三层的形状、半径与运动方式不变。
- 内、中、外半径为 `55.6 / 74 / 92.4px`，弧段长度比例为 `0.5 / 1 / 1.5`。
- 轻拍顺时针覆盖 `90°`，重拍逆时针覆盖 `120°`；弧段在 `150ms` 内完成行程并销毁。
- 击退沿弧段运动方向，速度 `187.5 px/s`，为荧光棒的 `1.25x`。
- 玩家持有正式警棍贴图 `baton_player01.png`，按约 `0.5653x` 显示；旋转原点为素材握把末端 `(123/128, 121/128)`，固定在角色腰部中线、内部下移 `22.5px`。瞄向另一侧时使用负 `scaleX` 几何镜像，静止位置和挥击轨迹严格关于角色中线对称。

手持武器不绕瞄准线旋转；轻 / 重攻击分别使用不同幅度的非线性向下挥击，并都在 `200ms` 内回到握持角。警棍只绘制发光弧线扫击，不额外绘制纯色扇形方向图形。玩家棍状武器的绘制层级为“武器 > 角色 > Attack 特效”。

## 六、敌人和波次

当前实机只生成两类敌人：

| 敌人 | HP / 半径 | 移动 | 攻击 | 掉落 |
|---|---|---|---|---|
| 保安 `SmallGuard` | `40 / 36.8 x 56px` | 每拍重选带随机偏差的方向；`44 px/s` 匀速 | 每小节第 4 拍发射 1 枚蓝弹，同时播放 Light 攻击特效 | 警棍 |
| 粉丝 `FanEnemy` | `40 / 源受击框 87 x 82px` | 加入物理组后立即写入初始速度；此后每拍重选带随机偏差的方向，拍间以 `66 px/s` 匀速跑步 | 每小节第 4 拍发射 1 枚蓝弹，同时播放橙色 Hard 特效并挥动荧光棒 | 荧光棒 |

`MidGuard` 代码仍保留，但不加入当前波次。

粉丝与玩家的正式本体画布均为 `256 x 256px`，运行时统一按约 `0.7067x` 显示；二者的正式棍状武器画布均为 `128 x 128px`，统一按约 `0.5653x` 显示。不得再把粉丝本体或武器套用程序化世界物件的 `1.2x` 倍率。

保安 Light 使用 `01–08` 八张贴图，粉丝 Hard 使用 `02–07` 六张贴图；二者都在 `500ms` 内由场景时钟逐帧切换并在末帧后隐藏。不得为独立攻击特效 Sprite 注册或播放 Phaser Animation；当前 Phaser 版本会在第一次第 4 拍调用该动画的 `.play()` 时锁住主线程。所有敌人本体必须根据当前移动 / 攻击方向左右镜像；攻击特效、专属武器和 FPV 投影必须复用本体的同一朝向，不能各自判断。

| 波次 | 保安 | 粉丝 | 总数 |
|---|---:|---:|---:|
| 1 | 1 | 1 | 2 |
| 2 | 2 | 2 | 4 |
| 3 | 4 | 4 | 8 |
| 4 | 8 | 8 | 16 |
| 5 | 16 | 16 | 32 |

两类实装敌人都在每个整数拍重选带随机偏差的方向，拍间不再使用节拍加速曲线，而是分别以 `44 / 66 px/s` 持续匀速移动；近身时随机方向偏差更大，避免大量敌人收束成规则圆环。未加入波次的中型保安移动时使用 `72 px/s` 匀速，进入保持距离区间后停下。

首次清空第五波后，场地底层常驻显示低饱和紫色纯色背板与 `VICTORY`；它们位于其他场景物件和 HUD 之下，并随之后每个轻重拍持续缩放、明暗呼吸，作为环境的一部分。游戏不会进入结束状态；等待 `2s` 后重新生成第五波的 `32` 只敌人，此后每次清空都继续重复第五波，顶部编号累计为 `Wave 6、Wave 7……`，形成无限循环与冲榜轮次记录。

主场景镜头采用轻量 Cinemachine 风格前探：1080p 基础缩放为 `1.0x`；角色在场地中央 `12%` 归一化死区内时保持居中，越靠近上下左右或四角，镜头越向对应方向平滑移动，水平 / 垂直最大约 `45 / 30px`，阻尼时间约 `220ms`。镜头只改变观看位置，不改变角色、敌人、弹幕、边界或伤害判定；HUD 与面板保持屏幕锚定，FPV 独立 Scene 不受影响。踩拍时轻 / 重最大缩放为 `1.00375x / 1.01875x`。

粉丝使用 `npc_fan01` 的正式橙色 `256 x 256px` 素材，替换旧粉丝外观而不是新增敌人类型。普通移动循环 8 帧 Run；第 4 拍攻击时角色本体继续运动，身后播放 6 帧橙色 Hard 特效，并由角色身后的专属 `128 x 128px` 荧光棒完成 `200ms` 向下挥击。保安第 4 拍在本体身后播放 Light 特效。敌人本体、武器与特效随朝向同步镜像；角色、武器、特效按“角色 > 武器 > 特效”分层；受击只对白闪，不切换旧 Roll 或近战动画。

## 七、敌方弹幕

- 蓝色长条，尺寸 `21.6 x 6px`，命中伤害 12。
- 所有敌人瞄准玩家后，都把攻击角吸附到最近的八方向扇区中线；弹丸只沿每隔 `45°` 的固定方向射出，出生偏移、贴图旋转、速度和三个命中方盒使用同一量化角。
- 存活 8 拍，即 2 小节。
- 默认基础速度 `144 px/s`，为上一版 `180 px/s` 的 `0.8x`。
- 默认关闭节拍突进，敌弹全程按 `144 px/s` 匀速移动。`P` 调参面板可手动开启；开启后每个整数拍前 `0.2s` 使用归一化 `easeInExpo` 位移曲线重分配速度，但窗口总位移仍严格保持为 `144 × 0.2 = 28.8px`。
- 突进开启且进入拍前窗口时生成与瞬时速度相关的 Trail。
- Trail 初始透明度限制在 `0.08 ~ 0.24`。
- 敌我直线弹幕沿长条方向放置头部、中部、尾部 3 个等大正方形判定盒，边长等于弹幕最细宽度；警棍弧段沿弧线前、中、后采样 3 个同尺寸方盒。Trail 仅作视觉残影，不参与命中判定；任一方盒命中后只结算一次并销毁整枚弹幕。

## 八、掉落与换武器教学

- 保安绑定警棍，粉丝绑定荧光棒。玩家已持有同种武器或场上已有同种掉落时不重复生成。
- 地面荧光棒为两根红色 `24 x 6px` 短棒；警棍为一根紫色 `40.8 x 7.2px` 长棒。
- 掉落物每个整数拍闪白 `90ms`，上浮 `10px` 后回落；玩家进入 `34px` 范围自动拾取。
- 拾取后的下一完整小节由系统自动演示新武器四拍连段，演示结束后交还控制。

## 九、ComboMeter 与 Fever Time

- 正确攻击和自动演示的基础能量为 2，经 `3x` 倍率结算为 `+6`；闪避不再获取能量，改按正确 / 错误扣除 `10 / 20` 点。
- 每 20 点提升一级伤害：1 至 5 级分别为 `+10% / +15% / +20% / +25% / +30%`。
- 100 点进入 Fever Time，基础持续 16 拍。结束后能量清零。
- Fever 期间正确输入以普通阶段一半效率回充，每次按 3 点折算为延长 `0.48拍`，剩余时长最多恢复至 16 拍。
- Fever 期间每次正确输入额外恢复 `10 HP`，生命不会超过最大值。
- Fever 正确轻拍附加半角 `55°`、半径 `230px`、伤害 10 的扇形音波；正确重拍附加半径 `190px`、伤害 14 的圆形音波。音波会清除途经敌弹并伤害敌人。

## 十、音效和手柄震动

- 游戏默认主音量为 `150%`，范围 `0–300%`；BGM 通道默认 `150%`，音效通道默认 `100%`，范围均为 `0–200%`。最终 BGM 响度为主音量 × BGM 通道 × 内部基础 `0.0375`。轻 / 重拍叫喊基础响度分别为 `0.42 / 0.28`。节拍采样与程序合成反馈为主音量 × 音效通道 × 各自基础响度。音效通道覆盖轻重鼓点/叫喊、攻击、命中、错误、受伤、拾取、Combo 和 Fever 等声音。三个滑块仅能通过 `Esc` 设置面板调整；面板打开时暂停节拍时钟、BGM、物理、动画、补间与主场景更新，除 `Esc` 和设置控件外不接收玩法输入。同一面板可开关右下 `240 x 153px` FPV 观察窗。它锚定屏幕右下角，右、下边缘均保留 `20px`，并只读投影主场景当前自动锁定方向上的玩家朝向、敌人与敌我弹幕，不改变相机、HUD、判定、移动或攻击。
- BGM 使用 `public/assets/audio/music/` 下的四首可选音轨，界面默认显示 `150%`，内部以 `0.0375` 基础音量播放。所有音轨均以 `132 / 源 BPM` 的倍率播放，首拍偏移按该倍率换算后与 Conductor 第 0 拍同步；每首音轨到自身的循环拍数边界时重新对齐，重开时停止旧实例，避免循环漂移或叠音。
- 轻拍喊声：`beat-light.mp3`，单人 `-13dB` 素材。
- 重拍喊声：`beat-heavy.mp3`，多人 `+0dB` 素材。
- 玩家受伤、进入 Fever、敌人受伤、拾取武器在整数拍播放；同拍优先级依次为：玩家受伤 > Fever > 敌人受伤 > 拾取。
- 正确轻拍震动 `60ms`，正确重拍震动 `130ms`，成功闪避震动 `90ms`；错误输入和闪避失败不震动。
