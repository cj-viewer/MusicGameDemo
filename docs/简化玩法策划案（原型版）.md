# 简化玩法策划案（当前原型版）

> 最后核对：2026-08-10
>
> 本文档只描述 `dev-1.0` 当前可运行原型。长期目标与未落地设计见《2D音乐弹幕游戏策划案（持续更新）》，精确参数与逐次改动见《实机落地与调整记录》。三份文档冲突时，以当前代码和《实机落地与调整记录》的“当前实机规则”为准。

## 一、当前验证目标

验证“自由走位 + 固定节拍攻击 + 轻重连段 + 节拍弹幕”是否能形成清晰、可读的战斗循环。

当前范围：单场地、五波敌人、两把武器、键鼠和手柄操作、ComboMeter、Fever Time，以及粉丝敌人的跑步/翻滚/近战序列帧。多房间、Boss、剧情、正式音乐关卡，以及玩家和保安的独立专属动画尚未实现。

## 二、操作

| 输入 | 行为 |
|---|---|
| `WASD` | 带惯性的八向移动 |
| 鼠标 | 瞄准；自动锁定鼠标方向前方 90 度范围内最近敌人 |
| 鼠标左键 / 右键 | 轻攻击 / 重攻击 |
| `Shift` | 沿当前移动输入方向闪避 |
| 左摇杆 / 右摇杆 | 模拟量移动 / 瞄准 |
| `LB` | 闪避 |
| `RB` | 攻击；自动采用当前拍要求的轻或重输入 |
| `R` | 重新开始 |
| `F` | 调试：直接充满 ComboMeter |

鼠标仍要求玩家区分轻重输入。手柄不使用 `RT` 攻击；`RB` 只合并轻重按钮，不绕过节拍窗口。

## 三、节拍与判定

- `120 BPM`、`4/4` 拍，每拍 `0.5s`、每小节 `2s`。
- 攻击窗口为整数拍前后各 `0.2s`；同一拍最多结算一次输入。
- 正确输入会执行完整攻击并积攒能量；错误输入仍攻击，但只保留中间弹丸且不积攒能量。
- 错误输入不会清空 ComboMeter，也不会禁止本小节后续攻击；空拍无惩罚。
- 节奏块提前 2 拍从判定条两侧汇聚。轻拍为青色圆环，重拍为黄色菱形；每个四拍小节之间有粉紫双线分隔。
- 轻重喊声跟随当前武器的四拍序列。无人正确攻击时音量为 `0.16`；正确攻击后按拍位使用 `0.28 / 0.40 / 0.52 / 0.64`，新小节重置。

## 四、玩家、闪避与反馈

| 参数 | 当前值 |
|---|---:|
| HP | 100 |
| 最高移速 | `260 px/s` |
| 加速 / 减速 | `1050 / 720 px/s²` |
| 闪避距离 / 时间 | `80px / 300ms` |
| 闪避体力 | 90 |
| 每拍恢复 | 10 |
| 非踩拍 / 踩拍消耗 | 30 / 15 |
| 闪避判定窗口 | 拍点前后各 `0.12s` |

- 闪避必须存在移动输入，不会改为朝鼠标方向移动。
- 闪避期间忽略敌人与弹幕碰撞，终点受场地边界限制。
- 踩拍闪避在终点释放半径 `60px` 的清弹震荡波，并按三倍能量倍率获得 `3` 点 Fever 能量。
- 玩家受伤后有 `600ms` 受伤无敌；玩家受伤和敌人受伤都有闪白、火花、震屏等反馈。
- 玩家保持原静态 `player.png` 角色图；玩家受击、闪避、攻击继续使用既有的闪白、拖尾与武器挥动表现。

## 五、武器

### 双持荧光棒

- 四拍输入：`轻 → 轻 → 重 → 轻`。
- 正确输入发射 5 枚红色长条弹丸；错误输入只发射瞄准方向正中的 1 枚。
- 5 枚弹丸均匀覆盖总计 `30°` 扇区，弹速 `320 px/s`，在下一个整数拍消失。
- 击退方向沿弹丸方向，速度 `150 px/s`，持续 `160ms`。
- 角色身上显示两根红色 `30 x 7.5px` 短棒；攻击时以底端为轴挥动 `30°`，并在下一整数拍结束。

### 伸缩警棍

- 四拍输入：`轻 → 重 → 重 → 轻`。当前四拍均执行警棍弧形扫击，不附带角色位移。
- 正确输入生成内、中、外 3 条紫色弧段；错误输入只保留中间弧段。
- 内、中、外半径为 `69.5 / 92.5 / 115.5px`，弧段长度比例为 `0.5 / 1 / 1.5`。
- 轻拍顺时针覆盖 `90°`，重拍逆时针覆盖 `120°`；弧段在 `150ms` 内完成行程并销毁。
- 击退沿弧段运动方向，速度 `187.5 px/s`，为荧光棒的 `1.25x`。
- 角色身上显示一根紫色 `51 x 9px` 警棍；攻击时以底端为轴挥动 `50°`，并在下一整数拍结束。

连续攻击会打断并重新开始武器挥动动画。待机武器固定在角色中心，不跟随鼠标旋转。

## 六、敌人和波次

当前实机只生成两类敌人：

| 敌人 | HP / 半径 | 移动 | 攻击 | 掉落 |
|---|---|---|---|---|
| 保安 `SmallGuard` | `40 / 17px` | 每拍重选带随机偏差的追踪方向 | 每小节第 1 拍发射 1 枚蓝弹 | 伸缩警棍 |
| 粉丝 `FanEnemy` | `40 / 17px` | 慢行跑步；拍前翻滚突进 | 每小节第 1 拍发射 1 枚蓝弹，同时播放近战 | 双持荧光棒 |

`MidGuard` 代码仍保留，但不加入当前波次。

| 波次 | 保安 | 粉丝 | 总数 |
|---|---:|---:|---:|
| 1 | 1 | 1 | 2 |
| 2 | 2 | 2 | 4 |
| 3 | 4 | 4 | 8 |
| 4 | 8 | 8 | 16 |
| 5 | 16 | 16 | 32 |

两类敌人都在拍间以 `30 px/s` 前进，并在每个整数拍重选带随机偏差的方向。保安下一拍前 `0.1s` 以 `105 px/s` 推进；粉丝在同一窗口以 `210 px/s` 翻滚，并以更高加速度调校为约两倍旧突进位移。近身时随机方向偏差更大，避免大量敌人收束成规则圆环。

粉丝动画规则：素材默认朝右，向左移动由引擎水平翻转；慢行循环 `run-02` 至 `run-05` 四帧，拍前突进、受击均循环翻滚，攻击触发一次近战。动画按透明内容而非画布校准：跑步 `445px`、翻滚 `415px`、近战 `500px` 内容高度。以旧静态粉丝约 `73px` 的可见高度为跑步基准，显示时分别约为 `73 / 68 / 82px` 高，宽度按动作自然变化。

## 七、敌方弹幕

- 蓝色长条，尺寸 `27 x 7.5px`，命中伤害 12。
- 存活 8 拍，即 2 小节。
- 拍间速度 `6 px/s`；每个整数拍前 `0.1s` 以 `600 px/s` 快速前移。
- 慢行阶段保留额外方向拖尾，拍前快速移动开始时清除；快速移动期间生成与速度相关的 Trail。
- Trail 初始透明度限制在 `0.08 ~ 0.24`。

## 八、掉落与换武器教学

- 保安绑定警棍，粉丝绑定荧光棒。玩家已持有同种武器或场上已有同种掉落时不重复生成。
- 地面荧光棒为两根红色 `30 x 7.5px` 短棒；警棍为一根紫色 `51 x 9px` 长棒。
- 掉落物每个整数拍闪白 `90ms`，上浮 `10px` 后回落；玩家进入 `34px` 范围自动拾取。
- 拾取后的下一完整小节由系统自动演示新武器四拍连段，演示结束后交还控制。

## 九、ComboMeter 与 Fever Time

- 正确攻击和自动演示的基础能量为 2，经 `3x` 倍率结算为 `+6`；踩拍闪避基础 1，结算为 `+3`。
- 每 20 点提升一级伤害：1 至 5 级分别为 `+10% / +15% / +20% / +25% / +30%`。
- 100 点进入 Fever Time，基础持续 16 拍。结束后能量清零。
- Fever 期间正确输入以普通阶段一半效率回充，每次按 3 点折算为延长 `0.48拍`，剩余时长最多恢复至 16 拍。
- Fever 正确轻拍附加半角 `55°`、半径 `230px`、伤害 10 的扇形音波；正确重拍附加半径 `190px`、伤害 14 的圆形音波。音波会清除途经敌弹并伤害敌人。

## 十、音效和手柄震动

- 轻拍喊声：`beat-light.mp3`，单人 `-13dB` 素材。
- 重拍喊声：`beat-heavy.mp3`，多人 `+0dB` 素材。
- 玩家受伤、进入 Fever、敌人受伤、拾取武器在整数拍播放；同拍优先级依次为：玩家受伤 > Fever > 敌人受伤 > 拾取。
- 正确轻拍震动 `60ms`，正确重拍震动 `130ms`，成功闪避震动 `90ms`；错误输入和闪避失败不震动。

## 十二、原型验收问题

1. 只用 `RB` 自动覆盖轻重输入后，手柄仍能否保留节拍参与感？
2. 五波指数增长在第 4、5 波是否造成不可读或性能压力？
3. 敌弹的慢行、拍前快速前移和方向拖尾是否足够可读？
4. 两种武器的 5/1 发与 3/1 段错误反馈是否清晰？
5. Fever 半速回充是否能鼓励持续正确输入，又不会无限维持？
