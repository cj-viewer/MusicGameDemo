# 简化玩法策划案（当前原型版）

> 最后核对：2026-08-17
>
> 本文档只描述 `dev-1.0` 当前可运行原型。长期目标与未落地设计见《2D音乐弹幕游戏策划案（持续更新）》，精确参数与逐次改动见《实机落地与调整记录》。三份文档冲突时，以当前代码和《实机落地与调整记录》的“当前实机规则”为准。

## 一、当前验证目标

验证“自由走位 + 固定节拍攻击 + 轻重连段 + 节拍弹幕”是否能形成清晰、可读的战斗循环。

当前范围：教学关与正式关两套纯视觉环境、五波敌人、两把武器、键鼠和手柄操作、ComboMeter、Fever Time、与节拍对齐的 BGM，以及玩家和粉丝敌人的独立序列帧。多房间、Boss、剧情、正式音乐关卡、玩家拾取动画，以及保安的正式动画接入尚未实现。

开局流程为：先显示游戏标题“节奏星球”、副标题“DJ Drop the Beat”和“开始”按钮；玩家点击后依次带原声播放 `intro.mp4` 与 `intro-rocket.mp4` 两段开场动画，第二段完成后直接进入教学。标题页或任一段视频播放期间均可按空格跳过全部片头并直接进入教学。

当前流程使用两套纯视觉环境：教学关为项目方 `111.png` 定版内容覆盖后的池塘俯视底图；完成教学并选择进入正式关后，切换为由原色运行底图与 35 张透明物件原位重组的粉紫音乐广场，另保留一张无物件干净底图。正式关物件沿用参考原图 RGB，并把原始投影一同纳入透明层；入口大门层保留安检口内的左右设备、中央淡色场景和前排栏杆。环境切换不重建角色、节拍或战斗状态，也不增加碰撞体；正式关左右底部灌木与低墙连续覆盖到画布侧边和底边。35 个物件会以各自底边为锚点跟随轻 / 重拍同步做轻微纵向回弹，重拍幅度更明显；原色运行底图和无物件干净底图始终静止。

## 二、操作

| 输入 | 行为 |
|---|---|
| `WASD` | 带惯性的八向移动 |
| 自动瞄准 | 默认锁定综合优先级最高的敌人；移动方向前方总角度 `45°` 的扇区内，敌人的有效距离按实际距离一半计算 |
| `"` 键 / `Enter` | 轻攻击 / 重攻击 |
| 左 `Shift` / 右 `Shift` | 沿当前移动输入方向闪避 |
| `Esc` | 打开 / 关闭音量设置面板；可调敌人死亡音效并开关右下 FPV；P 面板打开时按 Esc 直接切换到音量面板 |
| 左摇杆 | 模拟量移动；右摇杆不再控制瞄准 |
| `LB` | 闪避 |
| `RB` | 攻击；自动采用当前拍要求的轻或重输入 |
| `R` | 重新开始 |
| `F` | 调试：直接充满 ComboMeter |
| `C` | 调试：直接触发从左向右的全屏发光条清弹 |
| `P` | 打开 / 关闭调参面板；可调整玩家 / 敌人战斗参数、切换两种重击新模式并导出当前战斗参数 TXT |
| `Space` | 在标题页或任一段开场视频期间跳过全部片头并进入教学；教学期间直接进入正式关 |

鼠标移动和左右键均不提交战斗输入；键盘轻重攻击要求玩家用 `Quote / Enter` 区分输入。手柄不使用 `RT` 攻击，`RB` 只合并轻重按钮，不绕过节拍窗口。自动瞄准使用加权距离：扇区外敌人按实际距离计分，当前移动方向前方左右各 `22.5°`（总角度 `45°`）内敌人按实际距离除以 `2` 计分，分数最低者被锁定。因此前方距离为 `2` 的敌人与扇区外距离为 `1` 的敌人同优先；没有敌人时保持最后一次有效移动方向。

两段片头播放完毕或按空格跳过后直接进入教学场景，不再显示第二层全屏标题字幕或“点击开始”。教学关左下显示低透明度精简操作卡：左栏以同一基线排列 `WASD / 移动` 和左右 `Shift / 冲刺`，右栏排列双引号键 / 轻攻击、`Enter` / 重攻击、`Esc / 设置`。操作卡不重复显示自动锁定说明或四拍顺序，只用于视觉教学；它位于底图之上、角色之下，进入正式游戏后隐藏。教学连段改为左上透明美术面板，标题、框线和四拍图形均来自项目方原图，旧程序化深色背板与进度、延迟、跳过提示文字不再显示。连续三个小节完成后，轻攻击直接进入正式关，重攻击重新进行教学；鼠标无法完成该选择，手柄 `RB / LB` 分别映射为进入 / 重练。教学练习期间仍可随时按 `Space` 跳过剩余练习并直接进入正式关倒计时，隐藏文字不改变该输入逻辑。

## 三、节拍与判定

- `132 BPM`、`4/4` 拍，每拍约 `0.455s`、每小节约 `1.818s`。四首 BGM 均按 `132 / 各自源 BPM` 的倍率播放，因此音乐、Conductor、判定和视觉拍点等比例放慢；每首曲目的源文件首拍偏移在播放时按倍率换算，并继续与节拍时钟第 0 拍对齐。
- 攻击窗口为整数拍前后各 `0.2s`；同一拍最多结算一次输入。评价使用校准后的绝对时间误差：`≤100ms` 为 `PERFECT`，`>100ms 且 ≤200ms` 为 `GOOD`，超出窗口或轻重输入错误为 `POOR`。Perfect / Good 均执行完整正确攻击并积攒能量，Poor 沿用错误攻击与断连规则。
- P“玩家伤害”页分别提供荧光棒轻 / 重基础伤害 `10 / 18` 与警棍轻 / 重基础伤害 `12 / 26`，均可按 `1` 调为 `0–100`。两把武器另各有 Perfect / Good / Poor 倍率，默认 `120% / 100% / 50%`，可按 `10%` 调为 `0–300%`。单发 / 单段实际伤害为“当前武器轻或重基础伤害 × 判定倍率 × ComboMeter 伤害倍率”；Fever 与闪避音波不读取这些武器参数。
- P“速度 / 频率”页分别提供荧光棒轻 / 重与警棍轻 / 重攻击动作速度，默认均为 `100%`，可按 `10%` 调为 `50–200%`。每项分别缩放对应轻 / 重攻击的角色特效、武器挥动和动作锁；警棍弧段自身飞行速度继续使用独立参数。
- 每次已结算的攻击在玩家实际攻击锚点附近显示小型 JRPG 浮字：主字为窄体感粗斜体和深色描边，下方以更小字号标出 `EARLY / LATE` 与三位毫秒误差。浮字从轻微压缩状态快速弹起，短暂停留后继续上浮并消隐；Perfect 为金色，Good 为蓝色，Poor 为灰色。每个浮字独立退场且在结束后销毁，连续输入最多短暂重叠，不固定遮挡画面中央。
- 教学要求连续三个完整小节全对；教学期间收集按键种类正确、距离原始拍点 `≤180ms` 的输入时间差，其中 `≤120ms` 的稳定样本以中位数和离群值剔除估算设备延迟。校准值限制在 `±120ms`，只平移后续输入判定时钟，不改变 BGM、拍点提示或音效时钟。
- 正确输入会执行完整攻击并积攒能量；错误输入仍攻击，但只保留中间弹丸且不积攒能量。
- 错误输入不会清空 ComboMeter，也不会禁止本小节后续攻击；空拍无惩罚。
- 教学与正式游戏均不显示常驻战斗区外框、未来三拍的整场扩散框或底部汇聚式节奏条。教学练习期间左上显示项目方提供的 `578 x 278` RGBA 连段面板，运行时为 `366 x 176px`，中心 `(284, 211)`、左上角 `(101, 123)`；当前拍和正确命中仅把同一张图中对应格裁出并以 ADD 短暂高亮，不重新绘制标题、框线或轻重图形。连续三小节要求、延迟校准和 `Space` 跳过仍在逻辑中运行，但不再额外显示进度、延迟数值或跳过提示。进入正式关时仍改为 `320 x 64px` 的紧凑四拍图标条，只保留当前武器的四个 pattern 图标并继续逐拍高亮；切换武器时同步重建图标。移除整场框线只影响视觉提示，拍点前后各 `0.2s` 的攻击窗口、轻重 pattern 与结算不变。正确输入、Fever 和连续四拍仍保留各自瞬时反馈；连续完成一套四拍 Combo 后，场地四边仍会爆发 84 个向内 / 向外分层的 ADD 光屑，并叠加双层瞬时边框冲击波、宽光带、四角星爆和轻微镜头震动，短效结束后不会留下框线。
- 轻重喊声跟随当前武器的四拍序列，不因输入正确与否改变：轻拍基础音量为 `0.42`（上一版 `0.28` 的 `150%`），重拍保持 `0.28`。为补偿素材前置起声，轻、重喊声分别提前 `70ms / 74ms` 播放；重喊声在素材时间 `330–360ms` 淡出，避免跨到下一拍。

## 四、玩家、闪避与反馈

| 参数 | 当前值 |
|---|---:|
| HP | 100 |
| 最高移速 | `260 px/s` |
| 加速 / 减速 | `1050 / 720 px/s²` |
| 闪避距离 / 时间 | `160px / 140ms` |
| 正确 / 错误闪避消耗 | ComboMeter `10 / 20` 点（半级 / 一级） |
| 闪避判定窗口 | 拍点前后各 `0.12s` |

- 左下 HP 血条与 ComboMeter 归为同一信息区，二者处于同一水平基线；Combo 环向右移动其自身宽度的一半（`22px`），并跟随当前武器轻重拍进行更明显的律动。轻拍前纵向压缩到 `0.84x`、拍点弹到 `1.26x`；重拍前压到 `0.62x`、拍点弹到 `1.50x`。颜色沿用轻拍 `3%`、重拍 `5%` 的明度 / 饱和度变化限制；横向长度始终只表示剩余 HP，数值文字不缩放。
- 武器名位于 ComboMeter 圆环右侧，以 `22px` 粗体显示，并统一只使用“荧光棒 / 警棍”两个短名称；右上角不显示常驻设置提示。
- 闪避必须存在移动输入，不会改为朝锁定目标方向移动。
- 闪避期间忽略敌人与弹幕碰撞，终点受场地边界限制。
- 闪避不再使用体力；正确 / 错误闪避分别扣 `10 / 20` 点，最低扣到 `0`。ComboMeter 已为 `0` 时，两次成功启动的闪避至少间隔 `500ms`；非空时仍按原输入节奏响应。Fever 激活期间等比例缩短 `1.6 / 3.2` 拍剩余时间。
- 每次闪避进行到总时长的三分之二（约 `93ms`）直接释放 Fever 重拍同款全圆音波与音效，波前、`190px` 半径、清弹和伤害结算全部复用 Fever 圆波逻辑。音波伤害为 `14 × 当前 Combo 伤害倍率`，每个敌人只结算一次，且不返还 ComboMeter。
- 玩家受伤后有 `600ms` 受伤无敌；玩家与敌人受击时，本体 Sprite / Image 分别使用纯白填充闪烁 `140 / 120ms`，并保留火花、震屏等反馈。
- 玩家使用正式红发角色状态机：静止循环 `Idle` 8 帧，移动循环 `Run` 8 帧，闪避播放 `Dash` 12 帧。玩家与所有敌人本体在每拍做脚底锚定的 Y 轴上弹：轻拍升至基础高度 `105%`、重拍升至 `110%`，再在各自 `170ms / 220ms` 内恢复；不会压缩到原本高度以下，X 轴与左右镜像不参与缩放。仅显示 Sprite 参与，不缩放物理体、武器、攻击特效、FPV 或 Dash 位移。`Attack Light / Hard` 的 5 帧 PNG 是纯攻击特效层，必须与角色 `256 x 256px` 画布同中心、同翻转并在播放期间跟随角色，绘制在角色和武器身后；尺寸沿用现值。Light / Hard 分别使用亮黄 `#fff36b` / 紫粉 `#f28cff` 的 ADD 填色，Alpha 为 `0.72 / 0.92`，由单一 Sprite 接受 Glow 和 Threshold→Blur→ADD Bloom，不再叠加放大副本。实际轻攻击始终播放 Light，实际重攻击始终播放 Hard，错误输入也不串用。弹幕、警棍扫击、踩拍强调和 Fever 音波仍从既有攻击锚点生成。闪避位移仍在 `140ms` 内完成，Dash 动画持续 `360ms`，即在位移结束后保留 `220ms` 收势；冲刺拖影仅在位移期间沿真实轨迹每 `10ms` 补齐一次，起始 Alpha 为 `1.0`。战败后玩家与所有存活敌人立即停止移动和攻击，固定在原位播放各自 Idle（静态敌人保持静态待机），场上敌我弹丸及警棍弧形命中体全部清除，并显示失败 / 重开提示。
- 正式玩家帧均为 `256 x 256px` 透明画布，Idle / Run 的可见内容高度约 `100–116px`、脚底约在源图 `y=186`。1080p 内部画布使用约 `0.7067x`，内部可见高度约 `76.3px`、固定受击体约 `29.7 x 76.3px`；等比显示到旧 720p 窗口时仍约为 `50.9px / 19.8 x 50.9px`，维持此前视觉大小。透明画布不参与碰撞。
- 内部开发画布固定为 `1920 x 1080`，低于该物理分辨率时不启动游戏；全局使用 Nearest Neighbor / 像素整数渲染。战斗区边界为 `x=141–1779`、`y=18–939`（`1638 x 921px`），屏幕左、右、下三侧各保留约 `123px` 场外留白；玩家、敌人和掉落均限制在战斗区内。
- 教学关与正式关均不再绘制旧版三侧深紫粉边缘律动条、常驻紫色战斗区外框或未来三拍的整场扩散框；左、右、下不会再随轻重拍跳高、变亮或由粉紫转橙，战斗区边缘也不会循环出现拍点框线。不可见物理边界、角色与正式关物件跟拍、正确命中短效、Fever 临时边框和四拍连段爆发均保持不变。
- 玩家、保安和粉丝按脚底 Y 动态排序：屏幕下方对象遮挡上方对象。玩家手持武器和敌人血条使用所属角色相邻深度，整体仍参与同一 TopDown 遮挡关系；自动索敌不绘制攻击方向指示线。
- 1080p 内部画布的程序化场内对象使用 `1.2x` 倍率（旧 `0.8x × 1.5`），屏幕占比保持不变；正式红发玩家、攻击特效和正式武器使用各自显式比例。玩家移动、伤害、BPM 和判定窗口不因分辨率迁移而改变；敌人速度以本节当前 `44 / 66 / 72 px/s` 匀速规则为准。HUD、场地与节奏提示由旧 720p 排版统一按 `1.5x` 迁移，圆形能量表标题常驻为 `ComboMeter`。

## 五、武器

### 荧光棒

- 四拍输入：`轻 → 轻 → 轻 → 重`。
- 正确输入的弹丸数为基础 `1` 枚、每提升 `1` 个 ComboMeter 等级增加 `1` 枚，最多 `5` 枚（等级 `0–5` 对应 `1 / 2 / 3 / 4 / 5 / 5`）。错误输入只发射瞄准方向正中的 1 枚，长度与飞行距离各为正常攻击的 `50%`。
- 第一枚固定在瞄准中线，此后每升一级按左、右交替增加 `±7.5°、±15°、-22.5°` 偏移弹丸。每枚 `30.4 x 8px`，默认弹速 `360 px/s`，可在 `P` 设置中按 `20 px/s` 调为 `100–800 px/s`。`P` 调参面板的“玩家远程无限射程”按回传配置默认开启；关闭后有限模式默认最远飞行 `164px`，可按 `20px` 调为 `40–2000px`。两种模式都会在命中或飞出战斗区时销毁。
- `P → 模式 / 导出` 的“荧光棒重击：贯屏激光”按回传配置默认开启。重攻击输入先显示充能环，默认延迟 `0ms`，可按 `50ms` 调为 `0–1500ms`；激光粗细默认 `56px`，可按 `4px` 调为 `12–160px`。激光从输入时的武器发光端沿瞄准方向射到 `1920 x 1080` 画面边缘，路径上的每个敌人各结算一次伤害，不会在命中首个敌人后消失。Poor 的实际粗细为当前值的 `55%`；伤害仍读取该拍基础伤害、判定倍率与 ComboMeter 倍率，击退继续为 `150 px/s`。
- 击退方向沿弹丸方向，速度 `150 px/s`，持续 `160ms`。
- 玩家持有正式荧光棒贴图 `light_stick_player.png`，按约 `0.5653x` 显示；旋转原点为素材握把末端 `(101/128, 98/128)`，固定在角色腰部中线、内部下移 `22.5px`。武器绘制在角色前方，另一朝向使用负 `scaleX` 围绕 Origin 做几何镜像，禁止用 `flipX` 翻 UV。
- 直射先读取荧光棒源图发光帽外沿中心 `(29.5, 27.5)`，运行时按武器当前的正负 `scaleX` 和挥击角换算为世界坐标；随后每条弹道沿自身方向前移内部 `28.8px`（FIT 到 720p 约 `19.2px`），作为原长度判定段的起点。短亮芯与胶囊外晕以该判定段中心为锚；左右朝向、轻 / 重出手和扇射都使用同一规则，伤害、判定长度、弹速和寿命不变。

### 警棍

- 四拍输入：`轻 → 轻 → 重 → 重`。当前四拍均执行警棍弧形扫击，不附带角色位移。
- 正确输入的弧段数读取 ComboMeter：基础为中层 1 段，每提升 `2` 个等级增加 1 段，最多 3 段（等级 `0–5` 对应 `1 / 1 / 2 / 2 / 3 / 3`）；错误输入只保留中层，弧段长度和扫击覆盖角度均为正常攻击的 `50%`。完整三层的形状、半径与运动方式不变。
- 内、中、外半径为 `55.6 / 74 / 92.4px`，弧段长度比例为 `0.5 / 1 / 1.5`。
- 轻击顺时针扫角默认 `180°`，可在 P 按 `10°` 调为 `30–180°`；距离范围默认 `111px`，可按 `10px` 调为 `40–400px`。Poor 轻击使用当前设定角度的 `50%`，但仍读取设定距离。旧模式重击逆时针覆盖 `120°` 且不读取轻击距离；弧段默认在 `150ms` 内完成行程并销毁，`P` 可将弧段飞行速度调为 `50–200%`。
- 击退沿弧段运动方向，速度 `187.5 px/s`，为荧光棒的 `1.25x`。
- `P → 模式 / 导出` 的“警棍重击：击退月牙波”按回传配置默认开启。所有重攻击输入改为沿瞄准方向飞行的紫色月牙冲击波；正确重击最远距离默认 `424px`，可按 `40px` 调为 `120–1600px`，Poor 行程固定为当前设定值的 `50%`。月牙在前 `70%` 时间走完 `85%` 距离，最后 `15%` 行程以二次减速收至零速，到达上限后急停 `90ms` 再用 `110ms` 放大消散。每名敌人最多命中一次，伤害沿用该拍基础伤害、判定倍率与 ComboMeter 倍率，击退固定为 `320 px/s`。轻攻击与开关关闭时的重攻击继续使用原弧形扫击。
- 玩家持有正式警棍贴图 `baton_player01.png`，按约 `0.5653x` 显示；旋转原点为素材握把末端 `(123/128, 121/128)`，固定在角色腰部中线、内部下移 `22.5px`。瞄向另一侧时使用负 `scaleX` 几何镜像，静止位置和挥击轨迹严格关于角色中线对称。

手持武器不绕瞄准线旋转；轻 / 重攻击分别使用不同幅度的非线性向下挥击，并都在 `200ms` 内回到握持角。警棍只绘制发光弧线扫击，不额外绘制纯色扇形方向图形。玩家棍状武器的绘制层级为“武器 > 角色 > Attack 特效”。

两类实装敌人都在每个整数拍重选带随机偏差的方向，拍间不再使用节拍加速曲线，而是分别以 `44 / 66 px/s` 持续匀速移动；近身时随机方向偏差更大，避免大量敌人收束成规则圆环。未加入波次的中型保安移动时使用 `72 px/s` 匀速，进入保持距离区间后停下。

首次清空第五波后，场地底层常驻显示低饱和紫色纯色背板与 `VICTORY`；它们位于其他场景物件和 HUD 之下，并随之后每个轻重拍持续缩放、明暗呼吸，作为环境的一部分。游戏不会进入结束状态；等待 `2s` 后重新生成第五波的 `16` 只敌人，此后每次清空都继续重复第五波，顶部编号累计为 `Wave 6、Wave 7……`，形成无限循环与冲榜轮次记录。

主场景镜头采用轻量 Cinemachine 风格前探：1080p 基础缩放为 `1.0x`；角色在场地中央 `12%` 归一化死区内时保持居中，越靠近上下左右或四角，镜头越向对应方向平滑移动，水平 / 垂直最大约 `45 / 30px`，阻尼时间约 `220ms`。镜头只改变观看位置，不改变角色、敌人、弹幕、边界或伤害判定；HUD 与面板保持屏幕锚定，FPV 独立 Scene 不受影响。踩拍时轻 / 重最大缩放为 `1.00375x / 1.01875x`。

粉丝使用 `npc_fan01` 的正式橙色 `256 x 256px` 素材，替换旧粉丝外观而不是新增敌人类型。普通移动循环 8 帧 Run；攻击时角色本体继续运动，身后播放 6 帧橙色 Hard 特效，并由角色身后的专属 `128 x 128px` 荧光棒完成 `200ms` 向下挥击。保安攻击时在本体身后播放 Light 特效。敌人本体、武器与特效随朝向同步镜像；角色、武器与特效按“角色 > 武器 > 特效”分层；受击只对白闪，不切换旧 Roll 或近战动画。

## 七、攻击弹幕视觉与敌方弹幕

- 玩家荧光棒直射为红色线性自发光，并恢复“点/线特效自发光”任务的短光束比例：亮芯长度为物理判定段的 `1.35x`、厚度为原弹体的 `0.52x`；连续胶囊外晕长度为判定段的 `1.95x`、厚度为原弹体的 `3.2x`，不再设置额外最小长度。亮芯与外晕以原判定段中心为锚，原判定段仍从武器发光端前方内部 `28.8px` 开始。普通亮芯按 `66%` 向白抬亮并使用 `0.94` Alpha，正确踩拍为纯白 `0.96` Alpha；外晕使用红色连续胶囊 Alpha 纹理、`0.74` Alpha 与 ADD 合成。判定、弹速、寿命均不变；荧光棒正确踩拍不再从角色侧边生成旧双环或白色扇形。警棍扫击保留现有弧长与线宽。
- 敌弹继续使用现有点状尺寸：保安为青色 `#52efff`，粉丝为橙红色 `#ff543d`。保安 / 粉丝命中伤害默认均为 `12`，可在 P 中分别按 `1` 点调为 `0–100`；调整时已在场的对应敌弹也会立即更新伤害。
- 所有敌人瞄准玩家后，都先把基准攻击角吸附到最近的八方向扇区中线。保安单弹只沿该 `45°` 量化方向射出；粉丝再围绕量化基准展开三组弧形弹道。每个实际弹道的出生偏移、贴图旋转、速度和命中方盒始终使用同一角度。
- 存活 8 拍，即 2 小节。
- 保安与粉丝弹丸默认基础速度均为 `144 px/s`，可在 `P` 中分别按 `20 px/s` 调为 `40–600 px/s`。攻击频率范围 `0.25–8 次/拍`、步进 `0.25`；保安默认 `1 次/拍`，粉丝默认 `0.25 次/拍`。

## 八、掉落与换武器教学

- 保安绑定警棍，粉丝绑定荧光棒；默认掉落概率均为 `100%`，可在 P 中分别按 `5%` 调为 `0–100%`。只有玩家未持有且场上不存在同种掉落时才进行概率判定。
- 地面荧光棒为两根红色 `24 x 6px` 短棒；警棍为一根紫色 `40.8 x 7.2px` 长棒。
- 掉落物每个整数拍闪白 `90ms`，上浮 `10px` 后回落；玩家进入 `34px` 范围自动拾取。
- 拾取后立即切换武器并显示短暂提示，系统不会代替玩家攻击；新武器的下一次攻击必须由玩家主动输入。

## 九、ComboMeter 与 Fever Time

- 正确攻击的基础能量为 2，经 `3x` 倍率结算为 `+6`；闪避不再获取能量，改按正确 / 错误扣除 `10 / 20` 点。
- 每 20 点提升一级伤害：1 至 5 级分别为 `+10% / +15% / +20% / +25% / +30%`。
- 100 点进入 Fever Time，基础持续 16 拍。结束后能量清零。
- Fever 期间正确输入以普通阶段一半效率回充，每次按 3 点折算为延长 `0.48拍`，剩余时长最多恢复至 16 拍。
- Fever 期间每次正确输入额外恢复 `10 HP`，生命不会超过最大值。
- Fever 满格激活时，一根贯穿画面高度的橙金发光条用约 `620ms` 从左向右扫过全屏；敌弹在光条经过时逐列销毁，玩家荧光棒弹与警棍弧段不受影响。`C` 键可直接触发同一清屏逻辑用于调试。Fever 期间玩家攻击不再向左后 / 右后追加两组，始终只沿当前瞄准方向生成。
- Fever 正确轻拍附加半角 `55°`、半径 `230px`、伤害 10 的扇形音波；正确重拍附加半径 `190px`、伤害 14 的圆形音波。音波会清除途经敌弹并伤害敌人。

## 十、音效和手柄震动

- 敌人致死命中即时播放由高频破裂提示、中频下坠和低频落地组成的三层死亡音，不再排队普通敌人受伤音。Esc“敌人死亡音效”滑杆默认 `100%`、范围 `0–100%`；最终音量仍乘“受伤与敌亡”分类与主音量。
- 游戏默认主音量为 `150%`，范围 `0–300%`；BGM、节拍喊声、攻击与错误、受伤与敌亡、Combo、Fever、拾取六类音效默认均为 `100%`，各分类范围均为 `0–200%`。`Esc` 面板另有上限 `100%` 的敌人死亡音效滑杆及右下 FPV 开关。P 分为“速度 / 频率”“玩家伤害”“敌人 / 掉落”“模式 / 导出”四页；TXT 记录四个轻重基础伤害及其它战斗数值，但不记录 BGM 槽或 FPV。任一面板打开时均暂停玩法。
- BGM 使用 `public/assets/audio/music/` 下的四首可选音轨；教学关默认 `bgm0.mp3`，正式关默认 `bgm2.mp3`。界面默认显示 `100%`，内部以 `0.084375` 基础音量播放。所有音轨均以 `132 / 源 BPM` 的倍率播放，首拍偏移按该倍率换算后与 Conductor 第 0 拍同步；每首音轨到自身的循环拍数边界时重新对齐，重开时停止旧实例，避免循环漂移或叠音。
- 轻拍喊声：`beat-light.mp3`，单人 `-13dB` 素材。
- 重拍喊声：`beat-heavy.mp3`，多人 `+0dB` 素材。
- 玩家受伤、进入 Fever、敌人受伤、拾取武器在整数拍播放；同拍优先级依次为：玩家受伤 > Fever > 敌人受伤 > 拾取。
- 正确轻拍震动 `60ms`，正确重拍震动 `130ms`，成功闪避震动 `90ms`；错误输入和闪避失败不震动。
