# 双人分屏协作实验：移动位 + 第一人称节奏射击位

> 实验分支：`experiment/split-coop-fpv`（基于 dev-1.0 的 f8dd004）。
> 主线不受影响；放弃实验直接 `git checkout dev-1.0` 即可，无需任何清理。

## 玩法设想

把现有单人玩法拆给两个人：

| 角色 | 输入 | 画面 |
|---|---|---|
| 移动位（P1） | 键盘 WASD 移动、Shift 冲刺 | 左半屏：现有俯视战场（整体缩放 0.5 放进左半） |
| 节奏射击位（P2） | 鼠标瞄准、左键轻攻击、右键重攻击 | 右半屏：从主角位置出发的第一人称视角 |

现有代码的输入天然可拆：移动只读键盘、瞄准攻击只读鼠标，因此**逻辑层不需要任何双人改造**，本实验的核心工作是给射击位做一个第一人称显示面板。

## 技术设计

### 画面布局

- 游戏画布保持 1280×720。
- **分屏开关**：V 键随时切换（含标题界面）。默认关闭，行为与主线完全一致。
- 开启后：MainScene 主相机 `setViewport(0, 0, 640, 720)` + `zoom 0.5`，整个俯视战场（含 HUD）缩进左半屏；右半屏由新增的并行场景 `FpvScene` 负责。
- 踩拍特效的相机推拉改为基于 `baseZoom` 缩放，分屏与全屏下都正确。

### FPV 伪 3D 原理（无 3D，纯精灵缩放）

`FpvScene` 每帧读取 MainScene 的状态（敌人、双方子弹、主角、节拍时钟），用针孔投影公式把世界坐标映射到面板坐标：

- 视角方向 = 主角当前瞄准角（`aimAngle`），带平滑转向；FOV 100°。
- 相对角 `rel = wrap(angleTo(target) - viewAngle)`，水平位置 `x = 中心 + FOCAL · tan(rel)`。
- 尺寸随距离缩放：`屏幕高 = 世界高 · FOCAL / dist`（`FOCAL = 半幅宽 / tan(FOV/2)`）。
- 落地位置：`y = 地平线 + 视线高 · FOCAL / dist`（近大远小、近低远高）。
- 敌人直接复用当前贴图（保安图、粉丝当前动画帧），按距离排序绘制（远的先画）。
- 子弹画成同色矩形色块，同样透视缩放。
- 天空/地面双色背景 + 等距地面横线增强透视感；中心准星 + 随节拍收缩的节拍环，给射击位独立的节奏提示。

### 数据通道

FpvScene 通过 `scene.get('MainScene')` 只读访问；MainScene 暴露三个只读访问器（`fpvEnemies` / `fpvEnemyBullets` / `fpvPlayerBullets`），不改变任何游戏逻辑。对象池渲染（敌人 40、弹丸 80），无每帧创建销毁。

### 已知取舍（实验范围外，迭代候选）

- 射击位的瞄准仍是"俯视系"鼠标瞄准（FPV 里表现为转动视角对准目标），未做指针锁定式 FPS 转向。
- FPV 中暂不绘制敌人血条、受击闪白、场地墙体。
- 左半屏 HUD 是整体缩小的，未针对小尺寸重排。

- [x] 第二轮反馈：抗眩晕与右侧节奏显示（2026-08-12）：
  - **指针锁定观察**：点击右半屏进入指针锁定（鼠标隐藏），改为 FPS 式相对移动转向（灵敏度 0.0032 弧度/像素）；Esc 退出后回退为转向盘方案；关闭分屏自动释放锁定

  - **节奏点移到右侧**：分屏时左侧连段面板隐藏（教学面板除外），FPV 顶部显示连段条（○轻 ◆重），当前拍随节拍脉冲，换武器自动重建

```bash
git checkout dev-1.0                     # 回到主线，实验零残留
```
