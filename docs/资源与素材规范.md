# 资源与素材规范

## 目录边界

| 内容 | 目录 | 是否参与构建 |
|---|---|---|
| 角色、武器、特效、背景、UI | `public/assets/images/` | 是 |
| BGM、音效 | `public/assets/audio/` | 是 |
| 开场视频 | `public/assets/video/` | 是 |
| 字体、谱面、关卡数据 | `public/assets/fonts/`、`public/assets/data/` | 是 |
| 策划参考图、原图、附件 | `docs/图片和附件/` | 否 |

运行时代码只可从 `public/assets/` 加载资源。Phaser 路径必须通过 `import.meta.env.BASE_URL` 拼接，不能写死 `/assets/`，以兼容 GitHub Pages 的仓库子路径。

## 角色序列帧

角色素材默认只绘制**朝右**版本；向左运动由 Phaser 的 `setFlipX(true)` 完成。

```text
public/assets/images/characters/<角色>/animation/<动作>/<角色>_<动作>_<两位序号>.png
```

示例：

```text
public/assets/images/characters/player/animation/run/player_run_01.png
public/assets/images/characters/player/animation/dash/player_dash_01.png
public/assets/images/characters/npc/npc_guard01/animation/idle/npc_guard01_idle_01.png
```

- 只把实际播放的帧提交进运行时目录；站定测试帧、重复帧和废弃导出帧应在导入时清掉。
- **先校准，再接入引擎。** 导入前必须逐帧检查透明内容边界、脚底基线和像素高度；不得根据完整画布大小直接设置统一显示尺寸。
- 以一个动作作为视觉基准（本项目粉丝以跑步为基准），同一动作的所有帧必须裁掉无效透明边缘，并归一到同一内容高度；宽度按原比例变化。
- 不同动作可以使用不同内容高度。应相对基准动作人工查看后决定，例如粉丝当前为：跑步 `445px`、翻滚 `415px`、近战 `500px` 内容高度；以旧静态粉丝约 `73px` 的实际可见高度为跑步缩放基准，因此翻滚仅轻微收缩、近战适度放大，避免动作切换突变。
- 正式红发玩家素材统一使用 `256 x 256px` 透明画布：Idle 8 帧、Run 8 帧、Dash 12 帧、Attack Light / Hard 各 5 帧、Death1 / Death2 各 8 帧。Attack Light / Hard PNG 是纯特效层，只能用独立 Sprite 叠加，不得替换本体纹理；特效从角色中心向朝向侧偏移约 `5.12px`，深度低于武器和角色，生成后不得继续跟随角色，在 `200ms` 内由玩家基础比例放大至 `1.35x` 并淡出。预览 GIF 仅是角色与特效的合成预览。Idle / Run 当前按约 `0.471x` 显示，可见高度约 `50.9px`；固定受击体世界尺寸约 `19.8 x 50.9px`。
- 玩家正式手持贴图固定使用 `images/weapons/light_stick/player/light_stick_player.png` 与 `images/weapons/baton/player/baton_player01.png`。两者统一使用贴图中心原点、约 `0.377x` 显示比例，中心相对玩家为 `x=±8.96px、y=+3.84px`；左右只允许改变 X 符号并同步水平翻转，确保严格围绕角色中线对称。绘制深度必须略低于所属玩家，不得再用程序矩形棒替代。
- 当前正式资源目录没有截图中展示的 Pick 序列帧。不得用 Attack、Dash 或 Idle 冒充 Pick；补齐素材后再同步更新 preload、状态机、资源验收和文档。
- 每个动作完成裁切和缩放后，至少目视检查一张基准帧和一张幅度最大的帧，确认脚底不跳、攻击不显小、透明边缘不影响比例。
- 新动作必须同时更新 `preload`、Phaser 动画注册、敌人/角色状态切换和更新记录。
- 保持透明背景，单帧建议不超过 `1MB`。

## 通用命名与验收

- 新文件使用小写英文、数字与连字符；不得使用“final”“new”“v2”或模糊的临时后缀。
- 角色/敌人放 `images/characters/`，武器放 `images/weapons/`，视觉特效放 `images/effects/`，背景放 `images/backgrounds/`，UI 放 `images/ui/`。
- 音效放 `audio/sfx/`，BGM 放 `audio/music/`。音效键与文件名的映射须在加载代码中保持可追溯。
- 开场和过场视频放 `video/`，使用浏览器可播放格式；带声音的视频必须处理自动播放锁定。
- 导入后执行 `npm run build`，本地预览确认资源返回 200、控制台无资源 404、实际播放帧与逻辑状态一致。
- `dist/`、浏览器测试截图、下载残留和无引用的临时导出图不得提交。
