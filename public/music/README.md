# 添加自己的歌曲

游戏不内置任何受版权保护的歌曲。想跟着真实歌曲（比如初音的曲子）打节拍，
把你**合法持有**的音频文件（mp3 / ogg / m4a / wav）放进本目录，
然后在本目录创建 `tracks.json`：

```json
[
  {
    "name": "我的歌",
    "url": "music/mysong.mp3",
    "bpm": 132,
    "firstBeatOffset": 0.35,
    "gain": 0.8
  }
]
```

字段说明：

| 字段 | 说明 |
|------|------|
| `name` | 标题界面显示的曲名 |
| `url` | 相对站点根的路径，文件放在 `public/music/` 下就写 `music/文件名` |
| `bpm` | 歌曲每分钟拍数（大部分歌曲能在网上查到；VOCALOID 曲目一般也有公开数据） |
| `firstBeatOffset` | 音频文件开头到**第一拍**的秒数。判定总觉得自己按早了就调大，按晚了就调小，按 0.02~0.05 一档微调 |
| `gain` | 音乐音量 0~1，选填，默认 0.8 |

保存后刷新页面，标题界面按 **M** 切换曲目。加载失败会自动回退到内置合成曲。

注意：
- 本目录已被 git 忽略音频文件（避免误提交受版权保护的内容），`tracks.json` 同样只留在本地。
- 游戏节奏系统按 4/4 拍设计，选 4/4 拍、鼓点清晰的歌曲手感最好。
- BPM 变化的歌曲（变速曲）目前不支持，节拍会渐渐对不上。
