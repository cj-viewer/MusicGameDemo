# 非角色配色板

测量范围：教学实机完整四拍周期，共采样 8 帧；排除中央角色矩形区域。像素按最接近的项目代表色归类，因此下列面积占比用于表现层级判断，不等同于单帧逐色精确统计。

| 面积占比 | 用途 | 代表色 |
|---:|---|---|
| 67.53% | 场景底色 | `#1A1A2E` |
| 14.71% | 深层面板 | `#0F172A` |
| 12.60% | 律动紫 | `#63356F` |
| 3.23% | 结构灰蓝 | `#334155` |
| 0.46% | 高亮粉紫 | `#E879F9` |
| 0.46% | 重拍橙 | `#F97316` |
| 0.32% | 生命绿 | `#4ADE80` |
| 0.25% | 信息浅灰 | `#E2E8F0` |
| 0.17% | 节拍青 | `#67E8F9` |
| 0.17% | 警示红 | `#EF4444` |
| 0.08% | 强调黄 | `#FACC15` |

当前非角色画面约 `94.84%` 由深色场景、面板与律动紫构成；粉紫、橙、绿、浅灰、青、红、黄等功能强调色合计约 `1.91%`，其余约 `3.23%` 为结构灰蓝。

动态规则：外侧律动条在每个拍间只跟随下一拍，轻拍前为粉紫色、重拍前为橙色；上表对完整四拍周期取平均，因此律动紫和重拍橙均包含其在不同拍间的占用时间。
